# 半导体设备五大高壁垒核心零部件详解

- **所属模块**：`05_设备与核心部件 / 02_核心高壁垒零部件`

| 核心零部件 | 所在位置与主要功能 | 关键技术壁垒与代表企业 |
| :--- | :--- | :--- |
| **RF 射频电源与匹配器 (RF Generator & Matchbox)** | 在刻蚀/PECVD 腔室内把气体电离成等离子体，并独立控制离子轰击能量（常用 13.56MHz / 2MHz / 27MHz / 60MHz 等） | 极快阻抗动态匹配（毫秒级，防止反射功率烧毁电源）、多频脉冲同步（Pulsed RF）；代表：MKS、AE (Advanced Energy)、英杰电气/恒运昌 |
| **静电吸盘 (ESC, Electrostatic Chuck)** | 在真空中利用静电力牢牢吸住硅片（真空吸盘在真空下无效！），并通过背面通入 **He 氦气** 高效导热控温 | 氮化铝/氧化铝精密陶瓷烧结、内部电极与加热区多区独立微调（Multi-zone Temp Control）、耐等离子体腐蚀表面处理；代表：Shinko、TOTO、Entegris、Applied Materials |
| **质量流量控制器 (MFC)** | 精确控制进入反应腔的几十路特种气体流量（误差常需 `< ±1%` 设定值） | 热式/压差式传感器响应速度（`< 500ms`）、极高耐腐蚀金属密封与零泄漏；代表：Horiba、Brooks、MKS、七星华创 |
| **干泵与涡轮分子泵 (Dry Pump & TMP)** | **Dry Pump（在 Sub-Fab）** 把腔室从大气抽到粗真空并排出有毒副产物；**TMP（直挂腔室底部）** 把真空度推至 $10^{-6}\sim 10^{-8}\,\text{Torr}$ 高真空 | 耐腐蚀合金涂层、防止生成氯化铵/氟硅酸铵固体粉尘卡死转子（温度管控）、极低振动；代表：Edwards、Ebara、Pfeiffer、Kashiyama、中科仪 |
| **高精度密封圈与特种阀门 (O-Ring / VAT Valve)** | 腔室密封与压力精准控制（如摆阀 Pendulum Valve 快速调节抽速维持腔压） | 全氟醚橡胶（FFKM）耐极端氟/氧等离子体不掉粉（Particle）；代表：DuPont (Kalrez)、VAT（真空阀门绝对龙头） |
