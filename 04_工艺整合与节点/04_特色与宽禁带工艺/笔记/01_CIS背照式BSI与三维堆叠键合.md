## 1. CIS 光电核心指标与结构演进：FSI → BSI → 3D Stacked

CMOS 图像传感器（CIS）将入射光子转化为光生电子并实施低噪声模数读出。晶圆厂工艺整合（PI）的所有工艺参数权衡均围绕五大光电良率死线开展：
- **量子效率（QE）**：有效收集电子与入射光子数之比，受制于像素开口率、硅吸收深度及表面反射率；
- **满阱容量（FWC）**：单个钳位光电二极管（PPD）在溢流饱和前能锁住的最大电子数（$0.6\sim 1.0\,\mu\text{m}$ 像素典型约 $4000\sim 12000\text{ e}^-$）；
- **暗电流（Dark Current）与白点（White Pixel）**：无光照下由硅表面悬挂键、等离子体刻蚀损伤及 Fe/Cu 重金属污染（SRH 深能级复合中心）激发的漏电流（严控 $<1\sim 3\text{ e}^-/\text{pixel/s}$ @ $60^\circ\text{C}$）；
- **读出噪声与随机电报噪声（RN / RTS）**：源极跟随器（Source Follower, SF）栅氧界面陷阱随机俘获/释放电子导致的时序闪烁噪点；
- **光学/电学串扰（Cross-talk）**：大角度斜射光或光生载流子横向溢出引发邻近像素偏色与清晰度恶化。

### （1）4T 钳位光电二极管（PPD）像素电路与噪声链路拆解
现代高端 CIS 普遍采用 4 晶体管（4T）PPD 架构实现近零暗电流与低噪声读出：
```text
[4T PPD 像素核心电路与晶圆厂工艺噪声归属]
         Vdd
          │
        [RST 复位管] ──► (复位 kTC 噪声：由片内相关双采样 CDS 电路消除)
          │
  [PPD] ─[TG 转移栅]─► FD (浮置扩散节点) ──► [SF 源极跟随器栅极] ──► [SEL 行选通] ──► 列 ADC 读出
    ▲                                                ▲
(暗电流/白点：PPD 耗尽区金属污染与背界面态)    (RTS 闪烁噪声：SF 栅氧界面陷阱 Dit 决定!)
```
- **为什么必须依托晶圆厂工艺降噪？** 浮置扩散节点（FD）复位产生的热噪声可通过前后两次采样相减（**相关双采样, CDS**）在电路域完美抵消；但 **PPD 内部热生暗电流**与 **SF 晶体管栅氧界面态引起的 RTS 闪烁噪声**具有随机时变特征，无法被 CDS 滤除，必须靠前道纯净度控制、栅氧钝化工艺以及背面极限钝化从物理源头铲除。

### （2）结构代际跃迁：FSI → BSI → 3D 堆叠与双层晶体管像素
- **传统 FSI（Front-Side Illumination）物理死穴**：光线必须穿越厚达 $3\sim 5\,\mu\text{m}$ 的多层 $\text{SiO}_2$ 绝缘层与 Cu/Al 走线狭缝方能触达光电二极管。当像素缩至 $1.4\,\mu\text{m}$ 以下时，金属夹缝形成狭窄波导盲区与衍射损耗，有效开口率跌破 $30\%$，且斜射光线经金属侧壁多次反射极易窜入隔壁像素引发严重偏色。
- **背照式（BSI）**：正面制作完光电二极管与多层金属走线后，翻转键合于载体硅片上并从背面减薄进光，金属层全面退居感光硅片下方，进光开口率跃升至接近 $100\%$。
- **3D 堆叠与双层晶体管像素（2-Layer Transistor Pixel）**：
  - **两层/三层堆叠（Pixel + Logic / Pixel + DRAM + Logic）**：将像素感光阵列、高速逻辑 ADC 与高带宽 DRAM 帧缓存分别制造在最适工艺节点（如像素 45/65nm、逻辑 22/28nm）并通过铜混合键合直接面贴面垂直互连（如 Sony Exmor RS / IMX400 实现 960fps 超高速读取）；
  - **双层像素晶体管工艺串联（如 Sony Exmor T）**：传统像素中 PPD 感光区与 SF/RST/SEL 晶体管在同一平面争夺地盘。双层晶体管像素先做好下层 PPD + 转移栅（TG）晶圆 → 氧化层永久键合并超薄减薄后 → 在上方直接堆叠制造独立的像素读出晶体管（SF/RST/SEL）→ 再经混合键合连向底层逻辑晶圆，从而使单像素 **FWC 翻倍** 且将 SF 面积放大数倍大幅压缩 RTS 噪点。

## 2. 现代 BSI 与 3D 堆叠 CIS 晶圆厂核心制造技术

### （1）载体晶圆键合、极限背面减薄与背界面钝化
1. **永久氧化层熔融键合（Oxide Fusion Bonding）**：
   - 在像素晶圆正面覆盖平坦化 PECVD TEOS 氧化硅并做超精密 CMP（粗糙度 $R_q < 0.3\text{ nm}$）；
   - 等离子体活化表面生成亲水基团并与载体晶圆（Carrier Wafer）室温预键合，经 $200\sim 350^\circ\text{C}$ 低温退火转化为牢固 $\text{Si}-\text{O}-\text{Si}$ 共价键。
2. **三段式极限背面减薄（$775\,\mu\text{m} \to 2\sim 4\,\mu\text{m}$）**：
   - **粗/精机械磨削（Grinding）**：将 $775\,\mu\text{m}$ 硅衬底快速减薄至 $30\sim 50\,\mu\text{m}$；
   - **应力释放湿法刻蚀 + 精密 CMP**：采用 $\text{HF}/\text{HNO}_3$ 或 TMAH 旋转湿法蚀刻搭配 CMP 彻除机械磨削残留的数微米亚表面微裂纹损伤层（否则引爆满屏白点），精准停在目标硅厚度：

| 目标工作波段 | 典型波长（nm） | 硅吸收深度（工程量级） | BSI 目标硅厚与光学强化对策 |
| :--- | :---: | :---: | :--- |
| **蓝光 / 绿光** | $450 / 530\text{ nm}$ | $0.4\text{ }\mu\text{m}\ /\ 1.2\text{ }\mu\text{m}$ | 极易在近背表层吸收，对**背界面钝化质量**极度敏感 |
| **红光（常规彩色）** | $650\text{ nm}$ | $\sim 3.0\sim 3.5\text{ }\mu\text{m}$ | 常规手机 CIS 减薄厚度 **$2.5\sim 3.5\,\mu\text{m}$**（兼顾红光 QE 与控制相邻串扰） |
| **近红外 NIR（ToF / 安防）** | $850 / 940\text{ nm}$ | $> 15\sim 40\text{ }\mu\text{m}$ | 留厚至 **$5\sim 10\,\mu\text{m}$** 并在背面刻蚀**倒金字塔散射微结构**延长斜光程 |

3. **背面低温界面钝化（Backside Passivation — 良率生死线）**：
   - 磨薄后的硅背表面紧邻光电二极管耗尽区且布满悬挂键。由于正面已完成低熔点 Cu 互连，背面绝不能进入高温热氧化炉管。产线采用**双保险低温钝化工艺**：
   - **浅层硼注入 + 纳秒激光退火（Laser Anneal）**：向背面浅注高剂量硼并执行超短脉冲激光退火激活表面几十纳米硅（瞬间熔融结晶，热传导不到 $3\,\mu\text{m}$ 下方的正面 Cu 线），构筑高浓度 $p^+$ 空穴积累层推斥电子远离表面陷阱；
   - **负固定电荷高 $k$ 薄膜（ALD $\text{Al}_2\text{O}_3 / \text{HfO}_2 / \text{Ta}_2\text{O}_5$）**：ALD 生长的 $\text{Al}_2\text{O}_3$ 与硅界面天然携带高密度负固定电荷（$Q_f \approx -10^{12}\sim -10^{13}\text{ cm}^{-2}$），自发感生表面空穴积累屏蔽暗电流；同时利用硅（$n\approx 3.8\sim 4.1$）→ $\text{Al}_2\text{O}_3$（$n\approx 1.65$）/ $\text{HfO}_2$（$n\approx 2.0$）/ $\text{Ta}_2\text{O}_5$（$n\approx 2.1$）→ $\text{SiO}_2$（$n\approx 1.46$）梯度折射率匹配充当宽光谱**减反射膜（ARC）**，将硅表面反射率压低至 $<2\%$。

### （2）深沟槽隔离（F-DTI vs B-DTI）与背金属光栅
为遏制 $0.56\sim 0.8\,\mu\text{m}$ 超微像素间的斜射光子与光电子横向穿透串扰，必须在像素四周修建全反射隔离墙：

| 隔离架构 | 加工时序与剖面特征 | 核心优势与工艺瓶颈 |
| :--- | :--- | :--- |
| **F-DTI（正面深沟槽）** | FEOL 阶段从晶圆正面先行刻蚀 $2\sim 3\,\mu\text{m}$ 沟槽并填氧化硅/多晶硅 | 与有源区自对准、套刻精度高；但挤占正面 PPD 满阱容积，且填充热应力易诱发白点 |
| **B-DTI（背面深沟槽，主流）** | 背面减薄后自背面干法刻蚀深窄槽（宽 $80\sim 120\text{ nm}$，$AR \approx 15:1\sim 25:1$），内衬 ALD $\text{Al}_2\text{O}_3$ + 填 $\text{SiO}_2$/W | **完全释放正面晶体管空间**；痛点在于窄槽 RIE 侧壁损伤紧贴 PPD 激发暗电流，须靠高保形 ALD 负电荷膜严密钝化 |
| **Full-Depth DTI（全贯通）** | 贯通全部 $3\,\mu\text{m}$ 硅厚直抵正面介质（或上下 DTI 对接） | 彻断全波段光子与电子串扰（NIR 及 $0.6\,\mu\text{m}$ 像素标配），高深宽比刻蚀均匀性挑战大 |

- **背金属网格（Backside Metal Grid）**：紧贴 B-DTI 顶部构建高度 $200\sim 400\text{ nm}$ 的 W/TiN 或低折射率 $\text{SiO}_2$ 芯包金属光学围栏，借助全反射将大角度斜射光线牢牢锁回本像素光敏区。

### （3）彩色滤光片（CFA）与微透镜（Microlens）光学精密成型
- **CFA 低温图案化**：旋涂含红/绿/蓝（Bayer RGGB / Quad-Bayer）有机颜料的负性感光胶，三次低温 i-line/KrF 光刻显影。全程烘焙严格卡死在 **$180\sim 220^\circ\text{C}$ 以下**避免染料漂白分解或脱气，并在像元间铺设光学防串色网格（Grid-in-CFA）。
- **热回流 vs 无间隙微透镜（Gapless Microlens）**：将方形透镜胶岛在 $150\sim 200^\circ\text{C}$ 下热回流成球冠；针对 $<0.8\,\mu\text{m}$ 像素，为消灭圆形球冠四角漏光死区，将回流阵列表面胶冠作为模板执行整面各向异性等离子体回刻（Etch-Back）转移轮廓至高折射率底涂层，使微透镜彼此零间隙紧密接壤。
- **主光线角度偏移（CRA Shift）**：镜头边缘主光线斜入射角高达 $25^\circ\sim 35^\circ$，光刻版图必须从芯片中心向边缘按径向渐进施加上百纳米偏移量，保证斜射聚光斑准确穿过滤光片命中光电二极管中心。

### （4）Cu-Cu 混合键合（DBI / Hybrid Bonding）精确窗口
```text
[Cu-Cu 混合键合理想凹陷与两大致命失效窗口]
  (a) 理想窗口 (Dishing: 2~5 nm)        (b) Cu 凸起 (Protrusion > 1 nm)        (c) 凹陷过深 (Dishing > 10 nm)
  ═══SiO2═══  ┌──Cu──┐  ═══SiO2═══       ═══SiO2═══ ┌───Cu───┐ ═══SiO2═══      ═══SiO2═══             ═══SiO2═══
  ──────────  └──────┘  ──────────       ────────── │        │ ──────────      ──────────  ┌──Cu──┐  ──────────
      ▲ 室温硅氧瞬间紧密贴合                 ▲ 顶开 SiO2 引发大面积空洞              ▲ 300°C 热膨胀仍够不到 → Open 断路
```
1. **CMP 轮廓控制**：顶层大马士革铜焊盘间距微缩至 $1\sim 3\,\mu\text{m}$，CMP 后必须保证介质粗糙度 **$R_q < 0.2\text{ nm}$** 且铜焊盘相对周围 $\text{SiO}_2/\text{SiCN}$ 微凹陷（Dishing）严控在 **$1\sim 5\text{ nm}$**。
2. **等离子体活化与室温预键合**：$\text{N}_2/\text{O}_2$ 等离子体活化并超纯水冲洗生成高密度亲水硅羟基（$-\text{Si}-\text{OH}$），在高精度对准键合机（Overlay $< 0.2\sim 0.4\,\mu\text{m}$）室温真空/超净贴合形成氢键吸合。
3. **低温热退火同步导通**：$250\sim 350^\circ\text{C}$ 退火使硅氧键脱水缩合（$\text{Si-OH}+\text{HO-Si} \to \text{Si-O-Si}+\text{H}_2\text{O}$）；同时利用 Cu（$16.5\text{ ppm/K}$）与 $\text{SiO}_2$（$0.5\text{ ppm/K}$）巨大的热膨胀差，铜焊盘受热向上膨胀补齐 $2\sim 5\text{ nm}$ 凹陷并互扩散导通（密度 $>10^5\sim 10^6\text{ /mm}^2$）。
4. **混合键合与 Backside TSV 的产线分工**：在三层堆叠 CIS 中，**Cu-Cu 混合键合**专门负责晶圆中心区域每像素或像素区块级的百万级超高密度信号直连；而外围大电流供电轨及对外输出焊盘（Bond Pad）的垂直引出，仍需在背面减薄后刻蚀深达数微米的 **背面硅通孔（Backside TSV）** 穿透介质与硅层接通底层焊盘。

### （5）CIS 晶圆级光电 CP 测试（Optical Prober）门控
与纯数字逻辑 CP 不同，CIS 晶圆需进驻配备精密积分球均匀光源与温控暗室的光学探针台执行筛选：
- **暗场测试（Dark Field）**：测定整片暗电流均值、高温白点（White Spot）数量分布及暗信号非均匀性（DSNU）；
- **平场光照测试（Flat Illumination）**：标定光响应非均匀性（PRNU）、满阱容量饱和曲线与坏点集群簇，将孤立可控坏点写入片内 OTP 存储器做硬件级坏点坐标补偿（DPC），若集群坏点超出模组厂容限则直接判废。

## 3. 整合失效排查（Troubleshooting）与光电 Split 矩阵

1. **Case 1：白点（White Pixels）与暗电流陡增**
   - **整合根因**：减薄机械微裂纹清除不彻或 Fe/Cu/Mo 重金属污染渗入 PPD 耗尽区；或 B-DTI 窄槽侧壁 RIE 损伤过重，ALD $\text{Al}_2\text{O}_3$ 钝化覆盖或激光退火能量不足。
   - **Split 与 FA**：设计背面激光退火能量（$\pm 15\%$）、ALD $\text{Al}_2\text{O}_3$ 膜厚及 B-DTI 前洗配比 Split；结合 **DLTS（深能级瞬态谱）** 鉴识重金属能级与 **TEM** 测量侧壁损伤层厚度。
2. **Case 2：RTS 随机电报闪烁噪声超标**
   - **整合根因**：像素内源极跟随器（SF）栅氧存在高密度界面陷阱（$D_{it}$），或氮化硅封帽氢含量不足未饱和界面悬挂键。
   - **Split 与 FA**：执行 SF 栅氧工艺 Split（纯热氧 vs 轻度氮化氧）、埋沟道 vs 表面沟道 SF 注入剂量与 FGA 退火时长对比，统计低频闪烁噪声尾端像素占比。
3. **Case 3：键合空洞（CSAM 超声扫描亮斑）**
   - **整合根因**：CMP 后残余哪怕一颗 $0.1\,\mu\text{m}$ 颗粒即可顶起数毫米未键合空洞；或低温氧化硅介质含 $\text{H}_2\text{O}/\text{H}_2$ 过多在 $300^\circ\text{C}$ 退火脱气鼓包。
   - **Split 与 FA**：全片运行 **CSAM（扫描声学显微镜）** 与纳米颗粒扫描；开展活化功率、兆声波清洗及介质去氢预退火（Pre-bond Degas）温度 Split。
4. **Case 4：边缘色彩阴影与色偏（Color Shading）**
   - **整合根因**：边缘像素 CRA 径向偏移失准、CFA 旋涂边缘厚度条纹（Striation），或 B-DTI 刻蚀中心-边缘深度不均引发边缘蓝红串扰。
   - **Split 与 FA**：沿芯片半径方向分段测定 R/G/B 量子效率光谱（QE Spectrum）；调整 CFA 旋涂加速度曲线与 B-DTI 边缘调谐环（Focus Ring）射频功率。
