# 04 · 工艺整合与节点演进 (`04_工艺整合与节点`)

> 单项工艺（Unit Process）关心“这一步膜长得好不好、孔刻得直不直”；**工艺整合（PIE, Process Integration Engineering）**关心“把 1000 步拼在一起，最终芯片的电学性能 $V_{th}/I_{on}/I_{off}$ 和良率能不能达标”。

## 目录内容
- `01_CMOS全流程串联/` —— FEOL / MOL / BEOL 完整制造链与重入式流片逻辑
- `02_逻辑制程节点演进/` —— 从 28nm HKMG 到 GAA、BSPDN 背面供电的演进
- `03_存储器制造全流程/` —— DRAM（1T1C/深圆柱电容）与 3D NAND（百层堆叠/HARC/阶梯）工艺流
- `04_特色与宽禁带工艺/` —— CIS 背照堆叠工艺、碳化硅（SiC）与氮化镓（GaN）功率工艺
- `05_前道与先进封装衔接/` —— 前道 Fab 与先进封装（TSV / RDL / Hybrid Bonding / CoWoS / HBM）衔接
