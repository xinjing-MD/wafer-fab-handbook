# 先进逻辑节点技术跃迁：HKMG → FinFET → GAA → BSPDN

- **所属模块**：`04_process_integration_and_nodes / 02_logic_node_evolution`

| 节点阶段 | 面临的核心物理卡点 | 标志性工艺革新 |
| :--- | :--- | :--- |
| **90nm ~ 45nm** | 硅载流子迁移率遇到瓶颈 | **应变硅（Strained Si）**：PMOS 源漏嵌入 SiGe 外延压应力；NMOS 覆盖张应力 CESL 氮化硅层 |
| **45nm / 32nm / 28nm** | 二氧化硅栅氧薄至 ~1.2nm，栅极直接隧穿漏电失控 | **HKMG（高 k 金属栅）+ Gate-Last（后栅替换工艺）**：$\text{HfO}_2$ 提高物理厚度同时维持等效电容（EOT）；先用多晶硅假栅承受高温源漏退火，再挖掉假栅填入功函数金属 |
| **22nm / 16nm / 14nm** | 平面器件短沟道效应与亚阈值漏电恶化 | **FinFET 立体鳍式晶体管** + **SADP/SAQP 自对准多重图形化**（绕过 193i 光学分辨率极限） |
| **7nm / 5nm** | 多重曝光掩模暴涨、套刻误差叠加、周期变长 | 引入 **EUV 极紫外光刻** 替代部分复杂 SAQP 层次，缩短周期并提升图形保真度 |
| **3nm / 2nm** | FinFET 底部漏电加剧、Fin 数量离散化限制设计灵活性 | **GAA（Nanosheet 全环绕纳米片）** + **内侧墙（Inner Spacer）** + 选择性 SiGe 刻蚀通道释放 |
| **2nm / A16 及以下** | 正面互连极其拥挤，电源线（Power Rail）与信号线抢空间导致严重 IR Drop 压降 | **BSPDN（背面供电网络）**：把供电网络转移到晶圆背面，通过纳米硅通孔（nTSV）直接喂电给晶体管源漏，释放正面布线密度 |
