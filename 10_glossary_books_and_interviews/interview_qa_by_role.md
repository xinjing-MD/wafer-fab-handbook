# 晶圆厂热门岗位笔试与面试高频问题库（参考框架）

## 1. 通用必考基础题（所有岗位通用）
1. 请简述从光片到一颗芯片出厂，前段（FEOL）、中段（MOL）、后段（BEOL）分别在做什么？温度限制为何不同？
2. 什么是“重入式制造（Re-entrant Flow）”？为什么晶圆厂瓶颈通常在光刻区？
3. 解释一下什么是 **Q-Time**？如果清洗后超过 Q-Time 才进下一步设备会发生什么？
4. 为什么光刻区要用黄色灯光？晶圆在厂内为什么要放进充氮的 FOUP？

---

## 2. 工艺整合（PIE）与单项工艺（PE）高频题
1. 瑞利公式中 $CD$ 和 $DOF$ 为什么存在天生矛盾？业界是如何绕开分辨率极限的？
2. 干法刻蚀中 **选择比（Selectivity）**、**各向异性（Anisotropy）** 和 **Loading Effect** 分别是什么？如何通过调整 Bias 功率/压力/气体比例来调优形貌？
3. 为什么先进栅介质要从 $\text{SiO}_2$ 换成 $\text{HfO}_2$ 并搭配金属栅（HKMG）？为什么又要分 Gate-First 和 Gate-Last？
4. 为什么铜不能像铝一样直接光刻后干法刻蚀，而要采用双大马士革（Dual Damascene）工艺？ECP 填孔中的三种添加剂分别起什么作用？
5. WAT 测什么，CP 测什么？如果在 CP Wafer Map 上看到“每间隔几个 Die 就周期性重复出现同一颗坏 Die”，你第一反应怀疑哪道工序？

## 3. 设备工程师（EE）与厂务（Facility）高频题
1. 描述一台 Cluster Tool 从 FOUP 放到 Load Port 到晶圆进 PM 腔室的完整机械路径；真空下为什么不能用普通真空吸盘吸晶圆（ESC 原理是什么）？
2. RF 匹配器（Matchbox）反射功率（Reflected Power）突然飙高可能是什么原因？
3. 晶圆厂中常见的 **Turbopump（分子泵）** 与 **Dry Pump（干泵）** 分别装在哪里、抽到什么真空度？
4. 遇到洁净室 **TGMS 毒气报警** 或 **HF 酸溅射**，标准应急处置原则是什么？

## 4. CIM / MES / 良率分析（YE）高频题
1. 简述 **MES、EAP、RTD、MCS、FDC、APC** 各自在晶圆厂软件栈中的角色与上下游关系。
2. 解释 SEMI **E84、E87、E90、E10** 标准分别管什么？
3. $C_p = 1.8$ 但 $C_{pk} = 0.7$ 说明了什么问题？工程上该怎么解决？
4. 如果某批产品良率突然掉到 60%，你在数据分析时按什么顺序排查（Lot/Wafer/Site/Tool/Chamber/Time/Recipe）？
