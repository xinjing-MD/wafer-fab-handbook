# 晶圆厂高频缩略语与中英对照词典（A–Z）

| 缩写 | 英文全称 | 中文解释 | 常见出现场景 |
| :--- | :--- | :--- | :--- |
| **ADI / AEI** | After-Development / After-Etch Inspection | 显影后检查 / 刻蚀后检查 | 光刻与刻蚀质量把关 |
| **ALD** | Atomic Layer Deposition | 原子层沉积 | HKMG、阻挡层、SAQP 侧墙 |
| **AMC** | Airborne Molecular Contamination | 空气分子级污染物 | 厂务过滤与光刻防 T-top |
| **AMHS** | Automated Material Handling System | 自动物料搬运系统 | 天车、Stocker 全厂物流 |
| **APC / R2R** | Advanced Process Control / Run-to-Run | 先进过程控制 / 批次间控制 | 光刻/刻蚀自动微调补偿 |
| **AR / HARC** | Aspect Ratio / High Aspect Ratio Contact | 深宽比 / 高深宽比接触孔刻蚀 | 3D NAND、DRAM 电容孔 |
| **BEOL** | Back-End-of-Line | 后道金属互连工艺 | 多层 Cu 互连、Low-k、CMP |
| **BSPDN** | Backside Power Delivery Network | 背面供电网络 | 2nm 及以下先进逻辑节点 |
| **CD / CD-SEM** | Critical Dimension / CD Scanning Electron Microscope | 关键尺寸 / 关键尺寸扫描电镜 | 线宽测量与控制 |
| **CDS** | Chemical Delivery System | 中央化学品输送系统 | 厂务向机台稳定供应酸碱液 |
| **CMP** | Chemical Mechanical Planarization | 化学机械平坦化 | STI、W、Cu、ILD 表面磨平 |
| **CP** | Chip Probing (Wafer Sort) | 晶圆针测 / 中测 | 扎针测试每一颗 Die 生成 Wafer Map |
| **D0** | Defect Density | 缺陷密度（单位 $\text{defects/cm}^2$） | 良率模型核心输入参数 |
| **DOF** | Depth of Focus | 焦深 | 光刻机能否在起伏表面清晰成像 |
| **DIBL** | Drain-Induced Barrier Lowering | 漏致势垒降低 | 短沟道晶体管漏电效应 |
| **E84 / E87** | SEMI E84 / SEMI E87 | 天车并行握手协议 / 载具管理标准 | OHT 与 Load Port 自动交接 |
| **EAP** | Equipment Automation Program | 设备自动化控制程序 | 连接 MES 与机台 SECS/GEM 的中间件 |
| **EFEM** | Equipment Front End Module | 设备前端模块 | 含机械手与对准台的洁净微环境区 |
| **EM** | Electromigration | 电迁移 | 大电流下金属原子漂移导致断线/空洞 |
| **EOT** | Equivalent Oxide Thickness | 等效氧化层厚度 | 衡量 High-k 栅介质电容控制能力 |
| **ESC** | Electrostatic Chuck | 静电吸盘 | 真空腔室固定并控温晶圆 |
| **EUV** | Extreme Ultraviolet (13.5nm) | 极紫外光刻 | 7nm 以下核心精细图形曝光 |
| **FA (EFA/PFA)** | Failure Analysis (Electrical / Physical) | 失效分析（电性定位 / 物理切片） | EMMI、OBIRCH、FIB、TEM |
| **FDC** | Fault Detection & Classification | 故障侦测与分类 | 机台传感器 Trace 实时报警 |
| **FEOL** | Front-End-of-Line | 前道晶体管制造工艺 | STI、阱、栅极、源漏 |
| **FFU** | Fan Filter Unit | 风机过滤单元 | 洁净室天花板垂直层流送风 |
| **FOUP** | Front Opening Unified Pod | 前开式晶圆传送盒（25 片） | 12 寸晶圆标准密闭载具 |
| **GAA** | Gate-All-Around | 全环绕栅极（纳米片晶体管） | 3nm/2nm 继 FinFET 后主流架构 |
| **HKMG** | High-k Metal Gate | 高介电常数金属栅 | 解决 $\text{SiO}_2$ 太薄漏电问题 |
| **LP (Load Port)** | Load Port | 机台前端装载口 | FOUP 停靠与自动开门位 |
| **MES** | Manufacturing Execution System | 制造执行系统 | 全厂账务、工艺路线与 Lot 控制 |
| **MFC** | Mass Flow Controller | 质量流量控制器 | 精准控制进腔气体流量 |
| **MOL / MEOL** | Middle-of-Line | 中段接触孔互连工艺 | 连接晶体管电极与 M1 |
| **MRR** | Material Removal Rate | 材料去除速率 | CMP 抛光与刻蚀速度指标 |
| **OEE** | Overall Equipment Effectiveness | 设备综合效率 | 稼动率 × 性能 × 良率 |
| **OHT** | Overhead Hoist Transport | 空中悬吊天车 | 头顶轨道自动搬运 FOUP |
| **OPC** | Optical Proximity Correction | 光学邻近修正 | 预先修改掩模图形补偿衍射畸变 |
| **OVL (Overlay)** | Overlay | 套刻对准精度 | 上下层电路图形的精确对齐度 |
| **PCW** | Process Cooling Water | 工艺冷却水 | 给机台腔体/电源/真空泵降温 |
| **PIE** | Process Integration Engineer | 工艺整合工程师 | 串联全流程并保证最终电学与良率 |
| **PM** | Process Module / Preventive Maintenance | 工艺反应腔 / 预防性保养 | 语境区分机台腔室或定期保养 |
| **Q-Time** | Queue Time | 队列等待时限 | 清洗/显影等工序间的最大允许等待时间 |
| **RCA Clean** | RCA Standard Clean (SC-1 / SC-2) | RCA 标准湿法清洗 | 去颗粒与去金属离子经典配方 |
| **RTD** | Real-Time Dispatching | 实时派工系统 | 决定下一秒天车把料送哪台机台 |
| **SAQP / SADP** | Self-Aligned Quadruple/Double Patterning | 自对准四重/双重图形化 | DUV 突破分辨率极限的多重曝光技巧 |
| **SECS/GEM** | SEMI Equipment Communications Standard | 半导体设备通信通用协议 | 机台联网自动化的通用语言 |
| **SPC** | Statistical Process Control | 统计过程控制 | 用控制图和 $C_{pk}$ 监控工艺稳定性 |
| **STI** | Shallow Trench Isolation | 浅沟槽隔离 | 防止相邻晶体管漏电串扰 |
| **TSV** | Through-Silicon Via | 硅通孔 | 穿透晶圆垂直连接，HBM 与 3D 封装核心 |
| **UPW** | Ultra-Pure Water | 超纯水 ($18.2\,\text{M}\Omega\cdot\text{cm}$) | 晶圆清洗生命线 |
| **WAT** | Wafer Acceptance Test | 晶圆允收电性测试 | 切割道标准晶体管电学参数测试 |
| **WIP** | Work In Progress | 在制品 | 当前正在晶圆厂内流转的晶圆批次 |
| **WPH / WSPM** | Wafers Per Hour / Wafer Starts Per Month | 每小时产能 / 月投片量 | 衡量机台吞吐与全厂产能 |
