## 1. PN 结能带弯曲、内建电场、击穿与两类电容

### （1）空间电荷区物理与内建电势 $V_{bi}$
当 P 型（受主浓度 $N_A$）与 N 型（施主浓度 $N_D$）半导体接触形成冶金结时，载流子在浓度梯度驱动下跨界扩散，在界面两侧留下不可移动的电离杂质核（P 侧带负电 $-qN_A$，N 侧带正电 $+qN_D$），形成指向 P 区的内建电场。热平衡状态下两侧费米能级 $E_F$ 齐平，导出**内建电势（Built-in Potential）**：
$$V_{bi} = \frac{k_B T}{q} \ln\left(\frac{N_A N_D}{n_i^2}\right)$$
- **典型数值与温漂**：$300\text{K}$ 下单晶硅突变结典型 $V_{bi} \approx 0.75\sim 0.95\,\text{V}$；由于本征浓度 $n_i$ 随温度急剧上升，$V_{bi}$ 约以 $-2\,\text{mV/K}$ 随温升下降。
- **单边突变结耗尽近似**（针对 CMOS 源漏重掺 $n^+$ 对轻掺 $p$ 衬底，$N_D \gg N_A$）：空间电荷区几乎全部分布在轻掺杂一侧：
  $$W_{dep}(V_A) \approx \sqrt{\frac{2\varepsilon_{Si}(V_{bi} - V_A)}{q N_A}}, \quad |\mathcal{E}_{max}| = \frac{2(V_{bi} - V_A)}{W_{dep}}$$
  （外加电压 $V_A$ 正偏取正、反偏取负）。

### （2）反向漏电与击穿物理极限
- **反偏漏电流两大组成**：
  1. 轻掺杂耗尽区内的热产生电流 $J_{gen} = \frac{q n_i W_{dep}}{2\tau_g}$（对少子寿命 $\tau_g$ 与温度极度敏感）；
  2. 中性区少子扩散电流 $J_{diff} \propto n_i^2$（高温下占比迅速反超）。
- **雪崩击穿 vs 齐纳/隧穿击穿**：
  - **雪崩击穿（Avalanche, $V_{BR} > 6 E_g/q \approx 6.7\,\text{V}$）**：宽耗尽区内高能载流子碰撞电离倍增，具**正温度系数**（温度升高晶格声子散射增强、加速自由程变短，击穿电压升高）；
  - **齐纳/带间隧穿击穿（Zener/BTBT, $V_{BR} < 4 E_g/q \approx 4.5\,\text{V}$）**：常见于重掺 Halo 与源漏交界超陡结，导带与价带横向间距极窄直接量子隧穿，具**负温度系数**（温升导致 $E_g$ 收缩，隧穿更易发生）。

### （3）势垒电容与扩散电容工程辨析

| 电容类型 | 物理本质与主导偏压区间 | 核心解析公式 | 产线工程影响与测试提取方法 |
| :--- | :--- | :--- | :--- |
| **势垒电容（耗尽电容 $C_j$）** | 反偏或微正偏下，耗尽层宽度 $W_{dep}$ 随交变小信号电压摆动而对边缘杂质电荷充放电 | $$C_j = \frac{\varepsilon_{Si} A}{W_{dep}} = A\sqrt{\frac{q \varepsilon_{Si} N_{eff}}{2(V_{bi} - V_A)}}$$ | 是源漏结寄生电容主体（影响电路速度与功耗 $CV^2f$）；通过绘制 **$1/C_j^2 - V_A$ 曲线斜率**可直接反推轻掺侧掺杂浓度剖面 $N(W)$ |
| **扩散电容（存储电容 $C_d$）** | 强正偏下，大量少子跨结注入中性区并在有效复合寿命 $\tau_{eff}$ 内建立动态过剩电荷 | $$C_d = \frac{dQ_{diff}}{dV_A} \approx \frac{\tau_{eff} q I_F}{k_B T}$$ | 随正向电流 $I_F$ 指数暴增（远超 $C_j$）；直接限制功率二极管与双极晶体管开关速度，引起关断时的**反向恢复时间 $t_{rr}$** |

> [!NOTE]
> 对于离子注入形成的缓变结（如线性缓变结），$C_j \propto (V_{bi}-V_A)^{-1/3}$；在先进平面/FinFET 中常通过 **SSRW（超陡倒掺杂阱）** 或 **SOI 埋氧接触隔离** 压低源漏底部的有效结面积与掺杂浓度，将 $C_j$ 降低 $50\%\sim 80\%$。

## 2. MOS 电容三大工作状态、能带图解与二阶退化

### （1）P 型衬底 MOS 三态能带弯曲示意图
```text
(1) 积累态 (Vg < Vfb)     (2) 耗尽态 (Vfb < Vg < Vth)    (3) 强反型 (Vg >= Vth)
金属   氧化层   P型硅       金属   氧化层   P型硅         金属   氧化层   P型硅
  |      / \      _ Ec       |      / \                   |      / \
  |     /   \    /           |     /   \   \____ Ec       |     /   \   \
  |----/     \--/--- EF      |    /     \   ---- EF       |    /     \   \_____ Ec
  |   /       \    Ei        |---/       \  \___ Ei       |   /       \  ------ EF (近 Ec)
  |  /         \___ Ev       |  /         \               |  /         \ \____ Ei
  |                          |             \____ Ev       | /           \
  + 表面聚集大量空穴          + 表面空穴排走形成 Wdep       + 表面 ψs = 2ψB 产生薄电子层
```

以 P 型衬底（受主浓度 $N_A$，体费米势 $\psi_B = \frac{k_B T}{q}\ln(N_A/n_i) > 0$）为例，计及栅极与衬底的功函数差 $\Phi_{MS}$ 及氧化层固定电荷 $Q_f$，**平带电压（Flatband Voltage）**为：
$$V_{FB} = \Phi_{MS} - \frac{Q_f}{C_{ox}} - \frac{1}{C_{ox}}\int_0^{t_{ox}} \frac{x}{t_{ox}}\rho_{ox}(x)\,dx$$

随栅压 $V_G$ 由负向正扫描，MOS 结构严格经过三大物理状态：
1. **积累态（Accumulation, $V_G < V_{FB}, \psi_s < 0$）**：
   - 栅极负压吸引衬底多子空穴堆积在 $\text{Si}-\text{SiO}_2$ 界面下方极薄层内；
   - 半导体表层串联电容极大，总电容逼近氧化层电容：
     $$C_{total} \approx C_{ox} = \frac{\varepsilon_{ox} A}{t_{ox}}$$
2. **耗尽态（Depletion, $V_{FB} < V_G < V_{th}, 0 < \psi_s < 2\psi_B$）**：
   - 栅极正压将空穴排斥推向体内，留下负电受主离子形成耗尽层 $W_{dep} = \sqrt{\frac{2\varepsilon_{Si}\psi_s}{q N_A}}$；
   - 耗尽层电容 $C_{dep} = \varepsilon_{Si}/W_{dep}$ 与氧化层电容串联，总电容随 $V_G$ 增加单调滑落：
     $$C_{total} = \frac{C_{ox} C_{dep}}{C_{ox} + C_{dep}} = \frac{C_{ox}}{\sqrt{1 + \frac{2\varepsilon_{ox}^2 (V_G - V_{FB})}{q \varepsilon_{Si} N_A t_{ox}^2}}}$$
3. **反型态（Inversion, $V_G \ge V_{th}, \psi_s \ge 2\psi_B$）**：
   - 表面势达到强反型判据 $\psi_s = 2\psi_B$（界面电子浓度反超体内空穴浓度 $N_A$）后，表面势被反型电荷的指数响应近乎钉扎，耗尽层到达最大饱和宽度：
     $$W_{dep,max} = \sqrt{\frac{4\varepsilon_{Si} \psi_B}{q N_A}} = \sqrt{\frac{4\varepsilon_{Si} k_B T \ln(N_A/n_i)}{q^2 N_A}}$$
   - 由此导出长沟道理想**阈值电压方程**与**体效应（Body Effect）系数 $\gamma$**：
     $$V_{th} = V_{FB} + 2\psi_B + \frac{\sqrt{4\varepsilon_{Si} q N_A \psi_B}}{C_{ox}} + \gamma\left(\sqrt{2\psi_B + V_{SB}} - \sqrt{2\psi_B}\right), \quad \gamma = \frac{\sqrt{2\varepsilon_{Si} q N_A}}{C_{ox}}$$

### （2）金属栅功函数工程与费米能级钉扎（Fermi-Level Pinning）
- 传统 CMOS 使用 $n^+$ 多晶硅做 NMOS 栅极（功函数 $\Phi_m \approx 4.05\,\text{eV}$ 对齐导带底）、$p^+$ 多晶硅做 PMOS 栅极（$\Phi_m \approx 5.17\,\text{eV}$ 对齐价带顶），以对称调整 $\Phi_{MS}$ 实现低绝对值 $V_{th}$；
- 引入 HKMG 后，金属（如 TiN/TiAlC）直接接触 $\text{HfO}_2$ 时，高 k 界面氧空位电荷与金属诱导隙态（MIGS）会产生**费米能级钉扎效应**，将金属有效功函数（eWF）顽固地拉向硅禁带中央（约 $4.6\,\text{eV}$），导致器件 $V_{th}$ 过高；
- 产线需采用**功函数金属叠层（WFM）**及**极薄氧化镧（$\text{La}_2\text{O}_3$）/氧化铝（$\text{Al}_2\text{O}_3$）偶极子工程**在界面引入偶极势降 $\Delta V_{dipole}$ 以精确拉正 $V_{FB}$。

### （3）先进节点两大致命二阶电容退化（EOT vs CET）
当物理栅介质缩减至 $< 2\,\text{nm}$ 时，实测反型电容 $C_{inv}$ 对应的**等效电学电容厚度 CET** 明显大于物理等效厚度 **EOT**：
$$\text{CET} = \text{EOT} + \Delta_{poly} + \Delta_{QM}$$
- **多晶硅耗尽效应（$\Delta_{poly} \approx 0.3\sim 0.5\,\text{nm}$）**：多晶硅掺杂活性上限（$\sim 10^{20}\,\text{cm}^{-3}$）使其栅极界面表层在强反型时也形成耗尽区，相当于串联损失电容——成为必须淘汰多晶硅转用自由电子密度百倍高的金属栅的核心物理动因。
- **量子力学限域效应（$\Delta_{QM} \approx 0.3\sim 0.4\,\text{nm}$）**：电子波函数在介质界面势垒处归零，反型电荷密度重心向硅体内部退缩约 $1.0\sim 1.5\,\text{nm}$（即“暗区”效应），等效串联量子电容 $C_{QM}$。

## 3. 高频、低频、深耗尽 C-V 特性及 WAT 参数提取

在晶圆厂 WAT 机台测试 C-V 时，对栅极施加直流扫描偏压 $V_G$ 并叠加交流小信号（典型振幅 $15\sim 50\,\text{mV}$），不同测试速率与频率呈现四种经典行为：

```text
C / Cox
 1.0 |========\                           /---------- (低频准静态 <100Hz 或真实 MOSFET Cgs)
     |         \                         /
Cfb  |----------*                       /
     |           \                     /
Cmin |            \-------------------/-------------- (高频 100kHz~1MHz 稳态: 少子热产生跟不上)
     |             \                 \
     |              \                 \-------------- (深耗尽 Deep Depletion: 快速脉冲扫描)
     +-----------------------------------------------> Vg
          积累区       耗尽区       反型区
        (Vg < Vfb)               (Vg > Vth)
```

### （1）四类扫描模式物理机制对比
1. **高频稳态曲线（$100\,\text{kHz}\sim 1\,\text{MHz}$）**：交流周期（$1\,\mu\text{s}$）远快于体相少子的热产生-复合弛豫时间（$\tau_g \sim 10^{-5}\sim 10^{-3}\,\text{s}$）。反型电子无法随小信号高频增减，交流电荷增量由耗尽层边界 $W_{dep,max}$ 的多子空穴承担，反型区电容停留在最低谷 $C_{min} = \frac{C_{ox} C_{dep,min}}{C_{ox} + C_{dep,min}}$。
2. **低频/准静态曲线（$< 100\,\text{Hz}$ 或积分慢斜坡法）**：变化极慢，少子有充足时间热产生进出反型层，极薄反型层直接屏蔽交流信号，电容快速回升至 $C_{ox}$。
3. **真实 MOSFET（Split C-V, $C_{gc}$）的特殊行为**：源漏接地的 4 端 MOSFET 拥有海量储备电子的 $n^+$ 源漏区，可在皮秒尺度直接向沟道注入/抽离电子，因此**即使在 $1\,\text{MHz}$ 高频下，MOSFET 强反型区电容仍会回升至 $C_{ox}$**。
4. **深耗尽瞬态（Deep Depletion & Zerbst $C-t$ 法）**：施加极快正阶跃脉冲时，少子完全来不及生成，耗尽层向硅体内继续扩张突破 $W_{dep,max}$ 致使电容持续跌破 $C_{min}$；随后监测维持恒压下电容回升至 $C_{min}$ 的暂态弛豫斜率：
   $$\frac{d}{dt}\left(\frac{C_{ox}}{C(t)}\right)^2 \propto \frac{1}{\tau_g}$$
   通过 **Zerbst 图分析**可直接提取硅外延层**少子产生寿命 $\tau_g$** 与**表面产生速率 $s_0$**（对铁铜金属污染极度敏感）。

### （2）WAT 标准参数提取与寄生修正链路
- **实测串联电阻与漏电校正（Yang-Hu 双频法）**：
  当 EOT $< 1.2\,\text{nm}$ 时，并联栅极隧穿电导 $G_p$ 与衬底接触串联电阻 $R_s$ 会严重污染实测电容 $C_m$。首先须进行探针台 **Open / Short 开短路寄生去嵌**，再联合双频（如 $f_1 = 100\,\text{kHz}, f_2 = 1\,\text{MHz}$）实测导纳剥离出真实无损氧化层电容：
  $$C_{ox,true} = \frac{f_1^2 C_{m1}(1 + D_1^2) - f_2^2 C_{m2}(1 + D_2^2)}{f_1^2 - f_2^2} \quad \left(D = \frac{G_m}{\omega C_m}\right)$$
- **平带电压与固定电荷**：由体掺杂 $N_A$ 计算德拜长度 $L_D = \sqrt{\frac{\varepsilon_{Si} k_B T}{q^2 N_A}}$ 及平带半导体电容 $C_{FBS} = \frac{\varepsilon_{Si} A}{L_D}$，定位 $C_{FB} = \frac{C_{ox} C_{FBS}}{C_{ox} + C_{FBS}}$ 在高频曲线上对应横坐标即为 $V_{FB}$，反推 $Q_f$。
- **界面态密度 $D_{it}$**：通过 **Castagné-Vapaille 高低频结合法**提取能量分布：
  $$D_{it} = \frac{C_{ox}}{q A}\left(\frac{C_{LF}/C_{ox}}{1 - C_{LF}/C_{ox}} - \frac{C_{HF}/C_{ox}}{1 - C_{HF}/C_{ox}}\right)$$
  先进 HKMG 要求禁带中央 $D_{it}$ 压制在 $< 1\sim 5 \times 10^{10}\,\text{cm}^{-2}\text{eV}^{-1}$；精细排查常采用灵敏度更高的**交流电导法（$G_p/\omega$ 峰拟合）**。
- **Split C-V 提取有效迁移率**：在 MOSFET 上同步测量 $C_{gc}(V_G)$ 积分得到准确反型层电荷 $Q_{inv}(V_G) = \int_{-\infty}^{V_G} C_{gc}\,dV_G$，再结合极低漏压（如 $V_{DS}=50\,\text{mV}$）下的 $I_D$ 反推本征有效迁移率：
  $$\mu_{eff} = \frac{L_{eff}}{W_{eff}}\cdot\frac{I_D}{V_{DS} Q_{inv}(V_G)}$$

### （3）产线测试结构选型：MOSCAP C-V vs Split C-V 对比

| 测试架构 | 测试图形尺寸与层级 | 强反型响应高频极限 | 核心提取参数与工程优缺点 |
| :--- | :--- | :--- | :--- |
| **传统二端 MOSCAP** | 大面积方阵（典型 $50\times 50\sim 100\times 100\,\mu\text{m}^2$），Poly/Metal 层即可测试 | 仅能测低频/高频单侧，靠热产生响应 | **优点**：工艺周期短（前道 FEOL 后即可监控栅氧质量）、串联电阻校准直观，适合提取 $C_{ox}, V_{FB}, Q_f, D_{it}$ 与 $\tau_g$<br>**缺点**：无法直接提取工作沟道有效迁移率 |
| **四端 MOSFET Split C-V** | 大长宽比晶体管阵（如 $W/L = 10\times 10\,\mu\text{m}$ 或多指并联），须过接触孔后测试 | 即使 $1\,\text{MHz}$ 以上高频仍完全响应至 $C_{ox}$ | **优点**：直接分离栅沟道电容 $C_{gc}$ 与栅衬底电容 $C_{gb}$，无需掺杂假设即可精准提取反型电荷与沟道迁移率 $\mu_{eff}$<br>**缺点**：需完整源漏及接触金属化，寄生重叠电容 $C_{ov}$ 去嵌难度较大 |

## 4. 产线 C-V 曲线异常诊断、TDDB 关联与案例排查

| 实测 C-V 曲线异常特征 | 核心物理失效机理 | 晶圆厂高概率对应根因与排查工序 |
| :--- | :--- | :--- |
| **整体沿电压轴负向/正向平移（$\Delta V_{FB}$ 漂移）** | **固定正电荷 $Q_f$**、**可动离子（$\text{Na}^+, \text{K}^+$）** 或界面偶极子失配 | 1. 核查高温氧化炉石英管、洗净药液碱金属沾污（用 **BTS 偏压温度应力测试**确认是否随热电场可逆漂移）<br>2. 排查 HKMG 中 $\text{La}_2\text{O}_3/\text{Al}_2\text{O}_3$ 偶极子层退火热预算偏差 |
| **耗尽区斜率平缓拉伸畸变（Stretch-out）** | **界面态密度 $D_{it}$ 过高**：界面陷阱电荷随表面势充放电削弱了栅压调控耗尽层的能力 | 1. 检查成型气退火（**FGA, $\text{N}_2/\text{H}_2$ $400\sim 450^\circ\text{C}$**）氢钝化时间/浓度是否不足<br>2. 排查干法刻蚀与注离子引起的等离子体损伤（PID） |
| **正反扫描出现迟滞回线（Hysteresis）** | **氧化层体相/边界慢陷阱电荷充放电**（注：顺时针回线源于衬底向陷阱注入电子；逆时针多源自栅极注入或可动离子/铁电极化） | 1. 检查 ALD $\text{HfO}_2$ 前驱体（如 $\text{HfCl}_4$ / 有机胺）碳氯残留与氧空位 $V_O$ 密度<br>2. 核查后沉积退火（PDA）温度或氨气/氧气致密化气氛 |
| **积累区电容突然向下滚降（Hook / Roll-down）** | 栅介质直接隧穿漏电 $G_p$ 暴增或测试背接触串联电阻 $R_s$ 过大导致测量相位角失真 | 检查硅片背面氧化层是否剥除彻底、探针台 Chuck 接触阻值；开启多频校正测试或复测介质物理厚度 |
| **高频强反型电容异常抬升（Fake Low-Freq）** | 测试暗箱未密封漏光、或 MOSCAP 周边外围存在正电荷诱发反型通道连通周边扩散区 | 检查机台暗箱门微动开关；核对测试结构外围 Guard Ring 环偏压是否有效关断边缘反型层 |
| **耗尽-反型斜率变缓且 $C_{min}$ 明显偏高** | 实际近表层有效掺杂浓度 $N_A$ 显著高于工艺设计目标 | 排查 $V_{th}$ 调整离子注入剂量偏差，或前道热过程触发瞬态扩散改变沟道纵向分布 |

### 工程实战案例：HKMG $V_{th}$ 偏高与 TDDB 早期失效联动定位
- **异常现象**：新批次 WAT 报警 NMOS $V_{th}$ 偏高 $+80\,\text{mV}$ 且强反型 CET 较目标偏厚 $+0.15\,\text{nm}$。
- **C-V 剥离排查思路**：
  1. 对比高频与低频曲线斜率基本重合无 Stretch-out，排除 $D_{it}$ 界面态恶化（排除 FGA 问题）；
  2. 测量平带电压 $V_{FB}$ 正偏 $+70\,\text{mV}$，且积累区最大电容 $C_{ox}$ 明显下降而反型区无明显额外多晶硅耗尽肩峰；
  3. **根因锁死**：确定并非金属功函数金属（WFM）填错，而是 **界面氧化层 IL 在前清洗后自然氧化超长延时（Queue Time 超标）或 PDA 退火氧化气氛偏重导致 IL 多长了约 $0.15\,\text{nm}$**，同时增厚了 EOT 并改变了界面氧空位偶极平衡；
  4. **TDDB 预警关联**：在施加恒压应力（CVS）前后对比低频 C-V 积分畸变量与应力诱生漏电（SILC），可无损追踪介质体内陷阱生成速率，严防渗透击穿路径提前形成导致 10 年服役寿命违例。
