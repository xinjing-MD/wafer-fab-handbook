## 1. 三大核心存储器架构物理对比与 Fab 极限突破

芯片中的存储器（DRAM、3D NAND）与片内高速缓存（SRAM）遵循截然不同的制造与微缩哲学：先进逻辑追求单个晶体管的极限开关速度与最小动态功耗，而大容量存储器追求**在每平方微米（或等效 $F^2$ 特征面积）内塞入极限比特密度、超低单位漏电以保持电荷态，以及严格控制相邻存储单元间的电学串扰**。

| 存储类型 | 存储单元与物理核心机理 | 易失性 | 典型单元面积 | Fab 制造最关键瓶颈与当代架构演进 |
| :--- | :--- | :---: | :---: | :--- |
| **SRAM** | **6T**（2 上拉 PMOS + 2 下拉 NMOS + 2 传输门 NMOS 组成双稳态锁存器） | 易失 | `120~150 F²`<br>（随逻辑节点演进） | **Pelgrom 定律导致的阈值电压失配**（$\sigma(\Delta V_{th}) \propto 1/\sqrt{WL}$）与 Fin/Sheet 量化制约，致使 N5 $\to$ N3 节点 SRAM 微缩几乎停滞，亟需依赖读写辅助电路与 GAA/CFET 破局 |
| **DRAM** | **1T1C**（1 个低漏电访问管 + 1 个深槽/柱状超高 k 电容存储电荷状态） | 易失<br>（典型 64ms 刷新） | `6F²` 主流<br>向 `4F²` VCAT 与 3D 演进 | **超高深宽比电容孔刻蚀（AR > 50:1）与防倒塌支撑网**；**ZAZ 高 k 介质漏电抑制**；**埋入式字线（BCAT/Saddle-Fin）** 抑制访问管 GIDL 漏电保刷新周期 $t_{REF}$ |
| **3D NAND** | 垂直多晶硅沟道穿过上百层字线，靠 **FN 量子隧穿** 向 **ONO 电荷俘获层** 注入电子 | 非易失<br>（断电保持 > 10 年） | 等效 `< 1F²`<br>（靠垂直百层平摊） | **100~300+ 层 ONON 交替叠层应力与晶圆翘曲控制**；**超深通道孔低温刻蚀（HARC, Cryo-etch）**；阶梯接触与 **String Stacking / 双晶圆混合键合** |

### （1）SRAM：6T 稳定度物理博弈与先进节点微缩停滞根因
```text
       VDD                  VDD
        |                    |
     [PU1]                [PU2]  (上拉 PMOS)
        |------ Q   Qb ------|
  WL ---+-[PG1]       [PG2]--+--- WL  (传输门 NMOS)
  |     |                    |     |
 BL  [PD1]                [PD2]   BLB (下拉 NMOS)
        |                    |
       GND                  GND
```
- **稳定性（SNM）与晶体管强弱比约束**：6T SRAM 在读写过程中绝不能发生存储节点电位误翻转，其稳定性由**静态噪声容限（SNM，蝴蝶曲线最大内切正方形边长）**表征：
  1. **读稳定性（Read Stability）**：下拉管必须明显强于传输门，即 **单元比（Cell Ratio, $\beta = W_{PD}/W_{PG}$ 典型 $\ge 1.2\sim 1.5$）**，防止读操作开启传输门时“0”节点被位线电荷拉高翻转；
  2. **写能力（Write Margin）**：传输门必须强于上拉 PMOS，即 **上拉比（Pull-up Ratio, $\gamma = W_{PU}/W_{PG} < 1$）**，确保写操作能干脆拉低“1”节点电位。
- **为什么 N5 到 N3 SRAM 面积难再缩小？**
  - 根据 **Pelgrom 随机失配定律**，相邻晶体管阈值电压失配标准差满足：
    $$\sigma(\Delta V_{th}) = \frac{A_{Vt}}{\sqrt{W_{eff} L_{eff}}}$$
  - 当单元面积逼近极限，RDF（随机掺杂涨落）、功函数金属晶粒涨落（MGG）与线边缘粗糙度（LER）造成的 $\Delta V_{th}$ 剧增直接击穿低电压下的 SNM 容限。
  - 加之 FinFET 高密度版图（HD 1-1-1 构型）已将 PD/PG/PU 全压到只剩 1 个 Fin，失去了调节宽长比的空间，迫使电路必须借助字线欠压（WLUD）与负位线（NBL）读写辅助，最终须依靠 GAA 连续调宽（单独加宽 PD 纳米片）和 CFET 垂直叠层才能重拾微缩曲线。

### （2）DRAM：1T1C 电荷分享极限、6F² 布局与极低漏电访问管
```text
DRAM 1T1C 纵剖面结构示意:
   [ 位线接触 BL ]        [ 高深宽比圆柱电容 Cs (AR > 50:1) ]
         |                   |  TiN / ZAZ / TiN  | <-- 氮化硅支撑网防倒塌
   ------+-------        ----+-------------------+----
     n+  |  n+    <-- 访问管   [ 存储节点接触 SN ]
   ======U======= <-- 埋入式字线 BCAT (Saddle-Fin 槽型延长沟道降 GIDL)
      P-Well 衬底
```
- **破坏性读取物理约束**：DRAM 读取时字线打开，存储电容 $C_s$ 与寄生极高的长位线电容 $C_{BL}$ 发生电荷分享，感测放大器能获得的微弱电压信号摆幅为：
  $$\Delta V_{BL} = \frac{C_s}{C_s + C_{BL}} \left(V_{cell} - \frac{V_{DD}}{2}\right)$$
  随制程向 $1\alpha / 1\beta / 1\gamma$（10nm 级节点）微缩，尽管芯片平面投影面积锐减，但为了盖过感测放大器噪声并抵抗高能粒子软错误，单颗电容容量 $C_s$ 依然必须死守 **$10\sim 20\,\text{fF}$**（甚至更严苛节点至少 $6\sim 10\,\text{fF}$）底线。
- **Fab 两大极致制造模块**：
  1. **超高深宽比圆柱电容与 ZAZ 叠层**：
     - 在 $6F^2$ 紧密斜向布局中（字线节距 $2F \times$ 位线节距 $3F$），只能把电容做得极细极高（深宽比 AR $> 40\sim 60:1$）；
     - 为防脱模刻蚀后电容柱集群倾倒短路，需在高度方向植入两至三层**氮化硅支撑网（Mesh Supporter）**；
     - 电容介质采用 **ZAZ（$\text{ZrO}_2/\text{Al}_2\text{O}_3/\text{ZrO}_2$）** 超薄高 k 叠层 ALD 沉积：借 $\text{ZrO}_2$ 极高 $k \approx 35\sim 40$ 提容，中间嵌入高带隙 $\text{Al}_2\text{O}_3$ 打断多晶晶界阻绝电子隧穿漏电。
  2. **埋入式字线访问管（BCAT / Saddle-Fin）**：
     - 将 TiN/W 字线金属埋进硅槽表面以下做成马鞍形三维包裹结构，有效沟道长度绕弯拉长一倍以上，极大抑制了短沟道与**栅感应漏极漏电（GIDL）**；
     - 降低了字线与位线插头之间的耦合寄生电容，确保在 $85^\circ\text{C}\sim 95^\circ\text{C}$ 工作温度下电荷完整保持 **$64\,\text{ms}$** 刷新周期以上。
- **下一代演进**：突破 $6F^2$ 的核心方向是将晶体管完全直立化实现 **$4F^2$ VCAT（垂直沟道晶体管）**（位线藏底、电容立顶），以及探索采用超低漏电氧化物半导体（如 **IGZO 无结沟道**）构建真正多层立体 3D DRAM；在系统端则与高带宽内存（**HBM 3D TSV 堆栈 + Logic Base Die**）深度结合打破“内存墙”。

### （3）3D NAND：垂直电荷俘获（CTF）与超高深宽比低温刻蚀
```text
3D NAND 垂直通道孔截面 (横切单层字线):
  [ 核心填充 Oxide ] | [ 多晶硅环状沟道 ] | [ 隧穿 SiO2 ] | [ 俘获 Si3N4 ] | [ 阻挡 Al2O3 ] | [ W / Mo 字线 ]
       (Macaroni 极薄空心多晶硅沟道抑制晶界涨落)            <-- 电子 FN 隧穿锁入 Si3N4 深陷阱
```
2D 平面浮栅在 15nm 处因浮栅间强电容耦合串扰与单单元电子少于 20 个而彻底停滞。3D NAND 通过向垂直 Z 轴堆叠上百至三百余层实现比特容量指数爆发：
- **为什么电荷俘获层（CTF）淘汰了多晶硅浮栅（FG）？**
  CTF 采用绝缘的 **ONO 叠层**（阻挡层 $\text{Al}_2\text{O}_3/\text{SiO}_2$ — 电荷俘获氮化硅 $\text{Si}_3\text{N}_4$ — 隧穿层 $\text{SiO}_2$），利用 $18\sim 22\,\text{V}$ 高压诱发 **FN 量子隧穿** 将电子锁定在氮化硅局域深陷阱中。因为电荷被局域囚禁而不互通，即使隧穿氧化层存在单点针孔缺陷也不会瞬间放空整个存储单元，抗邻道横向干扰极强且通道孔结构更加紧凑。
- **当前主流 Replacement Gate（ONON $\to$ 钨/钼字线置换）四大产线极限**：
  1. **多层交替膜应力与晶圆翘曲（Warpage）**：连续生长 $200\sim 300+$ 层 $\text{SiO}_2/\text{Si}_3\text{N}_4$ 总厚度高达 $10\sim 15\,\mu\text{m}$，巨大的内应力会导致 300mm 晶圆弯曲数百微米直接无法通过光刻机吸盘！产线必须依靠背面沉积相反内应力的氮化硅补偿膜及工艺调温平衡应力。
  2. **超高深宽比通道孔刻蚀（HARC, AR $> 60\sim 80:1$）**：直径不足 $100\,\text{nm}$、深逾 $10\,\mu\text{m}$ 的通道圆孔必须一竿子打到底且保持垂直。最新先进节点普遍引入**低温刻蚀（Cryogenic Etch, $-60^\circ\text{C}$ 以下）**：利用低温下 $\text{HF}$ 等活性氟化物在孔底与孔壁吸附动力学的巨大差异，在极高刻蚀速率下完美消除侧壁鼓肚（Bowing）、孔道扭曲（Twisting）与底部闭合失效。
  3. **多晶硅沟道与阶梯引出（Staircase）**：在孔壁形成环形极薄无晶界干扰的多晶硅空心沟道（Macaroni 结构），在边缘通过数十步“光刻胶逐层修剪 + 刻蚀（Trim-and-Etch）”打造供各层字线插针引出的立体阶梯接触阵列。
  4. **分体制造与混合键合（CUA $\to$ Xtacking / CBA）**：为避免高温字线置换与沟道结晶退火（$> 900^\circ\text{C}$）损毁性能敏感的外围高速 CMOS 逻辑译码器，业界前沿已从阵列下置 CMOS（CUA）升级为将**存储阵列晶圆与外围逻辑晶圆分别独立优化制造，再经亚微米 Cu-Cu 混合键合面对面合体**。
- **3D NAND 固有电荷失稳痛点**：在 TLC/QLC 多比特存储中，受限于紧邻层间电荷在氮化硅连续薄膜内的**横向扩散漂移（Lateral Charge Migration）**以及读取未选中页施加高通过电压造成的**读干扰（Read Disturb）**，极易在高温长期存储后出现阈值分布（$V_{th}$ Distribution）展宽报错。

## 2. 特色工艺器件（Specialty）：CIS 图像传感器与宽禁带功率半导体

### （1）CIS（CMOS Image Sensor）光电物理与 3D 混合键合演进
```text
Stacked BSI CIS 纵剖面 (光线从背面直接射入):
      ↓↓↓  入射光子 (Photon)  ↓↓↓
   [ 微透镜 Microlens ] + [ 彩色滤光片 CFA ]
   ==========================================
   |  BDTI  |   背面减薄 P-Epi (2~6 μm)  |  BDTI  | <-- BDTI 侧壁覆负电荷 Al2O3/HfO2 阻绝串扰与暗电流
   | 深隔离 |     [ 钳位光电二极管 PPD ]  | 深隔离 |
   +--------+---[ TG ]---[ FD ]----------+--------+
               正面 BEOL 金属互联层
   ==========================================  <-- 亚微米 Cu-Cu Hybrid Bonding 混合键合界面
           先进逻辑 ISP / AI / DRAM 晶圆
```
- **4T 钳位光电二极管（4T-PPD）架构**：在传统 3T 像素基础上引入传输门（Transfer Gate），将光生电子从埋入硅表的钳位光电二极管彻底抽空至浮置扩散节点（FD），结合片上 **相关双采样（CDS）** 电路彻底消除了像素复位热噪声（$kTC$ 噪声），赋予现代手机与相机极高动态范围与近乎零读出噪底。
- **硅波长吸收物理与结构演进（FSI $\to$ BSI $\to$ 3D Stacked）**：
  硅对不同光谱的穿透吸收深度相差极大：蓝光（$450\,\text{nm}$）在表面 $0.4\,\mu\text{m}$ 内几乎全被吸收，红光（$650\,\text{nm}$）深入约 $3\,\mu\text{m}$，而近红外（$940\,\text{nm}$）可穿透 $> 10\,\mu\text{m}$。
  1. 早期**前照式（FSI）**光线必须穿过多层金属互联深井，微缩至亚微米像素时遮光与光学串扰极为严重；
  2. **背照式（BSI）**将传感片倒扣键合到支撑片后，从背面研磨+CMP+湿法精减薄硅片至仅 **$2\sim 6\,\mu\text{m}$**，光从无金属阻挡的背面直入光电二极管，量子效率（QE）大幅攀升；
  3. **堆叠式 CIS（Stacked CIS）**：将像素晶圆与先进节点（如 22nm/14nm）制造的 ISP/AI 算力逻辑晶圆（甚至中夹 DRAM 帧缓存晶圆）通过高密度 **Cu-Cu Hybrid Bonding（节距仅 $1\,\mu\text{m}$ 量级）**垂直互通，彻底释放像素有效感光占比并解锁高速全局快门（Global Shutter）。
- **CIS Fab 核心卡控痛点**：
  - **背面深沟槽隔离（BDTI）**：刻蚀贯穿微米级硅层的极窄深槽隔离像素间光学/电子串扰，随后 ALD 涂覆自带强负固定电荷的高 k 介质（**$\text{Al}_2\text{O}_3/\text{HfO}_2$**），在硅侧壁感应出高浓度空穴积累层完美钝化刻蚀悬挂键；
  - **苛刻级金属洁净度**：Fe、Cu、Ni 等重金属一旦扩散入感光区形成 SRH 深能级，即使全黑环境也会不断热产生暗电流形成刺眼的**白点（White Pixel）**——CIS 线对表面金属沾污管控（常 $< 10^8\sim 10^9\,\text{atoms/cm}^2$）甚至比先进逻辑产线更为敏感严苛。

### （2）第三代宽禁带功率半导体（4H-SiC & GaN-on-Si）
传统硅功率器件在高压、高频应用中受制于窄带隙与较低的临界击穿场强（$E_c \approx 0.3\,\text{MV/cm}$）。表征单极功率开关器件极限导通损耗能力的**巴利加优值（Baliga's Figure of Merit）**揭示导通比电阻反比于击穿场强的立方：
$$\text{BFOM} = \varepsilon_s \mu E_c^3, \quad R_{on,sp} \propto \frac{V_B^2}{\varepsilon_s \mu E_c^3}$$

| 关键材料与制造维度 | 硅（Si） | 碳化硅（4H-SiC） | 氮化镓（GaN-on-Si） |
| :--- | :--- | :--- | :--- |
| **禁带宽度 $E_g$ / 临界场强 $E_c$** | $1.12\,\text{eV}$ / $0.3\,\text{MV/cm}$ | **$3.26\,\text{eV}$** / **$2.5\sim 3.0\,\text{MV/cm}$** | **$3.40\,\text{eV}$** / **$3.3\,\text{MV/cm}$** |
| **热导率 $\kappa$** | $1.5\,\text{W/(cm}\cdot\text{K)}$ | **极高 $3.7\sim 4.9\,\text{W/(cm}\cdot\text{K)}$** | $1.3\sim 2.0\,\text{W/(cm}\cdot\text{K)}$（受 Si 衬底限制） |
| **主流结构与电压甜点** | 垂直超结 MOS / IGBT（600V~6500V） | **垂直沟槽/平面 MOSFET**（650V~3300V，主攻 **800V 新能源汽车主驱逆变器**） | **横向 HEMT**（利用 AlGaN/GaN 极化形成高速 2DEG 沟道；主攻 100V~650V 快充/数据中心高频供电） |
| **衬底生长与规格** | CZ/FZ 单晶（200/300mm 高度成熟） | **PVT 物理气相传输升华法**（$2100\sim 2300^\circ\text{C}$ 慢速长晶，150mm $\to$ **200mm** 演进） | 异质外延于 **150/200mm Si(111) 衬底**（生长数微米 AlN/渐变 AlGaN 缓冲层吸收 $14\%$ 晶格失配防开裂） |

#### SiC 与 GaN 产线制造核心壁垒与典型失效深度拆解
- **4H-SiC 产线四大独特工艺难题**：
  1. **超硬脆切磨抛与半透明传片**：莫氏硬度高达 9.2，金刚石线锯切耗时达硅的数倍且 CMP 速率极低；同时 SiC 晶圆在可见光波段呈半透明状，必须改造前道机械手及定位仪的光学传感器波长或使用物理遮挡标定。
  2. **热扩散极慢迫使高温注入与碳膜退火**：Al/N 等杂质在 SiC 中几乎无法热扩散，因此必须在 **$400\sim 600^\circ\text{C}$ 高温下离子注入**防止晶格不可逆非晶化，随后涂覆保护性**石墨碳膜（Carbon Cap）并在 $1600\sim 1750^\circ\text{C}$ 超高温激活退火**，防止表层硅原子优先挥发诱发严重的**台阶聚束（Step Bunching）**表面破坏。
  3. **$\text{SiC}-\text{SiO}_2$ 界面碳团簇钝化**：直接热氧化会在界面残留高密度碳团簇使 $D_{it}$ 比硅高 1~2 个数量级、沟道迁移率被拉低至仅 $20\sim 50\,\text{cm}^2/(\text{V}\cdot\text{s})$，产线必须辅以 **$\text{NO}$ / $\text{N}_2\text{O}$ 高温氮化退火**钝化界面碳键。
  4. **双极退化失效（Bipolar Degradation）**：体二极管正偏导通时电子-空穴复合释放的 $3.26\,\text{eV}$ 能量会驱动**基平面位错（BPD）**滑移扩展为大面积堆垛层错，导致导通电阻 $R_{on}$ 与正偏压降 $V_F$ 不可逆飙升，必须在厚外延缓冲层界面诱导 BPD 100% 转化为无害的穿透刃位错（TED）。
- **GaN-on-Si HEMT 产线三大核心痛点**：
  1. **常关型（Enhancement-mode）狭窄阈值窗口**：天然 AlGaN/GaN 异质结为常开型（2DEG 一直存在），工程上需在栅极下方精确外延并低损伤选择性刻蚀保留 **p-GaN 岛** 耗尽下方二维电子气实现安全常关，其典型 $V_{th}$ 仅 $1.5\sim 2.0\,\text{V}$ 且极易受刻蚀过刻影响而漂移。
  2. **动态导通电阻崩塌（Current Collapse）**：高压关断状态下高能电子注入 AlGaN 表面态或缓冲层碳掺杂深能级陷阱形成“虚拟栅极”，致使开关瞬态导通电阻剧增数倍；产线须靠高致密表面 $\text{SiN}_x$ 钝化与精细调配缓冲层碳掺杂分布平衡击穿耐压与陷阱效应。
  3. **无金（Au-free）CMOS 兼容金属化改造**：早年射频 GaN 惯用欧姆金电极，为进入低成本 200mm CMOS 代工线，须全面替换为 Ti/Al 基低退火温度（$500\sim 600^\circ\text{C}$）无金金属化方案。

### （3）存储与 CIS 核心晶圆键合（Hybrid Bonding）工艺对比
无论 3D NAND 的阵列-逻辑分离制造（Xtacking / CBA）还是 Stacked CIS 像素-ISP 堆叠，均重度依赖无需微凸块（Micro-bump）的 **Cu-Cu 混合键合（Hybrid Bonding）**：

| 键合方式 | 典型互连节距（Pitch） | 核心工艺窗口与关键指标 | 典型量产应用场景 |
| :--- | :---: | :--- | :--- |
| **W2W 晶圆对晶圆混合键合** | `$0.5\sim 3\,\mu\text{m}$`（向亚微米推进） | 1. **CMP 表面 Dishing 凹陷控制**：铜焊盘需略微凹陷（约 $1\sim 3\,\text{nm}$）于周围 $\text{SiCN}/\text{SiO}_2$ 介质表面，粗糙度 $R_a < 0.3\,\text{nm}$<br>2. **低温二步键合退火**：室温等离子体激活介质预键合 $\to$ **$250\sim 350^\circ\text{C}$ 退火**利用铜大于介质的热膨胀系数挤出桥接导通 | **Stacked CIS（像素+逻辑+DRAM）**、**3D NAND（Xtacking / CBA）** |
| **D2W 芯片对晶圆混合键合** | `$3\sim 10\,\mu\text{m}$` | 允许先筛选已知合格裸片（KGD）再贴片避免良率连坐，但要求极高晶圆表面洁净度与亚微米拾放对准吞吐率 | HBM 逻辑底层协同、先进 Chiplet 3D 异构集成（如 SoIC） |
