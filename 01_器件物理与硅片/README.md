# 01 · 半导体基础、硅片制备与核心器件 (`01_器件物理与硅片`)

本模块建立进入晶圆厂前的底层认知：**“晶圆厂到底在硅片上制造什么结构，以及物理极限在哪里？”**

## 目录内容
- `01_单晶生长与硅片规范/` —— CZ/FZ 单晶生长、300mm 硅片标准、Epi 外延、SOI
- `02_半导体物理基础/` —— 能带理论、载流子漂移扩散、PN 结/MOS 电容 C-V 特性、短沟道效应（SCE）与漏电
- `03_逻辑器件演进/` —— Planar MOSFET → FinFET → GAA → CFET 演进
- `04_存储与特色器件/` —— SRAM、DRAM、3D NAND、CIS 与 SiC/GaN 功率器件
