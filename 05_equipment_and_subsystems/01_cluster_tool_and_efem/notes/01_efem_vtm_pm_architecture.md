# 集束型设备（Cluster Tool）前端 EFEM 与真空传输架构

- **所属模块**：`05_equipment_and_subsystems / 01_cluster_tool_and_efem`

## 1. 为什么刻蚀、薄膜设备多采用“多腔体星形集群”架构？
很多工艺要求**多步薄膜或刻蚀连续完成且绝不能接触空气发生氧化/吸湿**（例如金属阻挡层 + 种子层，或者多步刻蚀 + 表面钝化），同时单一腔室耗时较长。于是出现了标准的 **Cluster Tool（集束型平台）**，把 1 个真空传输中心和 4~6 个独立反应腔室整合在一起。

---

## 2. 从外面看一台机台的三段式拆解

```text
[OHT 天车] ──> [Load Port 装载口 (Z=900mm)] ──> [EFEM 大气前端] ──> [Load Lock] ──> [VTM 真空传输腔] ──> [PM1~PM6 工艺腔]
```

1. **Load Port（前端装载口，SEMI E15.1 / E47.1 / E62）**：
   - 台面基准高度距架高地板约 **`900mm`**；上面有三根定位销（Kinematic Pins）精准卡住 25 片装 FOUP 底部；
   - 具备 **FIMS（前开式一体门）** 机构，向内压紧锁住 FOUP 门板并向下沉降打开，**保证晶圆始终不与外部洁净室空气直接乱流接触**。
2. **EFEM（设备前端模块，Equipment Front End Module）**：
   - 内部维持 ISO Class 1 微环境（顶部自带 FFU 向下吹风）；
   - 包含 **大气双臂 SCARA 机械手**（从 FOUP 25 层 `10mm` 间距里快速取片）、**Pre-aligner（光学预对准台，找准硅片 Notch 缺口方向）**、**OCR 激光码读取器（核对每片硅片身份证）**。
3. **Load Lock（真空缓冲室 / 气锁室）**：
   - 衔接大气与高真空的“减压过渡舱”：一侧开门接收大气机械手送入的晶圆 → 关门快速抽真空（几秒~十秒级）→ 另一侧开狭缝阀进入中心真空腔。
4. **VTM（Vacuum Transfer Module，真空传输腔）**：
   - 中央配有高精度真空机械手（常用 Frog-leg 或双臂磁流体密封机械手），通过 **Slit Valve（气动狭缝阀）** 把晶圆分发到四周星形排布的多个 **PM（Process Module，工艺反应腔室）**。
