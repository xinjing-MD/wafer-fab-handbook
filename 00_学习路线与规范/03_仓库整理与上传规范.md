# 仓库整理、命名与资料上传规范

## 1. 资料分级上传规则（防止 GitHub 仓库臃肿）

| 级别 | 文件类型 | 存放规则 | 体积控制 |
| :--- | :--- | :--- | :--- |
| **L1 纯文本与代码** | `.md` 笔记、`.py`、`.ipynb`、`.svg`、`.drawio` | 直接 `git push` 到对应模块目录 | 无严格限制（Notebook 提交前清理大输出） |
| **L2 轻量配图与精华论文** | `.png` / `.webp` 架构图、单篇关键 `.pdf` | 放对应模块 `图解/` 或 `论文与白皮书/` | 单图 `< 2MB`，单 PDF `< 10MB`，全库建议 `< 500MB` |
| **L3 超大教材与视频/模型** | 整本教材 PDF、培训视频 `.mp4`、3D 工程 `.blend/.step` | **禁止直接提交 Git**；上传网盘或 GitHub Releases，在 `外部资料索引.md` 建索引 | 仓库内只留标题、摘要、页数/时长和链接 |

---

## 2. 标准子模块 5 件套结构

建议 `03_七大核心工艺/` 等重点模块统一保持如下目录组织：
```text
01_具体工艺模块/
├── README.md                  # 本模块导读、核心概念 Checklist
├── 笔记/                      # 个人 Markdown 笔记（编号排序：01_xxx.md）
├── 图解/                      # 自制或精简后的示意图（SVG / PNG）
├── 论文与白皮书/              # 轻量公开讲义或经典论文精读指南
└── 外部资料索引.md            # 视频、教材、设备官网白皮书外链索引
```

---

## 3. 文件与 Commit 命名规范

- **目录/文件名**：数字序号前缀 + 简洁中文（无空格，用下划线 `_` 分隔，例如 `01_光刻原理_瑞利公式与Track联机.md`）；Python 脚本保持英文命名以便终端调用。
- **Commit Message**（简洁中文说明改动即可）：
  - `docs(刻蚀): 补充 ICP 与 CCP 等离子体机理笔记`
  - `feat(实战): 新增 SPC 判异规则检查脚本`
  - `index(光刻): 补充 ASML EUV 白皮书外链索引`
  - `chore(收件箱): 整理归档本周暂存文章`
