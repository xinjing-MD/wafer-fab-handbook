# 02 · 晶圆厂建筑布局、洁净室与厂务系统 (`02_厂房与厂务系统`)

> 晶圆厂不只是“摆满机器的大房间”，而是一座耗资百亿美元、全年 365 天 × 24 小时稳定运行的**超洁净精密化工厂与微振动隔离体**。

- `01_厂房结构与洁净室/` —— 三层垂直建筑结构、Bay & Chase 布局、ISO 洁净度、FFU、AMC 与抗微振
- `02_超纯水特气与供液/` —— 超纯水（UPW）、大宗/特种气体、中央供液系统（CDS/SDS）
- `03_空调真空供电与尾气/` —— 洁净空调（MAU/RCU）、尾气洗涤（Scrubber）、电力保障、真空与 PCW 冷却水
