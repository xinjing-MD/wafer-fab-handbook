## 1. 人的污染控制：无尘室为什么对“人”管得这么严？

在全自动化 300mm 晶圆厂内，设备腔体高度密封、晶圆运行在封闭 FOUP 中，**“人”反而成为了洁净室中最大、最不稳定且危害极高的污染源**。人体生理代谢与日常活动对纳米级良率构成了四大物理化学威胁：
- **微粒散逸**：人体静坐时每分钟即向空气脱落约 **$10^5$ 个 $\ge 0.5\,\mu\text{m}$ 的皮屑、毛发和衣物纤维**，走动时散发量飙升至 **$10^6\sim 5\times 10^6$ 个/分钟**；
- **碱金属与离子沾污**：人体汗液、唾液和皮肤油脂富含 $\text{Na}^+, \text{K}^+, \text{Cl}^-$ 等碱金属与卤素离子。极微量 $\text{Na}^+$ 扩散进入 MOS 晶体管栅氧化层（Gate Oxide），会在电场下发生可动离子漂移，直接破坏器件阈值电压（$V_{th}$）稳定性甚至引发漏电击穿；
- **有机物与 AMC 分子挥发**：化妆品、护肤霜、香水及染发剂中的硅氧烷、矿物质粉尘和胺类化合物会诱发光学镜片起雾与光刻胶 T-top 畸变；**进场前 30 分钟内严禁吸烟**是因为烟草焦油和亚微米粒子会在肺泡中持续滞留并通过呼气向外排放长达数十分钟；
- **人体静电放电（ESD）**：人在干燥洁净室内摩擦走动极易积聚 **3,000~15,000 V 高压静电**，而现代 FinFET/GAA 器件超薄栅氧（$1\sim 2\,\text{nm}$）仅需几十伏人体静电放电即可当场击穿。

### （1）标准穿戴准则（由上到下、从里到外封装原则）与分级对照
以先进制程 ISO Class 3~5 洁净室为例，更衣流程设计严格遵循“**上层阻挡下落、外层压紧包覆内层**”的流体力学逻辑：
1. **入室前净化与禁忌**：
   - 严格卸妆、摘除所有首饰与金属腕表，使用无尘抗菌洗手液洗手烘干；
   - 更换洁净拖鞋并走过粘尘垫（Sticky Mat，需定期撕除表层防止二次带尘）踏入更衣室（Gowning Room）。
2. **佩戴头套（Hood）与无尘口罩（Mask）**：
   - 口罩必须严密压住鼻梁并包住下巴，严禁露出鼻孔；
   - 头套须彻底包裹全部头发、鬓角与耳廓——防止上方掉落的头屑落入内衣领口。
3. **穿连体防静电无尘服（Bunny Suit）**：
   - 采用高密度超细聚酯长丝织就并嵌织**碳纤维导电网格（ESD Grid，表面电阻率控制于 $10^5\sim 10^9\,\Omega/\text{sq}$）**，既利用微孔拦截皮屑穿出，又随时引导人体摩擦静电接地消散；
   - 洁净服洗衣房必须用高纯 DI 水清洗并定期按 **IEST-RP-CC003（Helmke Drum 滚筒试验）**抽检确认发尘合格。穿衣时严禁衣服袖口、裤脚触碰地面。
4. **穿高筒无尘靴（Cleanroom Boots）**：
   - 将连体服裤脚完全塞入并包裹在高筒靴内，拉紧靴口按扣或搭扣，将人体下部微粒通路彻底密封。
5. **佩戴双层无尘手套（Double Gloves）与护目镜**：
   - 内层佩戴贴合手腕的薄型无粉丁腈或聚氨酯手套，并将无尘服弹性袖口压入内层手套中；
   - 再套上外层长袖无粉高纯洁净手套完全包覆袖口连接处（进入化学湿法区或维修作业需佩戴全封闭防化学飞溅护目镜）。
6. **ESD 校验与风淋室（Air Shower）**：
   - 穿戴完毕在全身镜自检无皮肤和普通衣物外露；经 **ESD 静电测试仪**（测试腕带/导电靴接地电阻是否在典型安全窗口 **$7.5\times 10^5\sim 3.5\times 10^7\,\Omega$**——既确保瞬间泄放静电，又保留足够阻值防止触及低压电源时电击伤人）通过后进入风淋室；
   - 风淋室内喷嘴以 **`20~25 m/s` 高速 HEPA 过滤气流** 强制吹扫 **`15~30 秒`**（双向门互锁不可强推），剥离表面浮尘后方可进入 Clean Bay。

| 厂房受控区域 | 典型洁净度级别 | 标准穿戴防护组合 | 关键管控附加要求 |
| :--- | :--- | :--- | :--- |
| **Clean Bay / 光刻核心区** | ISO Class 1~3（微环境） / Class 4 | 全套连体帽 + 口罩 + 连体 Bunny Suit + 高筒靴 + **双层无粉丁腈手套** | **ESD 校验必过**；光刻黄光区需加护眼或注意 UV 阻断；操作晶圆或腔室内件必须严守无尘接触规范 |
| **Service Chase / 灰区走廊** | ISO Class 5~6 | 分体或连体洁净服 + 口罩 + 发网/洁净帽 + ESD 鞋套/无尘鞋 + 单层或双层手套 | 进入拆腔维修（PM）须加戴安全帽/防撞帽、防切割或耐酸碱手套与防护面罩 |
| **Sub-Fab 辅助设备层** | ISO Class 7~8 / 普通受控区 | 工业防静电工作服 + **钢头防砸防穿刺安全鞋** + 安全帽 + 护目镜（免穿 Bunny Suit） | 强噪音区（Dry Pump 密集区 $>85\,\text{dBA}$）强制佩戴耳塞；涉化/换泵作业须穿耐化围裙与防毒面具 |

### （2）无尘室行为管控与物流剥离铁律
- **行动节制**：严禁奔跑、剧烈挥臂或跨越大步——高速移动产生的背风面涡流（Wake Vortex）会击穿 $0.35\sim 0.45\,\text{m/s}$ 的垂直单向层流，将地面颗粒直接卷吸至晶圆传片高度（900mm）。
- **用品严管**：严禁带入普通纸张、纸箱、瓦楞盒、木质铅笔、橡皮擦或普通圆珠笔（纸纤维碎屑对洁净室等同“沙尘暴”），所有记录必须采用**低脱落专用无尘纸（Cleanroom Paper）与专用防静电无尘笔**；非经防爆防尘与信息安全特批，严禁个人普通手机外露操作。
- **设备物料三级剥离与货淋室（Airlock）规则**：所有待入厂备件、滤芯与工具必须严格执行**“拆箱区脱外衣 → 中转区 IPA/超纯水无尘布擦拭 → 货淋室/传递窗（Pass Box）互锁吹扫”**三级剥离程序；**绝对禁止任何瓦楞纸箱或木托盘进入生产走廊**！
- **出入隔离**：穿着无尘服严禁离开洁净控制区前往普通厕所或餐厅，一旦脱下必须按标准回收清洗消毒或废弃处理，严禁反复穿用已受污染的高等级无尘服。

### （3）产线日常着装稽核高频违规红线（Gowning Audit Checkpoints）
1. **露发露耳与口罩滑落**：口罩未压紧鼻梁仅遮住嘴部（呼吸水汽喷洒在晶圆表面造成盐碱污染），或头套松脱露出碎发鬓角；
2. **拉链未拉到顶与裤脚外翻**：无尘服领口未贴合头套垂片，或裤脚未塞入靴筒导致行走时内衣纤维从裤口甩出；
3. **破损或交叉污染手套**：发现外层手套接触油污、化学品或撕裂未立刻更换；戴着洁净手套抓挠暴露皮肤或整理面罩后再直接触摸机台 Load Port 按钮；
4. **洁净服清洗认证（IEST-RP-CC003 Helmke Drum 分级）**：所有循环清洗后的连体无尘服须经干燥滚筒发尘抽检，达到 **Category I（最严苛，$\ge 0.5\,\mu\text{m}$ 颗粒排放率 $< 1,200$ 颗/分钟·件）** 方准投用至 ISO 1~4 核心区域。

## 2. EHS（环境、健康与安全）四大高危红线与作业许可制度

半导体晶圆厂集中了极端化学腐蚀、剧毒气体、超高压电、重型高速自动化天车和隐形高能激光辐射等高危工业源，“**任何产量与进度永远不可凌驾于 EHS 红线之上**”是所有先进 Fab 的最高铁律。

### （1）高危非常规作业许可矩阵（Permit-to-Work, PTW）
凡涉及非日常量产操作的装机、拆管、高空或焊接作业，必须在开工前完成电子化或纸质 PTW 安全许可会签并指派专职监护人：

| 作业许可类型 | 适用典型晶圆厂场景 | 强制安全先决条件与监测手段 |
| :--- | :--- | :--- |
| **LOTO 能量隔离许可** | 拆开刻蚀/CVD 反应腔、进入机械手区、电源柜检修 | 断电断气泄压放电后挂设**个人专属安全锁**并完成 Try-Out 验零验证 |
| **Confined Space 受限空间** | 进入大型炉管/特气地沟/水箱或密闭气瓶间作业 | 必须强制通风置换，**便携式 $\text{O}_2$ / 毒气四合一检测仪全程在线**（$\text{O}_2 \in 19.5\%\sim 23.5\%$），门外必须有专人连续监护 |
| **Line Break 管路破断** | 切割或拆卸酸碱 CDS、UPW、特气管道与泵体阀门 | 必须经过彻底排空、$\text{N}_2$ 吹扫置换、酸碱试纸测得中性及佩戴 **耐化防溅面罩+橡胶围裙** 方可松螺栓 |
| **Hot Work 动火作业** | Sub-Fab 不锈钢管路焊接、支架切割打磨 | 提前清理方圆 10 米内所有易燃溶剂/抹布、覆盖防火毯、配置灭火器且焊后持续监控防火巡查（Fire Watch）30~60 分钟 |
| **Track / Zone Lockout** | Clean Bay 吊顶内维修、架设梯子触及天车高空包络面 | 事先向 CIM/AMHS 申请**该区段 OHT 天车逻辑断电锁止**，地面拉起警示围栏后方可登高 |

### （2）红线一：氢氟酸（HF）渗透灼伤、化学混排禁令与特效急救
在湿法刻蚀与硅片清洗（DHF / BOE）中超高频使用的氢氟酸（HF），是晶圆厂内最具欺骗性的致死杀手：
- **致死毒理机理**：不同于浓硫酸或盐酸接触皮肤瞬间产生剧烈烧灼感，HF 属于弱酸（电离度低），低中浓度溅到皮肤上**初期往往没有任何痛感**，极易造成受害者掉以轻心！然而未解离的 HF 分子拥有极强的脂溶性穿透力，会无声穿透表皮深入真皮层、肌肉乃至骨骼，疯狂夺取体内游离钙离子（$\text{Ca}^{2+}$）和镁离子（$\text{Mg}^{2+}$）形成不溶性 $\text{CaF}_2$——**数小时后引发深层组织剧痛液化坏死，并使血清钙浓度暴跌导致急性低钙血症与高钾血症，极易瞬间诱发致命性心室颤动和心脏骤停（仅手掌面积大小的浓 HF 灼伤即可致命）！**
- **不可妥协的现场急救规程**：
  1. **10 秒即刻救援**：一旦怀疑或发生任何酸碱溅射，立即冲向最近**紧急冲淋洗眼器（依据 ANSI Z358.1 标准：任何化学操作点 10 秒内直线可达且无障碍阻挡）**启动大流量温水（$16\sim 38^\circ\text{C}$）持续冲洗；若岗位配备 **六氟灵（Hexafluorine）** 则应第一时间优先喷淋（六氟灵可同时温和螯合 $\text{H}^+$ 质子与 $\text{F}^-$ 氟离子，且本身无高渗透压及放热反应，能够直接拦截氟离子向皮下深层渗透）。
  2. **去衣冲洗与涂抹解毒剂**：边冲淋边用剪刀迅速剪除/脱掉受污染手套与无尘服，**严禁拿干布擦拭伤处**；对于皮肤接触部位，持续冲洗后立刻戴上干净手套将专备的 **2.5% 葡萄糖酸钙凝胶（Calcium Gluconate Gel）** 反复厚涂并轻柔按摩（以人工外源 $\text{Ca}^{2+}$ 牺牲替代自身血钙和骨骼被氟消耗）；若眼部溅入，严禁涂抹凝胶，须翻开眼睑持续用生理盐水/六氟灵冲洗至少 15 分钟并由医护专业转运至协议急救医院实施葡萄糖酸钙静脉或动脉灌注抢救！

| 危化品组合 | 严禁混合机理与灾难后果 | 现场储存与废液排口强制要求 |
| :--- | :--- | :--- |
| **$\text{H}_2\text{SO}_4 + \text{H}_2\text{O}_2$ (SPM) + 有机溶剂 (IPA/丙酮)** | 强氧化剂遇还原性溶剂瞬间引发剧烈氧化放热、爆沸甚至高能爆炸 | **严禁混倒在同一废液桶或共用有机/酸排接口**，配液容器须严密标注防误倒 |
| **氢氟酸 (HF) + 玻璃材质 / 含氰废液** | 猛烈腐蚀玻璃生成 $\text{SiF}_4$ 气体胀破容器；遇氰化物生成剧毒 $\text{HCN}$ 气体 | 必须采用耐氟塑料 **HDPE / PFA 容器** 盛装；含氟废液单独排入氟系废水处理槽 |
| **强酸 ($\text{HCl}/\text{HNO}_3$) + 强碱 ($\text{NH}_4\text{OH}/\text{TMAH}$)** | 中和瞬间释放高热量剧烈喷溅、产生大量有害酸碱气溶胶烟雾 | 机台双废液排口物理防呆隔离（不同管径接头防呆设计），严禁同桶混收 |

### （3）红线二：剧毒/自燃特气泄漏（TGMS）与惰性气体窒息红线
- **TGMS 毒气/自燃报警响应**：晶圆厂对 $\text{AsH}_3$（剧毒，极微浓度即可致命溶血）、$\text{PH}_3$、$\text{SiH}_4$（空气中浓度超过 $1.37\%$ 瞬间自燃闪爆）、$\text{Cl}_2$ 实施极高灵敏度监控。当厂务警戒灯塔（Signal Tower）特定警灯爆闪及广播响起撤离警报时，所有非应急人员必须**立刻停下手头工作（切忌贪恋收拾工具或挽救半成品晶圆）**，观察风向标识沿最近的合规安全逃生通道（Emergency Exit）**向上风向快速疏散**至户外指定集合点（Assembly Point）刷卡清点人数。
- **严禁盲目施救与 $\text{N}_2$/$\text{Ar}$ 窒息陷阱**：
  - 高纯氮气（$\text{N}_2$）和氩气（$\text{Ar}$）无色无味，在 Sub-Fab 封闭空间、气瓶间（Gas Bunker）或打开的大型工艺腔体内极易发生局部富集挤占氧气。
  - 正常空气含氧量 $20.9\%$，当环境含氧量降至 **$< 10\%$** 时，人员在吸入 **1~2 口气（5~10 秒内）即可瞬间丧失意识瘫倒窒息死亡**！
  - 因此，一旦发现同事倒在气瓶间或腔体内，**绝对严禁任何未戴防护装备的人员冲入救人**（产线历史上极多伤亡均为“盲目施救引发的连环多杀悲剧”），必须第一时间拉响警报呼叫专业 **ERT（应急响应团队）** 穿戴 **SCBA（正压自给式空气呼吸器）及 A 级重型防化服** 进场救援。
  - 进入可能积聚惰性气体的受限空间作业，必须强制办理作业许可（Confined Space Permit）并随身佩戴校准合格的便携式 $\text{O}_2$ 报警仪（设定 $< 19.5\%$ 即时报警撤离）。

### （4）红线三：LOTO（上锁挂牌）标准执行与 AMHS 天车机械碰撞防线
- **能量隔离与标准 LOTO 作业流**：晶圆机台同时连着 480V/380V 强电、高压 CDA 气动机械臂、极高温加热盘、真空吸力及危险化学品管路。设备维保前必须严格执行标准 LOTO 流程将机台置于**“零能量状态（Zero Energy State）”**：
  1. 通知相关产线与厂务确认停机窗口；
  2. 按正常程序关停机台；
  3. 切断上游所有断路器、气源手阀及化学品隔离阀；
  4. **由每位直接作业工程师亲自加挂专属个人安全锁（Personal Lock）及签字警示牌（Tag），贯彻“一人一锁一钥匙，谁挂谁拆”铁律**（严禁他人代解锁）；
  5. **释放全部储存残余能量**（高压电容放电、气缸泄压排空、加热盘降温至安全接触温度、机械臂落位锁死）；
  6. **Try-Out 零能量验证**（按动开机键并现场验电确认绝对无法启动及电压为零后方准伸手入腔！）。
- **AMHS / OHT 天车轨区高空防撞**：Clean Bay 顶部 OHT 天车以 $3\sim 5\,\text{m/s}$ 飞速穿梭并随时执行 Hoist 垂直垂吊抓取 FOUP。凡需要在天花板附近架设 A 字梯或移动作业平台检修 FFU、传感器或管路时，必须先向 CIM 物流控制系统申请**天车轨区逻辑锁定（Track / Zone Lockout）**并摆放物理隔离栏及声光警示灯，确认所在路段全部天车停驶断电后方可登高伸臂作业。

### （5）红线四：高压电、强射频、准分子激光与电离辐射（绝对禁止 Interlock Bypass）
- **电弧闪爆与高能辐射源**：离子注入机（Ion Implanter）高压加速端高达数十 kV 至数 MV，同时高能束流轰击靶材会持续产生强 **X 射线韧致辐射**；DUV 光刻机使用的 KrF（248nm）与 ArF（193nm）准分子激光器属于不可见高危 **Class 4 级紫外激光**，即便微弱漫反射入眼亦能在瞬间永久烧毁角膜与视网膜（调试光学腔时必须拉起专用光遮挡帘并佩戴标注对应波长高光密度 OD 值护目镜）；涉高压电柜操作必须履行双人监护制（Buddy System）并穿戴对应等级防电弧服与绝缘手套。
- **零容忍红线——严禁旁路安全联锁（No Interlock Bypass）**：所有高危机台均通过多套硬线机械微动开关、安全继电器与光栅联锁（Safety Interlock）确保“开门断高压、断射频、断激光、闭毒气”。**任何用磁铁吸住安全开关、用跳线短接传感器节点或强制修改安全 PLC 逻辑在开放状态下点亮激光/高压/射频/移动机械手的行为，均属晶圆厂最顶级的“零容忍红线（Zero Tolerance Violation）”，一经查实立即取消上岗权限乃至解除劳动合同。**

## 3. 洁净室极早期消防与应急处置黄金工程法则

由于洁净室拥有高达每小时 300~600 次的强力垂直层流，一旦机台内部电弧起火，高速气流会在几秒内极速助燃并将致命有毒浓烟灌满整个回风循环层！因此先进 Fab 天花回风道普遍部署了灵敏度比传统烟感高数百至上千倍的 **VESDA（极早期空气采样烟雾探测系统）**——在塑料电缆刚受热释放纳米级热解微粒但尚未出现明火时即可提前预警，联动降速/关停局部 FFU 防烟气扩散并触发洁净灭火。

### ERT 应急响应“黄金十分钟”协同机制
1. **0~2 分钟（触发与隔离）**：现场人员拍下机台红色 **EMO（Emergency Off，紧急停机按钮）** 或拉响手动报警，沿疏散指示牌撤离并拨打厂区急救专线（切勿挂断，报清准确楼层/Bay/机台号/涉事介质）；
2. **2~5 分钟（集结与着装）**：厂内全天候驻守的 **ERT（应急响应特种队）** 2 分钟内集结完毕，查明风向标及化学品安全技术说明书（MSDS/SDS），穿戴 SCBA 并携带便携直读气体检测仪进入上风口建立警戒隔离带；
3. **5~10 分钟（抢救与洗消）**：抢出伤员并在户外临时洗消帐篷完成脱衣冲淋与葡萄糖酸钙急救，待医护救护车转运；同步确认气体主阀关闭并排查相邻机台联锁状态，**未获 EHS 负责人气体浓度复测零检出书面授权前，严禁任何人擅自返回警戒区复机生产！**

| 突发紧急事态 | 严禁操作（致命误区） | 正确工程处置与标准动作 |
| :--- | :--- | :--- |
| **$\text{SiH}_4$ 等自燃/可燃特气着火** | **切忌在未切断气源前盲目直接扑灭火焰！**（火焰扑灭但泄漏持续会导致海量气体与空气充分预混，引发毁灭性二次空间爆轰） | 第一时间触发最近 **EMO 紧急切断开关** 或由消防总控关闭上游气瓶主阀；仅用大量雾状水持续冷却周边未着火钢瓶防止高温超压爆裂，等待残气燃尽 |

## 4. 晶圆厂地震联锁（Seismic Interlock）与灾后复机清查铁律

地震高发区（如日本、台湾及环太平洋半导体产业带）的 12 寸晶圆厂，必须在结构基础及 Sub-Fab 关键节点部署 **实时强震加速度监测仪（Seismic Sensor）** 与自动安全切断网：

1. **多级地震阈值自动联锁动作**
   - 当探测到地震 P 波预警或地表加速度达到设定一级阈值（如工程典型区间 **$0.05\sim 0.08\,g$ / 4 级以上震感**）时，厂务安全 PLC 在毫秒级内触发全厂关键防护：
     - **特气/化学品总阀紧急闭锁（Shut-off）**：所有易燃自燃、剧毒特种气体 VMB/气瓶柜主阀及大宗化学品泵同步锁定关断，严防管道震裂发生次生火灾毒爆；
     - **OHT 天车全线紧急制动停机**：指令所有空中天车在轨急停，避免剧烈晃动下抓手摆动坠落晶圆盒（FOUP）或跨区撞车；
     - **高危工艺设备停止反应（EMO / Standby）**：终止晶圆传输机械手动作并使反应腔退回安全惰性保护态。
2. **震后人员自救与复产检查红线（Post-Seismic Recovery SOP）**
   - 震感发生瞬间，洁净室内人员立即远离高大立式石英炉管、玻璃/化学品湿法台与未固定气瓶柜，迅速蹲伏于结构承重柱或坚固设备框边护住头颈（**切忌在震动尚未平息时穿越架空天车下方狂奔！**）；
   - 地震平息后按指令全员撤离至空旷集结点，**在厂务及 EHS 团队完成以下三大硬核巡检并签字放行前，严禁盲目恢复特气与机台复机**：
     1. 利用激光追踪仪/微检漏仪逐一核查 Sub-Fab 所有特气管道焊缝、玻璃管道及化学品 PFA 双套管无撕裂泄漏；
     2. 确认所有中央废气 Scrubber、冷机、UPW 与消防稳压管线及电力系统完好无损；
     3. 光刻机与核心量测机台（E-Beam / CD-SEM）必须重新执行**主动气垫水平复校（Auto-Leveling）、激光干涉仪校准与基线比对（Baseline Check）**，确认硅片破片已彻底清理真空腔体后方可投入正常流片。
