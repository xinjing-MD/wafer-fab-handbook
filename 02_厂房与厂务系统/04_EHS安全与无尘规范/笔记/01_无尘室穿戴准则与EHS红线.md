# 无尘室穿戴准则与晶圆厂 EHS 高危红线

- **所属模块**：`02_厂房与厂务系统 / 04_EHS安全与无尘规范`

## 1. 人的污染控制：无尘室为什么对“人”管得这么严？
人体每分钟都会脱落数万至数十万个皮屑与微粒，化妆品、香水、纸屑、甚至圆珠笔芯都是致命污染源。

- **标准穿戴顺序（从上到下，从里到外原则）**：
  1. 除妆、摘饰品、洗手并进入更衣前室（换拖鞋/洁净鞋套）
  2. 戴头套（Hood）与无尘口罩（Mask，遮住口鼻与头发）
  3. 穿连体无尘服（Bunny Suit，拉链严密、袖口裤脚封口）
  4. 穿高筒无尘靴（Boots，把裤脚包进靴筒内）
  5. 戴双层无尘手套（Gloves，包裹袖口）与护目镜（如进化学区）
  6. 过风淋室（Air Shower）高速吹除表面浮尘后进入 Clean Bay
- **行为红线**：禁止奔跑（扬尘）、禁止使用普通纸张与木制铅笔（需用无尘纸/无尘笔）、禁止携带个人手机直接暴露操作（按各厂管控政策）、禁止随意触碰裸露晶圆或机台运动部件。

## 2. EHS（环境、健康与安全）四大高危风险

1. **氢氟酸（HF）灼伤**：湿法清洗与刻蚀高频使用。HF 初期皮肤痛感不明显但能穿透皮下与钙离子结合导致深层组织坏死甚至心脏骤停；必须熟记**六氟灵（Hexafluorine）冲洗**与**葡萄糖酸钙凝胶**急救流程。
2. **剧毒/自燃特气（$\text{AsH}_3, \text{PH}_3, \text{SiH}_4, \text{Cl}_2$）**：听到 **TGMS 毒气报警** 或看到警灯闪烁，立即按指定疏散路线向上风向撤离，严禁盲目冲进报警区域救人（需专业 ERT 应急小组佩戴 SCBA 正压空气呼吸器处置）。
3. **机械夹伤与天车碰撞（AMHS / 机台维修）**：检修设备必须严格执行 **LOTO（Lockout / Tagout 上锁挂牌）**，断电断气锁死气动阀门后再进腔体。
4. **高压电、RF 射频与强激光/X 射线**：光刻机准分子激光、离子注入机高压/X 射线屏蔽联锁（Interlock）严禁任何形式的短接旁路（Bypass）。
