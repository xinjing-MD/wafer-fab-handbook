# WAT、CP Wafer Map 识别与失效分析（FA）方法论

- **所属模块**：`07_yield_spc_and_failure_analysis / 03_wat_cp_and_fa`

## 1. WAT（晶圆允收测试）vs CP（晶圆针测）

| 维度 | WAT / PCM（晶圆级电性参数测试） | CP（Chip Probing / Wafer Sort） |
| :--- | :--- | :--- |
| **测试位置** | 芯片之间的**切割道（Scribe Line）**专门测试结构（TEG） | 每一颗真实的**产品芯片（Die）焊盘** |
| **测试内容** | 晶体管 $V_{th}$、$I_{dsat}$、$I_{off}$、接触孔电阻、金属线阻、栅氧击穿 | 芯片完整数字/模拟/存储逻辑功能、漏电、功耗、速度分 Bin |
| **覆盖率** | 每片抽测 5~9 个站点（Site） | **100% 全片每颗 Die 逐一扎针测试** |
| **定位能力** | 迅速判断是**基础晶体管参数漂移**（系统性工艺问题）还是金属接触电阻异常 | 生成 **Wafer Map（晶圆良率分布图）**，区分随机颗粒缺陷还是空间几何规律缺陷 |

## 2. 常见 Wafer Map 空间图谱与根因直觉

| Wafer Map 失败图形 | 高概率对应的晶圆厂根因 |
| :--- | :--- |
| **Edge Ring（边缘环状失效）** | 边缘光刻胶涂覆/边缘曝光不良、CMP 边缘过抛、刻蚀腔室 Edge Ring（聚焦环）老化、湿法旋转清洗甩干边缘水痕 |
| **Center Bullseye（中心同心圆失效）** | 薄膜/刻蚀气体喷淋头（Showerhead）中心气流不均、ESC 中心区域加热丝或氦气背冷异常、CMP 中心压力设定偏差 |
| **Scratch / Arc（划痕或弧线）** | CMP 研磨垫掉金刚石/大颗粒磨料、机械手夹爪异常蹭伤 |
| **Repeated Grid / Shot（周期性曝光场失效）** | **光刻掩模版（Reticle）上有脏污或损伤缺陷**（每跨一个曝光场重复出现同一位置死 Die，极易锁死为光刻问题！） |
| **Random Scattered（全片随机散点）** | 随机颗粒污染（洁净室环境、化学药液、腔室掉粉），通常与缺陷密度 $D_0$ 正相关 |

## 3. 失效分析（FA, Failure Analysis）标准流：先无损电定位，再破坏看微观

1. **EFA（电性失效分析，非破坏/定位阶段）**：
   - **Curve Tracer**：测 I-V 曲线确认是开路（Open）、短路（Short）还是漏电（Leakage）。
   - **EMMI（微光显微镜）**：探测漏电或击穿 PN 结微弱光子发射，精确定位失效热点坐标。
   - **OBIRCH / TIVA（激光诱导电阻变化）**：用激光局部加热金属/通孔微短路或高阻空洞位置，捕捉电流微变精准定位。
2. **PFA（物理失效分析，逐层剥离与电镜切片）**：
   - **化学/机械逐层剥离（De-layering）**：从钝化层往下逐层剥除铜与介质，配合 SEM 找金属桥接或断线。
   - **Dual-Beam FIB + TEM / EDS**：在定位热点处用离子束切出数十纳米薄片，在 TEM 下看晶格和薄膜界面，并用 **EDS（能谱分析）** 查出异常污染物究竟是什么元素。
