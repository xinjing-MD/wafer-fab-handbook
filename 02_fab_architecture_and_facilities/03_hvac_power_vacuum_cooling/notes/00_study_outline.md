# 空调、尾气处理、真空与冷却水架构梳理（待完善）

后续可围绕以下厂务子系统补充笔记：
1. **HVAC（洁净室空调）**：MAU（新风机组控制温湿度与粗滤）+ DCC（干盘管）+ FFU（风机过滤单元）+ RCU 循环。
2. **Scrubber（尾气本地洗涤塔）**：Burn-Wet（燃烧+水洗，处理硅烷等自燃/PFC气体）、Dry Bed（干式吸附，处理剧毒砷化氢/磷化氢）等。
3. **PCW / Chiller（工艺冷却水）**：去离子水闭式循环，为机台腔壁、RF 电源、干泵精准控温。
4. **电力与 UPS / 飞轮储能**：电压暂降（Voltage Sag）敏感性极高（SEMI F47 标准），短暂断电可能导致全线报废。
