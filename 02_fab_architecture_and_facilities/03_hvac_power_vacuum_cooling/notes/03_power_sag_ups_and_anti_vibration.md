# 晶圆厂供电稳定性、SEMI F47 电压暂降抑制与抗微振基座

- **所属模块**：`02_fab_architecture_and_facilities / 03_hvac_power_vacuum_cooling`

---

## 1. 为什么“闪烁一下”（电压暂降）会让晶圆厂损失数亿元？

电网受到雷击或短路故障时，常产生仅持续 **100~500 毫秒的电压跌落（Voltage Sag / Dip）**。普通工厂仅灯光闪烁，但在晶圆厂里：
1. **涡轮分子泵（TMP）保护停机**：转速高达数万转的 TMP 一旦失去电源逆变支撑，会紧急急停，高真空瞬间瓦解并导致高压油气倒吸毁坏工艺腔体；
2. **射频电源（RF）熄弧**：正在刻蚀的晶圆表面等离子体突然熄灭，高能带电离子在晶圆表面非均匀沉积造成无法挽回的死片；
3. **光刻机双工件台磁悬浮失锁**：以纳米精度高速行进的工件台因电压丢失触发硬件抱死防撞，全片甚至整批在制品（WIP）全部报废，光刻机校准需耗时数天。

## 2. SEMI F47 电压暂降抗扰度工业标准

SEMI 组织制定了强制性的 **SEMI F47 标准**，规定半导体制造设备必须具备在电网跌落时“挺住不停机”的穿透能力（Sag Ride-through）：

```text
电网剩余电压百分比
 100% |---------------------------------------- (正常运行)
      |
  80% |          |============================= (必须连续承受 1 秒以上)
  70% |          |          |
      |          |          |
  50% |==========+          +------------------ (在 50% 电压下必须挺住 200 毫秒)
      |
   0% +----------+----------+-----------------> 时间 (ms)
      0         200        500        1000
```

- **厂务端保护手段**：
  - **双回路或三回路 110kV / 220kV 独立变电站供电**，毫秒级快速自动切换互投；
  - **中高压动态电压恢复器（DVR, Dynamic Voltage Restorer）**：能在 2~5 毫秒内注入补偿电压，把跌落填平；
  - **飞轮储能 / 工业级不间断电源（UPS）**：针对光刻机、CIM 服务器和核心安全系统提供无间断电能支撑。

## 3. 抗微振结构设计与 VC 标准曲线

光刻机套刻精度已经达到亚纳米级，外界道路重卡行驶、地铁经过甚至空调管道振动，都会通过大地传播破坏光刻聚焦。

### （1）BBN 振动判据准则（Vibration Criteria, VC Curves）
半导体行业按振动速度均方根（RMS Velocity）分级：

| 级别 | 振动速度阈值 | 适用晶圆厂典型设备区域 |
| :---: | :--- | :--- |
| **VC-A** | $50\,\mu\text{m/s}$ | 普通研发实验室、普通光学显微镜 |
| **VC-B** | $25\,\mu\text{m/s}$ | 微观检测区、金相检验台 |
| **VC-C** | $12.5\,\mu\text{m/s}$ | 绝大多数干法刻蚀、薄膜沉积 Cluster Tool 机台 |
| **VC-D** | $6.25\,\mu\text{m/s}$ | 测量 SEM、E-Beam 电子束检测机台 |
| **VC-E / VC-F** | **$3.12\,\mu\text{m/s} \sim 1.56\,\mu\text{m/s}$** | **先进 DUV / EUV 光刻机台专属严苛标准** |

### （2）晶圆厂三级隔振工程实现
1. **地基孤岛沉箱（Deep Concrete Caissons & Rock Piles）**：光刻机区厂房桩基打入坚硬地下岩层数十米，与普通辅助厂房基础完全结构断开；
2. **华夫板高阻尼地面（Waffle Slab）**：洁净室底层浇筑 600~900mm 厚的钢筋混凝土格子结构华夫板，既允许垂直气流下穿，又具有极高抗弯曲刚度和自重吸振阻尼；
3. **机台主动气浮隔振台（Active Pneumatic Vibration Isolation Platform）**：光刻机和电子束量测仪自带压电加速度传感器与主动控制气囊，实时产生反向微力抵消来自地面的微小震颤。
