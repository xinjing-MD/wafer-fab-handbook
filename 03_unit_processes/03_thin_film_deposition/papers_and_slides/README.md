# 薄膜沉积经典论文、顶级会议讲义与技术白皮书精读指南

本目录用于收纳 CVD、ALD、PVD 与 Epi 外延生长领域的**经典学术综述、IEDM / VLSI 专题论文与设备龙头官方白皮书（Applied Materials / ASM International / Lam Research）**。

## 1. 必读里程碑经典学术论文（Seminal Papers）

### （1）原子层沉积（ALD）全景经典综述
- **文献标题**：*Atomic Layer Deposition: An Overview*
- **作者与机构**：Steven M. George (University of Colorado)
- **发表出处**：*Chemical Reviews*, 2010.
- **核心贡献**：全球被引用数千次的 ALD 必读圣经。详细剖析了 TMA/水反应制备 $\text{Al}_2\text{O}_3$、四氯化铪制备 $\text{HfO}_2$ 的表面配位化学动力学；给出成膜饱和窗口（ALD Temperature Window）、反应自限制机理与前驱体蒸气压选择准则。

### （2）流动性化学气相沉积（Flowable CVD / FCVD）填隙突破
- **文献标题**：*Advanced Gap-Fill Techniques for High-Aspect-Ratio Structures in Sub-10nm Technologies*
- **作者与机构**：Applied Materials Advanced Dielectrics Team
- **发表出处**：*IEDM Technical Digest*, 2014.
- **核心贡献**：解决高深宽比 STI 浅沟槽和多层字线间距极窄时的无空洞填充难题。利用气相前驱体在低温表面瞬间生成液体状低聚硅氧烷流动态薄层（实现无缝流平填充），随后经高温退火转变为致密高质量二氧化硅。

### （3）选择性区域沉积（Area-Selective Deposition, ASD）前沿
- **文献标题**：*Area-Selective Deposition: Materials, Applications, and Challenges*
- **发表出处**：*Nature Reviews Materials*, 2019.
- **核心贡献**：探讨自对准制造的终极方案——通过表面官能团化学修饰（自组装单分子层 SAMs），实现金属或介质“只在金属表面长、不在氧化物表面长”的自下而上底自组织工艺，大幅降低光刻与套刻对准压力。
