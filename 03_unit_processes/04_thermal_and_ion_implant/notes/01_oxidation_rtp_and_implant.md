# 热处理、氧化扩散与离子注入核心原理

- **所属模块**：`03_unit_processes / 04_thermal_and_ion_implant`

## 1. 热氧化（Thermal Oxidation）与 Deal-Grove 模型
硅片在高温炉管中与氧气或水汽反应生成高质量的 $\text{SiO}_2$：
- **干氧氧化**：$\text{Si} + \text{O}_2 \rightarrow \text{SiO}_2$（致密、缺陷少、速率慢，适合超薄高质量栅氧/垫氧）。
- **湿氧氧化**：$\text{Si} + 2\text{H}_2\text{O} \rightarrow \text{SiO}_2 + 2\text{H}_2$（速率快，适合较厚的隔离氧化层）。
- **Deal-Grove 两阶段机制**：
  - 薄氧化层阶段：**表面反应控制**，膜厚随时间呈**线性生长**；
  - 厚氧化层阶段：氧分子必须穿过已有 $\text{SiO}_2$ 才能抵达 Si 界面，变成**扩散控制**，膜厚随时间呈**抛物线（$\propto \sqrt{t}$）生长**。
- **体积膨胀规律**：每生长 $1\,\text{nm}$ 的 $\text{SiO}_2$，大约消耗 $0.44\,\text{nm}$ 的硅衬底，界面会向硅内部推进。

## 2. 退火（Annealing）与热预算（Thermal Budget）
离子注入后，杂质原子停留在晶格间隙且硅晶格遭到严重轰击损伤（非晶化），必须通过退火：
1. 修复晶格损伤；
2. 让掺杂原子跳入硅晶格替位位置（电学激活，形成有效载流子）。

| 退火方式 | 升温/保温时间尺度 | 工程演进原因 |
| :--- | :---: | :--- |
| **炉管退火（Furnace）** | 数十分钟~小时 | 热预算极高，杂质会严重向外扩散，28nm 以下前段不再适用于源漏浅结激活 |
| **RTP / Spike Anneal** | 秒级（闪升闪降，Peak 仅毫秒~1秒） | 减少杂质扩散同时保证激活率 |
| **毫秒激光/闪光退火（LSA / Flash）** | **毫秒级** | 仅加热表层纳米级深度至接近熔点，在不让结深扩大的前提下将激活率推到极限 |

## 3. 离子注入（Ion Implantation）
将掺杂气体（如 $\text{AsH}_3, \text{PH}_3, \text{BF}_3$）电离成离子，通过电场加速并经质量分析磁铁选出单一纯净离子束，精准“打入”硅晶圆内部：

- **两个独立可控的核心参数**：
  - **注入能量（keV ~ MeV）** → 决定离子射程深度（Projected Range $R_p$），即**结深**。
  - **注入剂量（Dose, $\text{ions/cm}^2$）** → 由束流积分时间控制，决定**掺杂浓度**。
- **典型工程问题与对策**：
  - **沟道效应（Channeling）**：硅单晶原子排列存在通道，离子若垂直入射会沿着晶格走廊钻得过深导致拖尾。**对策**：将晶圆倾斜 **7° Tilt + Twist 旋转角**，或先用 Ge/Si 做预非晶化注入（PAI）。
  - **光刻胶掩模阻挡**：注意！注入束流能量过高时会把光刻胶打碳化（Crusting），导致后续湿法清洗难以剥离，必须配合灰化（Ashing）+ SPM 清洗。
  - **角度阴影效应（Shadowing）**：在 FinFET 高耸结构侧面做注入时，需要调整倾角和四面旋转注入（Quad Implant）才能覆盖鳍片两侧。
