# 《现代晶圆厂三维建模参考手册》
## 第二章：主要半导体制造设备详查与三维特征

---

### 2.1 半导体制造设备通用模块化解构（EFEM + 主机机架 + 反应腔）

在为晶圆厂三维建模时，切忌将设备当成一个铁板一块的金属长方体。现代绝大多数 300mm 晶圆处理设备（除光刻机和立式炉外）均遵循 **SEMI 模块化集群工具（Cluster Tool）** 架构。所有设备都由以下三大功能总成拼接而成：

```
+---------------------------------------------------------------------------------------+
|  [洁净走廊 Clean Bay 侧]                               [后廊维护区 Service Chase 侧]    |
|                                                                                       |
|  +--------------------+  +--------------------+  +---------------------------------+  |
|  | 设备前端模块 EFEM   |  | 真空过渡室 Loadlock|  | 主机真空传输室与反应腔 VTM & PM |  |
|  | (常压洁净微环境)     |  | (气密降压/抽真空)  |  | (高真空工艺反应区)              |  |
|  |                    |  |                    |                                 |  |
|  |  [LP1] [LP2] [LP3] |  |                    |          +-------------+        |  |
|  |  +---+ +---+ +---+ |  |  +----+    +----+  |          | 反应腔 PM1  |        |  |
|  |  | F | | F | | F | |  |  |LL 1|    |LL 2|  |          +------+------+        |  |
|  |  | O | | O | | O | |  |  +----+    +----+  |                 | 狭缝阀 Slit   |  |
|  |  | U | | U | | U | |  |    ||        ||    |          +------+------+        |  |
|  |  | P | | P | | P | |  |    ||        ||    |  +-------+ 真空机械手  +-------+|  |
|  |  +---+ +---+ +---+ |  |  +-------------+  |  |PM 3   |  (蛙腿/SCARA)|   PM 2||  |
|  |    |     |     |   |  |  | 狭缝隔离阀门|  |  +-------+ (VTM 核心)  +-------+|  |
|  |    V     V     V   |  |  +-------------+  |          +------+------+        |  |
|  |   [ 900mm 台面 ]   |  |                    |                 |               |  |
|  |                    |  |                    |          +------+------+        |  |
|  | 大气 SCARA 双臂机械手|  |                    |          | 反应腔 PM 4 |        |  |
|  | + 晶圆缺口对准寻心仪|  |                    |          +-------------+        |  |
|  +--------------------+  +--------------------+  +---------------------------------+  |
|            ^                                                      ^                   |
|            | 嵌穿 Bulkhead 隔墙封板线                              | 位于 Service Chase|
+------------+------------------------------------------------------+-------------------+
```

1. **EFEM（Equipment Front End Module，前端自动化装载模块）：**
   - **位置：** 永远面向 Clean Bay 洁净走廊，其前面板与厂房隔墙（Bulkhead）平齐镶嵌。
   - **尺寸：** 宽度根据装载口数量决定（2口：~1.2m；3口：~1.8m；4口：~2.4m），进深约为 0.8m - 1.1m，高度 2.2m - 2.6m。
   - **核心特征：** 顶部配有专用 mini-FFU 保持机内正压；正面安装 2 至 4 个标准 **SEMI E15.1 Load Port**；下部为钣金检修裙边与双向三色/四色信号灯塔（Signal Tower）；内部为一台 3 轴/4 轴大气晶圆装卸机械手（Atmospheric Dual-arm Robot）和一个光学缺口对准仪（Wafer Pre-Aligner）。

2. **Loadlock（真空过渡互锁室）：**
   - **作用：** 晶圆在大气压（1013 mbar）与高真空（$10^{-5}\text{ mbar}$ 以下）之间进出的缓冲闸门。
   - **机械外观：** 厚重的不锈钢/铝合金电镀厚壁腔体，上下两层叠放（Double-decker）或左右双腔并列。前后各配有一个细长矩形**气动狭缝隔离阀门（Slit Valve）**，开有大口径真空抽气法兰（连接 Subfab 的干泵）。

3. **VTM（Vacuum Transfer Module，真空传输室）与 PM（Process Module，工艺反应腔）：**
   - **VTM 外观：** 正五边形、正六边形或多边形不锈钢铸造真空筒体，中心轴线装有一台磁流体密封/磁悬浮双叶片真空机械手。
   - **PM 工艺腔体：** 沿多边形辐射状挂接在 VTM 的各个切面上（每个设备通常挂 2 到 8 个 PM 腔体）。每个腔体外表包裹着保温护罩、密布的气体质量流量计（MFC）供气歧管、高频射频同轴电缆、气动提升气缸以及观察等离子体辉光的石英视窗（Viewport）。

### 2.2 核心设备详细参数、几何尺寸与三维特征梳理

#### 1. 光刻系统 (Photolithography Tools)
光刻是晶圆厂中最昂贵、结构最庞大、精度最极致的设备，通常以 **“光刻机 + 涂胶显影机” 1:1 在线串联（In-line Track-Scanner Cluster）** 的形式联合运行。

##### (A) ASML TWINSCAN EUV 光刻机 (代表型号: NXE:3400C / NXE:3600D / EXE:5000)
- **工艺角色：** 7nm、5nm、3nm 及以下先进制程的核心曝光设备，采用 13.5nm 极紫外光源在晶圆表面纳米光刻胶上曝光纳米级集成电路图样。
- **总体外形与尺寸（洁净室暴露主体）：**
  - **宽 $\times$ 深 $\times$ 高：** 约为 **$3.2\text{m} \times 4.6\text{m} \times 3.2\text{m}$** [工程近似值]。
  - *(注：若计入底层 Subfab 的高功率驱激光器、高压氢气循环柜及供锡发生器，整套系统需要贯穿三层厂房，总长达 14m，重超 180 吨)*。
- **外形与表面材质：**
  - 机壳主体为哑光白色与极浅灰色（RAL 9003/9010）高平整度金属烤漆面板，表面无任何外露铆钉。
  - 侧面维护板带有磁吸或内嵌隐藏式铰链门，上部装有黑色亚克力控制集成屏与 ASML 蓝色发光 Logo。
  - 顶部配有专用的高洁净度过滤顶盖，上方直通天花板专用定制排气风道与重型减震吊梁。
- **正面特征：** 面向洁净室一侧设有专用的 EUV 掩模版传送盒（RSP, Reticle Smif Pod）独立装卸端口与晶圆双装载口，配备双触摸交互悬臂显示屏。
- **内部核心机械构件（若制作剖面透视动画）：**
  - **双工作台系统（Twinscan Stage）：** 两个可以在毫米级行程上以高达 5g 极速交替加速度移动的超轻陶瓷磁悬浮晶圆载物台（Wafer Stage）。台面上密布微小的晶圆真空吸盘撞针。一个工作台在真空曝光腔内以纳米步进进行脉冲激光扫描，另一个工作台同时在外部进行精密光学激光干涉对准与表面拓扑形貌测高（Leveling）。
  - **Zeiss 蔡司反射光学镜组（POB, Projection Optics Box）：** 内部为 6 至 8 块表面原子级粗糙度的超精密钼/硅（Mo/Si）多层反射镜，镜架由低膨胀因子的殷钢（Invar）或碳化硅陶瓷骨架支撑，四周包覆纯铜水冷吸热套板。
  - **激光锡等离子体光源（LPP EUV Source）：** 位于机身尾部/侧部，为一个高压真空金属圆筒，内部高频喷嘴每秒喷出 50,000 个熔融金属锡微滴，两束高功率二氧化碳（$\text{CO}_2$）激光在空中精准轰击锡滴引发等离子体爆炸，产生 13.5nm EUV 光。

##### (B) ASML TWINSCAN DUV 浸没式光刻机 (代表型号: NXT:1980Di / NXT:2050i)
- **工艺角色：** 成熟制程核心曝光及先进制程多重曝光（Multi-Patterning）与非关键层光刻，采用 193nm 氩氟（ArF）激光配合高纯超纯水（折射率 $n=1.44$）透镜浸没技术。
- **外形尺寸：** 约为 **$2.8\text{m}(\text{W}) \times 4.2\text{m}(\text{D}) \times 3.0\text{m}(\text{H})$** [工程近似值]。
- **特征结构：** 相比 EUV，DUV 机身更为紧凑。顶部装有巨大的准分子激光光束传输通道（Beam Delivery Tube，厚壁不锈钢高纯度充氮光路套管，从 Subfab 激光源穿过地板垂直连入光刻机顶部照度积分器）。浸没式机台在晶圆物镜下方带有一个蓝宝石材质的水滴约束微流道喷嘴（Immersion Hood）。

##### (C) 涂胶显影一体机 (Track / Coater & Developer - 代表厂商: Tokyo Electron TEL CLEAN TRACK LITHIUS Pro Z)
- **工艺角色：** 与光刻机通过硬件渡桥接口（Interface Block）无缝连接，负责曝光前的晶圆去水烘烤（Dehydration Bake）、涂底层抗反射膜（BARC）、高速旋转甩胶（Spin Coating）、曝光后烘烤（PEB）及显影清洗（Development）。
- **外形尺寸：** 整体呈细长列车状矩形，约为 **$2.2\text{m}(\text{W}) \times 5.5\text{m} - 6.2\text{m}(\text{D}) \times 2.6\text{m}(\text{H})$** [工程近似值]。
- **三维特征：**
  - **正面：** 4 个并行 SEMI E15.1 Load Port，外罩防黄光抗静电深茶色透视观察窗。
  - **内部结构（分层多单元立体架构）：** 机身内部是一条长达 5 米的中央封闭微环境直线搬送轨道，一台高速 3 轴轻量化直线电机驱动机械臂沿中轴线飞速滑动。两侧上下叠放着数十个独立的密闭处理圆盅单元：上层为旋转涂胶杯（Spin Cups）与显影杯，内含可做精密弧度摆动的微量注射泵喷嘴臂；中下层密集排列着几十个带气缸升降盖的圆形高精度热板（Hot Plates, $60^\circ\text{C}-250^\circ\text{C}$）与冷板（Chill Plates）。
  - **与光刻机交接：** 尾端带有专用的 Optical Interface Block，内部有缓冲冷却台，晶圆由此处的交接手臂直接递入 ASML 光刻机的晶圆装卸站。

#### 2. 等离子体刻蚀系统 (Plasma Etching Tools)
刻蚀设备用于将光刻胶定义的电路图形永久刻穿进晶圆表面的氧化硅、多晶硅或金属层。

##### 代表厂商与型号：
- **Lam Research（泛林半导体）：** Kiyo 系列（导体刻蚀）、Vector/Sense.i 系列（极高产出率模块化刻蚀平台）。
- **Applied Materials（应用材料）：** Centura AdvantEdge、Centura Producer Etch、Sym3 系列。

##### 典型尺寸与几何形态（以 Lam Sense.i / Kiyo 4腔集群机台为例）：
- **总体尺寸：** 约为 **$2.4\text{m}(\text{W}) \times 3.2\text{m}(\text{D}) \times 2.5\text{m}(\text{H})$** [工程近似值]。
- **几何结构：**
  - **前部（EFEM）：** 3 口 Load Port，机身呈标准浅灰色钣金，正面右上角悬挂三色状态灯柱与触摸屏工业电脑。
  - **中部（VTM 真空室）：** 多边形厚壁铝压铸真空室，顶盖带有一圈高压气缸铰链，供工程师掀开顶盖维护机械手。
  - **后部反应腔（Process Modules）：** 呈“U”形或对称伞形挂接在 VTM 侧方和后方。每个反应腔为一个直径约 600mm - 750mm、高约 800mm 的厚壁圆柱形金属罐，外壁紧贴各种传感器、管路与温控加热带。
- **腔体顶部核心视觉细节：**
  - **RF 匹配箱（RF Match Box）：** 安装在每个反应腔的正顶部或紧贴侧面，为一个闪亮的铝制长方体屏蔽盒，带镀银接地板与醒目的黄色“High Voltage RF Warning”闪电三角形危险标贴。
  - **进气喷淋盘（Showerhead）：** 顶部中央接入多组超纯不锈钢气体管线（Swagelok 接头，管径 1/4 英寸），通向内部密布微孔的硅/碳化硅气体喷淋盘。
- **内部核心机械构件：**
  - **静电吸盘（ESC, Electrostatic Chuck）：** 反应腔底部正中央为高纯氧化铝/氮化铝陶瓷电极圆盘，台面加工有阿基米德螺旋线微凹槽，用于向晶圆背面通入 5-20 Torr 的高纯氦气（He）做强制导热。中央开有 3 个呈 120° 排布的微型通孔，内部装有由底部微型气缸驱动的石英/陶瓷晶圆顶升销（Lift Pins，垂直行程约 15mm）。
  - **等离子体辉光（动画关键点）：** 刻蚀腔体通常带有耐高温蓝宝石玻璃观察窗，工作时内部展现高能辉光放电：
    - 含氯气体（$Cl_2, BCl_3$ 铝/硅刻蚀）：展现为明亮的**蓝绿色 / 蓝黄色辉光**。
    - 氟碳气体（$CF_4, C_4F_8$ 介质氧化硅刻蚀）：展现为神秘的**深紫色 / 蓝紫色辉光**。
    - 氧气去胶（$O_2$ Ashing）：展现为淡雅的**粉红白色 / 紫红色辉光**。

#### 3. 薄膜沉积系统 (Thin Film Deposition Tools: PVD / CVD / ALD)
负责在晶圆上生长或沉积极致均匀的介电层、金属阻挡层和互连导电层。

##### (A) Applied Materials Endura 300mm PVD (物理气相沉积 / 溅射机台)
- **工艺角色：** 铜互连阻挡层（Ta/TaN 种子层）、接触孔衬底（Ti/TiN）、硅化物底层（Co/Ni）的原子级溅射沉积。
- **外形尺寸：** 极为庞大的多腔集群平台，宽约 **$3.2\text{m}$**，深约 **$4.0\text{m}$**，高约 **$2.6\text{m}$** [工程近似值]。
- **外形与结构特征：**
  - **星形七边形/九边形结构：** 采用双真空传输室架构（Buffer Chamber + Transfer Chamber 级联），外围辐射状挂载多达 6 至 8 个大型加工腔室。
  - **阴极磁控靶材头（PVD Cathode Magnetron）：** 每个 PVD 腔室顶部都是一个重型金属圆锥形台体，内部装有高强钕铁硼永磁铁旋转电机机构，靶材头带有醒目的粗壮水冷绝缘高压电缆（黑色聚氨酯护套，管径可达 40mm）和气动提升重型平衡吊架。
  - **预清洗腔（Degas / Pre-Clean）：** 其中 1-2 个腔室为晶圆红外石英灯丝真空预热脱气腔与氩等离子体轻微反溅射清洗腔。

##### (B) Applied Materials Producer GT / XP (双腔并行 PECVD / ALD 平台)
- **工艺角色：** 沉积超薄氮化硅（$\text{Si}_3\text{N}_4$）、氧化硅（$\text{SiO}_2$）、超低介电常数材料（Low-k CDO）以及高介电常数金属栅极（High-k ALD）。
- **外形尺寸：** 约为 **$2.6\text{m}(\text{W}) \times 3.6\text{m}(\text{D}) \times 2.4\text{m}(\text{H})$** [工程近似值]。
- **结构标志性特征：**
  - **Twin-Chamber® 双生腔体设计：** 机身上挂载 3 个巨大的矩形双腔体模块（每个模块内部并排设置两个一模一样的晶圆加热反应底座，一次性并行处理 2 片晶圆，整机同时处理 6 片）。
  - **机身颜色：** 典型应用材料公司风格，银灰主色调搭配深蓝色或暗灰金属裙边，机壳棱角分明，侧面贴有醒目的白色“PRODUCER”立体铭牌。

#### 4. 化学机械抛光系统 (CMP - Chemical Mechanical Planarization)
CMP 是晶圆制造中唯一将化学腐蚀与机械磨削物理结合的湿法“平坦化”工艺，是实现多层布线必不可少的设备。

##### 代表厂商与型号：
- **Applied Materials（应用材料）：** Reflexion LK / Reflexion LK Prime 系列。
- **Ebara（荏原制作所）：** F-REX 300 系列。

##### 典型尺寸与几何形态（以 AMAT Reflexion LK 为例）：
- **外形尺寸：** 约为 **$2.2\text{m}(\text{W}) \times 3.8\text{m}(\text{D}) \times 2.4\text{m}(\text{H})$** [工程近似值]。
- **三维特征与机械组成：**
  - **前部：** 3 至 4 口 Load Port，内部配有全密封防水湿式晶圆搬送机械手。
  - **中部研磨区（Polishing Section，全透明耐腐蚀防护罩）：**
    - **大研磨盘（Platens）：** 底部并列分布着 **3 个巨大的水平圆形不锈钢研磨转盘**（直径约 750mm - 800mm），表面粘贴着粗糙多孔的聚氨酯抛光垫（IC1000 抛光垫，通常为灰白色或亮黄色）。研磨盘以 60 - 120 RPM 逆时针匀速旋转。
    - **多区压力抛光头（Titan Head）：** 悬挂在旋转横梁上的 **4 个圆形悬臂抛光夹持头**（直径约 320mm），下方利用气囊将晶圆面朝下紧紧吸附压在研磨垫上，一边自身以 60 - 100 RPM 高速自转，一边在研磨盘半径方向以 50mm - 80mm 的振幅来回做正弦扫动。
    - **研磨液供液喷臂（Slurry Arm）：** 弧形不锈钢喷管对准研磨盘中心偏内侧，持续喷洒乳白色胶状研磨液（二氧化硅或氧化铈纳米悬浮颗粒）。
    - **金刚石修整器（Pad Conditioner）：** 每个研磨盘旁设有一个带独立气动摇臂的小型旋转圆盘（直径约 100mm），表面电镀密集的金刚石颗粒，紧贴抛光垫做同向振荡修整，刮除微孔中的反应生成物残渣。
  - **后部清洗区（Integrated Cleaner）：** 研磨完毕的湿晶圆被直接送入后部的 Desica® 清洗模块，经历双面 PVA 纳米海绵滚刷刷洗（Megasonic 超声波纯水清洗）和马兰戈尼（Marangoni）异丙醇（IPA）蒸汽极速无痕干燥。

#### 5. 离子注入机与高温热处理系统 (Ion Implanter & Thermal Processing)

##### (A) 离子注入机 (Ion Implanter - 代表型号: Axcelis Purion / AMAT Varian VIISta)
- **工艺角色：** 将硼（B）、磷（P）、砷（As）等杂质离子在百万伏特高压电场中加速成高能粒子束，暴力轰入硅晶圆表层，精确改变晶体管局部导电特性。
- **外形尺寸：** 晶圆厂中占地最长、最厚重的设备之一，宽约 **$3.0\text{m}$**，深达 **$5.2\text{m} - 6.0\text{m}$**，高约 **$2.8\text{m}$**，重量往往超过 10 至 15 吨 [工程近似值]。
- **结构与部件（通常分为前后两大总成）：**
  - **前部洁净装载室：** 包含 Load Port、高速晶圆真空装载锁、以及装有精密静电夹盘的高速机械扫描工作台。
  - **后部射线与加速器机房（位于 Service Chase 或穿过墙体）：** 必须用重型钢结构框架与厚铅屏蔽板全封闭。内部包含高频等离子体离子源腔体（带有巨大绝缘陶瓷套管）、重达数吨的高磁场 90° 扇形磁铁分析器（用于剔除杂质同位素，保留特定荷质比离子）、多级高压静电加速线性管道（带金属环状均压极板）及静电四极透镜聚焦束线。

##### (B) 立式高温扩散与退火炉 (Vertical Furnace - 代表型号: TEL TELINDY Plus / Kokusai Vertron)
- **工艺角色：** 批次（Batch）热处理，一次可装载 100 - 150 片晶圆，用于湿氧/干氧热氧化长薄膜、多晶硅掺杂低压气相沉积（LPCVD）及晶格损伤高温退火。
- **外形尺寸：** 占地面积小但垂直极高，呈高耸的方柱形立柜，宽约 **$1.8\text{m}$**，深约 **$2.6\text{m}$**，高度往往高达 **$3.4\text{m} - 3.8\text{m}$** [工程近似值]。
- **标志性结构：**
  - **上部石英反应管道（Bell Jar）：** 位于机台顶端，为一个被五段独立电阻加热线圈包裹的倒扣高纯度石英/碳化硅玻璃钟罩反应膛，工作温度可达 $400^\circ\text{C} - 1200^\circ\text{C}$。
  - **下部升降机构与晶圆石英舟（Wafer Boat）：** 下方设有一个由精密伺服滚珠丝杠驱动的垂直升降托盘，托盘上竖立着一个由黑色碳化硅或透明石英雕琢而成的“多层晶圆舟塔”（内部开有 150 道密集卡槽）。动画中可展示晶圆舟缓缓从下方垂直升入炽热发红的石英炉膛中，底部圆形不锈钢隔热保温法兰紧紧顶压密封。

#### 6. 晶圆量测与表面缺陷检测设备 (Metrology & Inspection)

##### 代表厂商与型号：
- **KLA（科磊半导体）：** 29xx / 39xx 系列宽波段等离子体（BBP）高灵敏度图形晶圆缺陷检测系统、Voyager 系列暗场激光检测仪、Archer 700 纳米套刻误差测量系统。
- **Hitachi High-Tech（日立高新）：** CG6300 / CS4800 极低电压关键尺寸扫描电子显微镜（CD-SEM）。

##### 典型外形与视觉特征：
- **外形尺寸：** 宽约 **$1.8\text{m} - 2.2\text{m}$**，深约 **$2.4\text{m} - 2.8\text{m}$**，高约 **$2.4\text{m}$** [工程近似值]。
- **外观辨识度：**
  - 机器整体非常整洁封闭，宛如一台精致的现代科学实验室柜体。KLA 设备通常为优雅的暖白色或深蓝色与银色相间。
  - **防电磁与声学屏蔽罩：** 机箱侧面常挂装高灵敏度消磁线圈阵列（Helmholtz Coils），机脚带有主动压电防震伺服马达。
  - CD-SEM 顶端突出有一根小型立式电镜镜筒（带有二次电子探测器、高压偏转极板与高真空潘宁冷阴极离子真空计）。
  - 操作台旁通常并排放置一组带双联大尺寸工业液晶显示器和人体工学轨迹球键盘的操作控制岛（Console Island），用于工程师实时调阅晶圆缺陷图谱（Wafer Defect Map）和局部纳米级 SEM 电子显微镜扫描成像照片。
