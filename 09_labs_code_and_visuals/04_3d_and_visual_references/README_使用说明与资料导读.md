# 《现代晶圆厂三维建模参考手册》使用说明与资料导读

### 一、资料包简介 (Package Overview)

本压缩包为 **《现代晶圆厂三维建模参考手册》（300mm/12英寸先进制程 Wafer Fab 工业级建模与科普动画全套技术指引）** 的完整交付包。

本套资料专为 3D 艺术家、动画导演以及自动化 AI 建模系统设计，旨在解决半导体晶圆厂三维建模中普遍存在的“概念科幻化、结构不符合实际、设备尺寸失真、工艺流程混淆”等问题。全书紧扣国际半导体设备与材料协会（SEMI）标准，参考台积电（TSMC）、英特尔（Intel）、阿斯麦（ASML）、应用材料（AMAT）、泛林半导体（Lam Research）、东京电子（TEL）等真实厂房与设备参数编写。

### 三、建议阅读与建模执行顺序

1. **第一步（全局统揽）：** 阅读 `INDEX_全景知识库总览.md`，建立对整座晶圆厂各系统比例、标高和核心数值的整体认知。
2. **第二步（空间骨架搭建）：** 阅读 `01_晶圆厂建筑结构与空间布局指南.md`，在 Blender 中建立 1:1 公制米的世界场景，搭建华夫板、架高地板网格、Bay & Chase 走廊与 Bulkhead 隔墙。
3. **第三步（机台与物流布设）：** 阅读 `02_主要半导体制造设备详查与三维特征.md` 和 `06_Blender场景分层_模型资产库与着色材质规范.md`，制作标准 Load Port 预制件，摆放各工艺机台白模，拉设 OHT 天车天轨。
4. **第四步（材质调优与渲染）：** 按照 `06` 分册中的着色器节点图，调配黄光走廊、硅晶圆薄膜干涉镜面、茶色 FOUP 晶圆盒以及等离子体辉光。
5. **第五步（动画编排与运镜）：** 结合 `03_晶圆制造工艺流程与设备流转逻辑.md` 的 12 幕分镜剧本与 `04_自动化物流与机械机构动态运行规范.md` 的机械动作时序，为天车抓手、晶圆搬送手臂及反应腔狭缝阀打上流畅的关键帧。

### 四、关键工业标准与工程数值速记卡

- **晶圆尺寸：** 直径 $\Phi 300\text{mm}$，厚度 $775\,\mu\text{m}$。
- **FOUP 晶圆盒：** 外包络 $420\text{mm}(\text{W}) \times 350\text{mm}(\text{D}) \times 338\text{mm}(\text{H})$，内部 25 层，间距（Pitch）恒定为 $10.0\text{mm}$。
- **Load Port 装载标高（SEMI E15.1）：** 距架高地板表面严格恒定为 **$900\text{mm} \pm 10\text{mm}$**。
- **架高穿孔地板：** $600\text{mm} \times 600\text{mm}$ 铝合金板，架空高 $600\text{mm} - 900\text{mm}$。
- **洁净室净空高：** 架高地板至天花板 FFU 滤网面净高 **$4.2\text{m} - 4.8\text{m}$**；Subfab 净空高 **$4.5\text{m} - 6.0\text{m}$**。
- **OHT 天车标高：** 轨道悬挂高度距架高地板 **$3.2\text{m} - 3.8\text{m}$**。
- **光刻照明环境：** 严格采用 **589nm 单色琥珀金黄光**（严禁混入紫外与蓝光波段）。
