# 《现代晶圆厂三维建模参考手册》
## 第一章：晶圆厂整体建筑结构与空间布局指南

### 1.1 现代12英寸（300mm）晶圆厂垂直空间分层结构（4层三明治架构）

现代先进制程（300mm/12英寸）晶圆厂（Wafer Fab）并非单一平层的工业厂房，而是一座为了实现极致洁净度、抗微震性以及海量动力管线集成而设计的**垂直多层三明治建筑系统**。在 Blender 建模时，必须建立准确的垂直标高剖面关系。

```
+-------------------------------------------------------------------------+ 标高: +16.0m ~ +18.0m
|  顶层空气处理静压层 (Fan Deck / Recirculation Plenum)                     | 层高: ~3.5m - 4.5m
|  - RAHU 回风循环机组 / 轴流风机阵列                                        |
+=========================================================================+ 标高: +12.5m (吊顶标高)
|  FFU / ULPA 滤网天花板网格 (满布率 25% - 80%)                              |
|-------------------------------------------------------------------------|
|  洁净室核心生产层 (Cleanroom Process Floor)                              | 层高: ~4.5m - 5.5m
|  - 清洁走廊 (Clean Bay, 589nm黄光/白光)                                   | (净空高: ~3.8m - 4.5m)
|  - 设备维护后廊 (Service Chase / 灰区)                                   |
|  - 天顶悬挂 AMHS OHT 天车导轨系统 (距地板 3.2m - 3.8m)                    |
+=========================================================================+ 标高: +7.0m ~ +8.0m
|  华夫板 (Waffle Slab, 厚度 0.8m - 1.2m, 密集圆形/方形落风孔)              |
|  架高地板 (Raised Access Floor, 600x600mm 铝合金穿孔板, 离地 0.6m - 0.9m)  |
+-------------------------------------------------------------------------+ 
|  辅助动力设备层 (Subfab / 洁净下层)                                       | 层高: ~4.5m - 6.0m
|  - 干泵阵列 (Dry Vacuum Pumps)、温控冷水机 (Chillers)                      |
|  - 尾气等离子/电热处理装置 (POU Point-of-Use Scrubbers)                  |
|  - 射频电源柜 (RF Generators)、二次配管配线 (Hook-up Manifolds)           |
+=========================================================================+ 标高: +2.0m ~ +2.5m
|  底层动力与基础管网层 (Basement / Facility Level)                         | 层高: ~3.5m - 5.0m
|  - 工业酸碱废液中和池 (Acid/Base Neutralization Tanks)                   |
|  - 超纯水 (UPW) 主循环管道、大口径排风总管 (General/Acid/VOC Exhaust)     |
|  - 巨型独立防震柱基础群 (Isolated Tool Plinths)                           |
+-------------------------------------------------------------------------+ 标高: ±0.000m (地基岩层)
```

#### 垂直分层核心工程参数与建模指导：
1. **顶层静压箱与回风层 (Plenum / Fan Deck)：**
   - **尺寸参考：** 净高 3.5m - 4.5m。
   - **可见构造：** 密布的大口径冷热水循环主管（保温层包裹，银白色铝皮或绿色环氧漆，管径 $\Phi 300\text{mm} - \Phi 600\text{mm}$）、新风补给风管（矩形镀锌铁皮风管，横截面可达 $2000\text{mm}\times 1200\text{mm}$）、密集的电缆桥架。
   - **天花板吊顶：** 由结构钢吊杆（直径 12mm - 16mm 螺杆）吊挂的重型铝合金 T-Bar 天花龙骨。龙骨间距标准为 $1200\text{mm} \times 600\text{mm}$ 或 $1200\text{mm} \times 1200\text{mm}$。
   - **FFU（风机过滤单元）：** 尺寸通常为 $1175\text{mm} \times 575\text{mm} \times 320\text{mm}$ 或 $1175\text{mm} \times 1175\text{mm} \times 350\text{mm}$，内部含离心风机与 ULPA 滤网（超高效空气过滤器，过滤效率 99.9999% @ 0.12µm）。

2. **洁净室生产层 (Cleanroom Process Floor)：**
   - **净空高度：** 从架高地板到 FFU 滤网下表面通常为 **4.2m 至 4.8m**（为容纳 EUV/高耸设备与双层 OHT 轨道留出充足余量）。
   - **微环境等级：**
     - 光刻胶涂布/曝光核心区：ISO Class 1 ~ Class 3（美标 Class 1），单向垂直层流。
     - 晶圆盒内部（FOUP 内部）：ISO Class 1 级别超净微环境（填充超纯干燥氮气 $\text{N}_2$ 或极限过滤洁净空气 CDA）。
     - 洁净走廊（Clean Bay）：ISO Class 4 ~ Class 5（美标 Class 10 ~ 100）。
     - 设备维护后廊（Service Chase）：ISO Class 6 ~ Class 7（美标 Class 1,000 ~ 10,000，属于灰区/半洁净区）。

3. **结构华夫板 (Waffle Slab) 与抗震地基：**
   - **结构本质：** 厚度达到 **800mm 至 1200mm** 的现浇双向正交高刚度钢筋混凝土实心板。
   - **开孔特征：** 华夫板表面呈矩阵状开辟有垂直通孔（圆孔直径一般为 $\Phi 400\text{mm} - \Phi 500\text{mm}$，或 $450\text{mm}\times 450\text{mm}$ 方孔），开孔率通常在 25% 至 40% 之间。气流穿过架高地板后，经由此孔洞直接排入 Subfab。
   - **立柱网格：** 支撑华夫板的重型混凝土巨柱间距通常为 **$6.0\text{m} \times 6.0\text{m}$**、**$6.0\text{m} \times 9.0\text{m}$** 或 **$9.0\text{m} \times 9.0\text{m}$**，立柱断面一般为 $800\text{mm} \times 800\text{mm}$ 到 $1000\text{mm} \times 1000\text{mm}$。
   - **防微震基座（Inertia Block / Plinth）：** 针对光刻机（ASML Twinscan）、透射电镜（TEM）、关键量测仪（CD-SEM）等极限敏感设备，其下方的华夫板往往开出独立结构槽，安装与大楼主体结构物理断开的**独立重型混凝土防震浮筑块**，下垫气动减震器（Air Springs）或主动电磁式压电防震平台（Active Vibration Cancellation），以满足 VC-D 或 VC-E（振动速度小于 $3\,\mu\text{m/s}$）的严苛抗微震标准。

4. **辅助动力设备层 (Subfab)：**
   - **净空高度：** 通常为 **4.5m 至 6.0m**。
   - **视觉特征：** 机械密集、钢铁管线丛生的高密度工业空间。顶部为华夫板底面，下垂成千上万根真空波纹管、特氟龙化学管、超纯水不锈钢管和防静电排气管。
   - **主要设备群：**
     - **干式真空泵群（Dry Vacuum Pumps）：** 标配厂商为 Edwards、Pfeiffer、Ebara。尺寸约为 $450\text{mm}(\text{W}) \times 800\text{mm}(\text{D}) \times 650\text{mm}(\text{H})$ 的紧凑箱体，常采用双层或三层立体钢构架高层架摆放。
     - **尾气处理洗涤器（POU Scrubbers）：** 标配厂商为 DAS、Centrotherm、Ebara。通常为高达 1.8m - 2.2m 的立式圆柱形或矩形金属机柜，顶部连接厚壁不锈钢排气歧管。
     - **循环冷却水温控机（Chillers / Heat Exchangers）：** 维持工艺腔体在 $\pm 0.1^\circ\text{C}$ 精度的工业水冷机柜。

现代晶圆厂核心洁净室普遍采用 **Bay & Chase（工作湾与维护后廊并列）** 布局，而非开敞大通铺（Open Ballroom）。此架构对于三维建模的墙体搭建具有决定性意义。

#### 关键空间结构元素与建模尺寸规范：
1. **封板隔墙（Bulkhead Wall）：**
   - **作用：** 将设备截成“前脸”与“后躯”两部分。设备的前端晶圆装载模块（EFEM, Equipment Front End Module）直接嵌在洁净湾隔墙的矩形切口内；而笨重、散热量大、需要频繁换件检修的真空腔体、气体管路、阀岛及电气柜全部位于隔墙后方的 Service Chase。
   - **材质外观：** 50mm 厚高平整度双面彩钢夹芯洁净板（白色聚酯涂层，哑光反射），拼接缝采用防霉中性硅酮密封胶嵌缝（胶缝宽 4mm - 6mm）。
   - **设备开口：** 设备与墙体开口边缘配有定制的连续硅胶气密密封压条（Gasket）及不锈钢收边不锈钢压角，保证微差压密封。

2. **走廊与通道尺寸体系：**
   - **Clean Bay 洁净走廊宽度：** **3.6m 至 4.8m**。正中央上方悬挂 OHT 天车导轨，两侧留出至少 1.2m 的人行操作宽度，保证两名身穿洁净服的工程师并排走动或推动手动晶圆转运推车。
   - **Service Chase 维护后廊宽度：** **2.4m 至 3.6m**。中间保留至少 0.9m - 1.2m 的纯净无障碍通道，用于推移重型真空泵、分子泵吊装小车或更换靶材/反应腔衬套（Chamber Liners）。
   - **Main Spine Boulevard（物流中央主轴干道）：** **4.8m 至 6.0m**。通常横贯整座厂房，连通所有的 Bay，天花板下安装双向多股 OHT 主线轨道与道岔（Switching Points），地面设有紧急安全疏散通道与防静电环氧地坪引导线。

3. **架高地板系统（Raised Access Floor System）：**
   - **规格基准：** 国际通用标准为 **$600\text{mm} \times 600\text{mm}$** 见方模块，厚度 50mm - 55mm。
   - **材质：** 高压压铸防静电铝合金地板，表面贴覆防静电 PVC 贴面或导电环氧粉末涂层（浅灰色，高光至半光，漫反射率约 0.65）。
   - **开孔形态：**
     - 盲板（Solid Tile）：用于人行主干道与设备正前方站立区，无孔。
     - 穿孔板（Perforated Tile）：用于回风区，表面布满圆形倒角密集阵列小孔（如 $\Phi 8\text{mm} - \Phi 12\text{mm}$ 孔径），开孔率 25% 至 40%，部分背面带有风量微调调节阀（Damper）。
     - 格栅板（Grated Tile）：开孔率可达 50% - 65%，多用于气流返流要求极高的高发热设备周边。
   - **支撑结构：** 地板四角由镀锌钢/不锈钢可调支架（Pedestal，立杆直径 $\Phi 25\text{mm} - \Phi 32\text{mm}$，底部膨胀螺栓锚固在华夫板上）配合横梁（Stringer，方钢规格 $20\text{mm}\times 30\text{mm}$）组装成网格架构。

### 1.3 核心工艺区域空间功能划分与环境特征

晶圆厂各区域并非同质化空间，各自有其鲜明的环境、照明及气流特征。在三维渲染与模型布设中必须做出显著区分：

| :--- | :--- | :--- | :--- | :--- | :--- |

### 1.4 自动化物料搬送系统（AMHS）空间几何与机械接口

现代 300mm 晶圆厂已全面淘汰人工搬运裸片，全部依靠 **AMHS（Automated Material Handling System）** 悬挂天车系统与封闭晶圆盒（FOUP）在三维立体空间穿梭流转。

#### 关键部件工程规格与建模参考：
1. **OHT 轨道系统（Monorail Track）：**
   - **悬挂高度：** 轨道下沿距离架高地板表面通常为 **3.2m 至 3.8m**。
   - **截面尺寸：** 采用高强度阳极氧化挤出铝型材，截面宽度约为 **80mm - 120mm**，高度约为 **150mm - 200mm**。轨道侧面开有连续导向槽，底部有供夹爪与吊索下落的开口缝隙。
   - **供电与通信：** 普遍采用非接触感应供电（HID, High Inductive Power Distribution），无滑触磨损产尘碳刷；轨道侧方贴有光反射条码带与红外/微波射频定位标记块。
   - **分支道岔（Track Switch）：** 在 Bay 走廊与 Main Spine 交叉处，设有高速电磁摆臂道岔，天车无需减速即可变道。

2. **FOUP 晶圆转运盒（Front Opening Unified Pod - SEMI E47.1 标准）：**
   - **外形尺寸：** 宽度 **$415\text{mm} - 426\text{mm}$**，深度 **$342\text{mm} - 355\text{mm}$**，高度 **$338\text{mm}$**（含顶部提手）。
   - **结构细部：**
     - **顶部法兰（Top Handling Flange）：** 呈倒“T”字形或阶梯状多边形聚碳酸酯把手，专供 OHT 机械手水平滑入夹紧。
     - **前门板（Door）：** 带有双内六角/异形扭转锁孔（SEMI E62 标准接口），门边缘内嵌氟橡胶高弹性气密环。
     - **盒体材质：** 整体为防静电、低释气的碳纤维掺杂聚碳酸酯（ESD Polycarbonate），呈半透明深烟灰色、深茶色或琥珀色，可隐约透光看见内部水平插放的 25 片硅晶圆。
     - **内部结构：** 两侧内壁铸有 25 组间距极小的支撑卡齿（Pitch 间距恒定为 **$10\text{mm}$**），晶圆仅边缘 3mm 接触卡槽。
     - **底部构件：** 底盘嵌有 3 组沿中心呈 120° 放射状分布的“V”型定位凹槽（Kinematic Coupling Grooves, 符合 SEMI E57 标准），以及充放高纯氮气用自封微型气阀（Purge Nozzles）。

3. **晶圆盒储存立库（Stocker）与在轨缓冲架（Under-Track Buffer, UTB）：**
   - **Stocker（自动化晶圆立库）：** 类似于大型自动化立体仓库，外形为一个巨型全封闭钣金长方体机房（长可达 10m - 30m，宽 3m - 4m，高 4m - 5m），直接贯穿架高地板。内部设有一台或两台超高速双立柱堆垛机械手，两旁为成百上千个存放 FOUP 的蜂窝货架，外侧配备与 OHT 对接的出入库专用 Load Port。
   - **UTB / STB（轨下/轨侧缓冲支架）：** 悬挂在 OHT 轨道正下方或侧方、不占用地面的轻量化悬臂金属平台，离地高约 2.2m - 2.5m。天车可将暂时无需加工的 FOUP 就近下放暂存在半空中，极大缩短干线运输排队延迟。
