# 分岗位学习路径指南（Role-Based Tracks）

不同岗位的切入点差异很大，建议遵循**“全厂通识（20%）+ 本职核心模块精研（80%）”**的策略：

| 目标方向 | 核心必学目录（深挖） | 辅修了解目录（通识） | 推荐实战输出 |
| :--- | :--- | :--- | :--- |
| **工艺整合工程师 (PIE)** | `01` 器件物理<br>`03` 全七大工艺<br>`04` FEOL/MOL/BEOL 整合<br>`07` WAT/良率归因 | `05` 设备基础<br>`08` 成本影响 | 绘制完整工艺 Split Table 与 Cross-section 剖面图 |
| **单项工艺工程师 (PE)** | `03` 中对应自身模块（如光刻/刻蚀/薄膜）<br>`07` SPC/DOE/FDC | `01` 器件影响<br>`04` 上下游衔接<br>`05` 腔体结构 | 针对特定工艺缺陷写 3 篇 DOE 与 Troubleshooting 分析 |
| **设备工程师 (EE / 装机维护)** | `02` 厂务接口与 EHS<br>`05` 机台架构与核心零部件<br>`06` E10/E84 接口 | `03` 对应机台工艺机理<br>`07` FDC 异常信号 | 拆解 RF/真空/气路/传片机械手故障树（Fault Tree） |
| **厂务工程师 (Facility)** | `02` 洁净室/UPW/特气/CDS/HVAC/EHS<br>`08` 能耗与 OpEx | `03` 各工艺对水电气耗量要求<br>`05` Sub-Fab 辅机配置 | 整理 Fab 动力需求矩阵与 Hook-up 接口规范 |
| **CIM / MES / AMHS 工程师** | `06` OHT/Stocker + SECS/GEM + MES/EAP/RTD/APC<br>`09` 协议模拟脚本 | `04` Re-entrant 流程<br>`05` Load Port / EFEM<br>`08` Cycle Time/派工 | 用 Python 实现 SECS-II 消息编解码或 E84/E10 状态机 |
| **良率分析 / FA 工程师 (YE / FA)** | `07` 良率模型/SPC/WAT/CP/FA<br>`09` Python 良率与图像分析 | `01` 器件失效机理<br>`03` 常见工艺缺陷来源<br>`04` 整合链路 | 用 Python 做 Wafer Map 模式识别与相关性归因 Demo |
| **行业研究 / 科普 / 3D 可视化** | `02`、`03`、`04` 全流程直觉<br>`05` 设备厂商图谱<br>`08` 经济账与材料供应链<br>`09` 流程图与 3D 规范 | `06` 天车物流视觉逻辑<br>`07` 良率对单颗芯片成本的影响 | 输出行业专题长文、Mermaid 工艺图或三维厂房拆解规范 |
