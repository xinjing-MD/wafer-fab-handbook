# 晶圆厂成本经济账、单颗芯片成本与工业工程（IE）KPI

- **所属模块**：`08_fab_operations_and_industry / 01_fab_economics_and_ie`

## 1. 为什么说晶圆厂是极致重资产行业？
1. **CapEx（资本支出）惊人，其中设备占 70%~80%**：一座月产 3~5 万片 12 寸先进制程晶圆厂投资常高达百亿至两百亿美元，土建洁净室约占 20%~25%，精密工艺与量测设备占大头（其中单台 EUV 光刻机即数亿美元）。
2. **折旧是晶圆制造最大的固定成本**：行业常见会计折旧周期为 5~7 年。无论晶圆厂是否接满订单，每天折旧费用都在刚性发生——因此**产能利用率（Utilization）低于 ~70%~75% 时，毛利率会断崖式下跌**。

## 2. 单颗合格芯片制造成本的底层公式

$$\text{Cost per Good Die} = \frac{\text{Wafer Cost}}{\text{Gross Die per Wafer} \times Y_{CP}}$$

- **Wafer Cost（晶圆代工加工费 + 硅片材料）**：随制程节点提升，掩模步骤和 EUV 曝光次数翻倍，300mm 晶圆加工单价从成熟节点的千美元级跃升至 3nm/2nm 的近两万美元级。
- **Gross Die per Wafer（单片毛芯片数）**：300mm 晶圆可用直径扣除边缘禁区（Edge Exclusion，通常 3mm）后，矩形芯片尺寸越大，边缘浪费的残缺面积越多（大尺寸 GPU 往往一片只切出几十颗，而小尺寸 MCU 可切上万颗）。
- **良率杠杆效应**：当单片成本固定时，CP 良率从 `50%` 提升到 `90%`，相当于单颗好芯片的制造直接成本几乎腰斩！

## 3. 晶圆厂工业工程（IE）核心运营指标

| 指标 | 含义与管理核心 |
| :--- | :--- |
| **WSPM / KSPM** | 月投片量（Wafers Starts Per Month / 千片月产能），衡量 Fab 规模的常见单位（如 100K/M 代表月产 10 万片） |
| **OEE（设备综合效率）** | $\text{OEE} = \text{Availability(稼动率)} \times \text{Performance(性能效率)} \times \text{Quality(良率)}$ |
| **Cycle Time（生产周期）** | 一批晶圆从投片到出厂的总时间，通常用 **X-Factor = 实际 Cycle Time / 理论纯加工时间** 衡量（优秀 Fab 控制在 1.8~2.5 倍左右） |
| **Bottleneck（瓶颈管理 / TOC）** | 全厂最贵且最繁忙的往往是**光刻区（特别是 EUV/ArFi）**。瓶颈机台停机 1 小时，全厂产出就永久损失 1 小时；非瓶颈区则需保留缓冲避免 WIP 堆积 |
