# 原子层刻蚀（ALE）与自对准接触孔（SAC）工艺难点

- **所属模块**：`03_七大核心工艺 / 02_刻蚀与清洗`

---

## 1. 为什么常规持续等离子体刻蚀满足不了 3nm / 2nm GAA？

进入 $3\,\text{nm}/2\,\text{nm}$ **GAA Nanosheet（全环绕栅极纳米片）** 世代，单层硅纳米片导电沟道厚度仅 **$5\sim 7\,\text{nm}$**，相邻两片硅沟道垂直释放间隙仅 **$8\sim 12\,\text{nm}$**，保护侧漏的内侧墙（Inner Spacer）更是薄至 $4\sim 6\,\text{nm}$。在如此接近原子尺度的微结构上，传统连续放电等离子体刻蚀（Continuous RIE）面临三大不可逾越的物理失效门槛：

1. **亚表面晶格损伤（Sub-surface Damage）**：连续 RIE 中高能离子（$100\sim 500+\,\text{eV}$）直击硅晶格，会在表面撞出厚达 **$2\sim 4\,\text{nm}$ 的非晶化损伤与杂质嵌入层**——对于总厚度仅 $6\,\text{nm}$ 的 GAA 纳米片，表层毁坏 $2\,\text{nm}$ 将直接令器件迁移率断崖式下跌！
2. **微负载效应与 ARDE 失效**：反应气体与离子同时轰击时，密集 SRAM 区与稀疏逻辑区发生自由基争夺，且深窄沟槽刻蚀明显滞后（RIE Lag），导致同一晶圆不同区域的过刻蚀量失控。
3. **纳米级停止选择比天花板**：当底部高-$k$ 栅介质或阻挡层厚度只有 $1\sim 2\,\text{nm}$ 时，连续 RIE 稍有过冲即发生毁灭性击穿。

## 2. 原子层刻蚀（ALE, Atomic Layer Etch）的自限制循环机理

**ALE 是 ALD（原子层沉积）的完美逆过程**：将耦合在同一时间发生的高能混杂反应，拆分为“**自限制表面化学改性 $\to$ 吹扫 $\to$ 亚阈值选择性剥离 $\to$ 吹扫**”的离散闭环。每个循环精准剥落 **$0.3\sim 0.7\,\text{nm}$（约 $1\sim 2$ 个单原子层）** 并在耗尽改性层后自动归零！

### （1）定量准则：Kanarik ALE 协同度（Synergy）与能量窗口
Lam Research 的 **Keren J. Kanarik 与 R. A. Gottscho** 等人（*JVSTA*, 2017）提出了衡量 ALE 循环纯度的标准定量公式——**协同度 $S$**：
$$S = \frac{\text{EPC} - (\alpha + \beta)}{\text{EPC}} \times 100\%$$
其中 $\text{EPC}$（Etch Per Cycle）为每周期刻蚀厚度；$\alpha$ 为单独通入改性步骤时的不期望自发化学掏蚀量；$\beta$ 为单独执行剥离步骤时的不期望纯物理溅射损失。理想自限制 ALE 要求 $\alpha \approx 0, \beta \approx 0$，协同度 $S \to 100\%$。

以最具代表性的**各向异性硅 ALE（$\text{Cl}_2$ 改性 + $\text{Ar}^+$ 脱附）**为例，其四步精密工艺流如下：
1. **步骤 A（表面氯化吸附改性）**：通入 $\text{Cl}_2$ 等离子体自由基（无偏压），氯原子与最表层硅原子发生 Langmuir 自限制饱和吸附生成 **$\text{SiCl}_x$** 改性层。强电负性氯原子抽取键合电子，将最外层与下层纯硅之间的键能大幅削弱（纯硅表面结合能约 **$4.7\,\text{eV}$**），一旦铺满单层即停止向体相深处穿透（$\alpha \approx 0$）。
2. **步骤 B（抽真空吹扫 Purge）**：将腔体内残余未吸附的氯气彻底抽空，严防下步物理与化学混杂反应发生。
3. **步骤 C（窄能谱低能离子轰击脱附）**：通入 $\text{Ar}^+$ 离子，将离子能量精准压入 **ALE 工艺窗口（$E_{\text{th,mod}} < E_i < E_{\text{th,bulk}}$）**——针对 $\text{Si}-\text{Cl}_2/\text{Ar}^+$ 体系，文献标定的最优工作窗口约为 **$30\sim 55\,\text{eV}$**（在 $50\,\text{eV}$ 附近测得协同度 **$S = 90\%$**）：该能量恰好足以敲断削弱了的 $\text{Si}-\text{SiCl}_x$ 表面键使其以 $\text{SiCl}_x\uparrow$ 挥发，但**绝不足以敲碎下方纯净晶体硅的 $\text{Si}-\text{Si}$ 键（溅射阈值 $> 50\sim 60\,\text{eV}$）**！
4. **步骤 D（吹扫归零停刻）**：一旦表面 $\text{SiCl}_x$ 改性单层全部剥尽，刻蚀速率自动归零（$\beta \approx 0$）。哪怕延长轰击时间等待深窄沟槽最慢的位置剥完，浅槽区也不会多刻掉哪怕一个原子——**从物理根源彻底消除微负载效应与 RIE Lag**！

> **介质定向 ALE（$\text{SiO}_2 / \text{Si}_3\text{N}_4$）**：步骤 A 改用脉冲 $\text{C}_4\text{F}_8$ 等离子体沉积埃级碳氟表面改性薄膜，步骤 C 通低能 $\text{Ar}^+$ 触发局部反应生成挥发性 $\text{SiF}_4/\text{CO}$ 脱附，应用于先进金属接触孔破底及极薄硬掩模开窗。

### （2）热各向同性 ALE（Thermal Isotropic ALE）与 GAA 纳米片通道释放
对于 3D 堆叠的 GAA 纳米片，竖直方向飞行的离子根本无法绕进水平叠片之间的狭窄夹缝。业界依赖 **Steven M. George** 团队奠基的**纯热化学配体交换 ALE** 以及高选择比各向同性气相刻蚀技术：
- **双脉冲配体交换机理（如 $\text{Al}_2\text{O}_3 / \text{HfO}_2$ 热 ALE）**：Step 1 脉冲通入氟化剂（如 $\text{HF}$）把金属氧化物表层转为金属氟化物；Step 2 脉冲通入有机金属配体前驱体（如三甲基铝 $\text{Al(CH}_3)_3$ TMA 或 $\text{Sn(acac)}_2$），在 $150\sim 300^\circ\text{C}$ 下发生热力学配体交换形成易挥发配位络合物脱附，实现**3D 任意死角全向保形、绝对零离子损伤、埃级精准减薄**。
- **GAA 纳米片沟道释放（Channel Release）**：外延生长多层交替 $\text{Si} / \text{Si}_{0.7}\text{Ge}_{0.3}$ 超晶格后，需从侧面钻入把牺牲层 $\text{SiGe}$ 全部掏空、留下悬空纯硅纳米片通道！采用无离子损伤的热气相（如无水 $\text{HCl} / \text{ClF}_3$ 或远程 $\text{NF}_3$ 等离子体）或高精度湿法选择刻蚀，借助 $\text{Ge}$ 显著降低键合活化能的特性，实现 **$\text{SiGe} : \text{Si}$ 选择比超过 $100:1$**，保护纳米片零厚度损失与 $\text{SiBCN}$ 内侧墙完好。

### （3）量产产能权衡：Hybrid Etch（混合刻蚀策略）
单周期 ALE 包含通气、平衡、吹扫和脱附步骤，耗时约 $5\sim 15\,\text{s/cycle}$，对应有效平均刻蚀速率仅 $2\sim 5\,\text{nm/min}$。若整槽 $50\,\text{nm}$ 全靠 ALE 刻完，单片耗时逾 $15\,\text{min}$ 将彻底拖垮整厂 WPH。因此 12 寸产线的标准方案是 **同腔室混合刻蚀（In-situ Hybrid RIE + ALE）**：前 $85\%\sim 90\%$ 深度由高速连续 RIE 完成，距最终停止界面仅剩 **$3\sim 8\,\text{nm}$** 时原位切入 ALE 步精准收尾并剥离前序受损晶格层。

## 3. 自对准接触孔（SAC, Self-Aligned Contact）化学选择比与失效防御

在 $14\,\text{nm}$ 以下 FinFET 与 GAA 器件中，栅极节距（CPP）缩至 $42\sim 54\,\text{nm}$，金属栅与相邻源漏接触孔（M0/CA）物理间隙已经小于光刻机套刻误差极限——一旦光刻偏移使接触孔半压在栅极上方，常规刻蚀会直接刻穿金属栅导致**栅-源/漏致命短路（Gate-to-Contact Short）**。

### 超高 $\text{SiO}_2 / \text{Si}_3\text{N}_4$ 选择比（$> 20:1\sim 30:1$）的“氧清道夫”机理
SAC 刻蚀的化学魔术在于：使用高碳氟比（High C/F Ratio）气体如 **$\text{C}_4\text{F}_6$（$\text{F}/\text{C} = 1.5$）、$\text{C}_4\text{F}_8$** 搭配 **$\text{CH}_2\text{F}_2 / \text{O}_2 / \text{Ar}$**，在同一腔室内同时实现“猛吃氧化硅，完全停在氮化硅上”：
1. **$\text{SiO}_2$ 表面（晶格氧清道夫效应 Oxygen Scavenging）**：当 $\text{CF}_x$ 自由基在 $\text{SiO}_2$ 表面成膜时，高能离子撞击氧化物晶格释放出丰富的**晶格氧原子（$\text{O}^*$）**。晶格氧迅速将沉积的富碳聚合物氧化气化为 $\text{CO}$、$\text{CO}_2$ 与 $\text{COF}_2$ 抽走，使 $\text{SiO}_2$ 表面保护聚合物始终维持在极薄的动态平衡态（$< 1\sim 2\,\text{nm}$），刻蚀持续高速向下推进。
2. **$\text{Si}_3\text{N}_4$ 栅帽表面（富碳聚合物厚盾封锁）**：$\text{Si}_3\text{N}_4$ 晶格中**完全不含氧原子**！无法消耗掉沉积的 $\text{CF}_x$ 聚合物，同时添加剂 $\text{CH}_2\text{F}_2$ 或 $\text{H}_2$ 中的氢原子优先抓取自由 $\text{F}^*$ 结合成 $\text{HF}$ 抽离，进一步拉高表面 C/F 比。结果在氮化硅栅帽表面堆起厚达 **$3\sim 5\,\text{nm}$ 的致密碳氟屏蔽膜**，耗尽全部入射离子能量，把 $\text{Si}_3\text{N}_4$ 刻蚀速率几乎压制为零！

### SAC 量产两大对立失效模式与 Troubleshooting 平衡

| 失效模式 | 微观物理成因 | 产线调机与工艺突破方案 |
| :--- | :--- | :--- |
| **1. 栅帽肩部圆角削穿**<br>（Corner Rounding / Cap Loss $\to$ 短路） | 尽管栅帽平顶护盾稳固，但在栅帽 **$45^\circ$ 侧肩拐角**处，物理离子溅射产额高达平面的 $2\sim 3$ 倍，同时聚合物沉积率在尖角处最薄，过刻蚀极易削圆拐角击穿内部金属栅！ | 切分为 **准 ALE 交替循环（Quasi-ALE SAC）**：每步短促刻蚀之间穿插无偏压纯 $\text{C}_4\text{F}_6/\text{CH}_2\text{F}_2$ 补膜，定点修复氮化硅肩部拐角护盾；采用同步脉冲低偏压降低离子溅射动能。 |
| **2. 窄隙底部刻蚀骤停**<br>（Contact Etch Stop $\to$ 高阻开路） | 为盲目追求超高 $\text{SiO}_2/\text{Si}_3\text{N}_4$ 选择比而压低 $\text{O}_2$ 流量或加浓 $\text{C}_4\text{F}_6$ 时，狭窄的源漏沟槽底部在即将见底前被浓稠聚合物彻底封死，接触孔悬空开路！ | 精密控制微量辅助 $\text{O}_2$ 流量窗口；采用**多步分段法**（主刻蚀较高 $\text{O}_2$ 快进 + 临近接触孔底换超高选择比低偏压脉冲过刻蚀），并于刻后以温和 $\text{H}_2/\text{He}$ 灰化+湿法清洗扫净孔底聚合物残膜而不腐蚀下方硅化物。 |
