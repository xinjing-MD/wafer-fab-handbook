# 高深宽比刻蚀（HARC）与 Bosch 深硅刻蚀技术

- **所属模块**：`03_七大核心工艺 / 02_刻蚀与清洗`

---

## 1. 什么是高深宽比刻蚀（HARC, High Aspect Ratio Contact/Channel）？

深宽比（Aspect Ratio, $AR$）定义为孔/槽深度与底部特征宽度的比值（$AR = H / W$）。
在普通逻辑电路中，接触孔深宽比约 `5:1 ~ 10:1`；但在 **DRAM 深圆筒电容** 和 **200~300+ 层 3D NAND 垂直沟道孔** 中，必须在仅 `50~100 nm` 的开口里垂直向下穿透 **`5~8 μm`** 的多膜层介质，深宽比达到惊人的 **$60:1 \sim 100:1$**——相当于用吸管垂直打穿几十层高楼且不能歪斜一丝！

## 2. HARC 刻蚀四大经典物理陷阱与机台对策

| 常见几何缺陷 | 物理成因（腔室内发生什么） | 晶圆厂工程对策 |
| :--- | :--- | :--- |
| **ARDE（深宽比相关刻蚀）** | 宽口比窄口更容易进入中性自由基与离子，导致同一片上**宽孔刻穿底了、窄孔还没刻到位** | 优化腔压降低碰撞；采用脉冲射频与高自由基比例平衡传输速率 |
| **Etch Stop（刻蚀中途停止）** | 孔太深时，孔壁积累正电荷排斥后续正离子入射；底部聚合物排不出去直接堵死 | **高能量极高偏置电压（数千伏级 Bias RF）** 强行把离子打入孔底；优化氟碳比 ($\text{C}_x\text{F}_y$) 减少过度聚合 |
| **Bowing（侧壁鼓肚）** | 孔口边缘受斜向散射离子二次反弹轰击，导致孔径中上部被横向掏宽像“酒桶” | 增强孔壁保护性碳氟聚合物沉积；转向 **Cryogenic 极低温刻蚀（-60°C~-80°C）** 用 $\text{HF}/\text{PF}_3$ 形成极强低温侧壁钝化膜 |
| **Twisting（孔道扭曲偏斜）** | 孔内随机微电荷堆积产生局部横向偏转电场，把离子束打歪，底部直接撞穿隔壁孔造成短路 | 使用多频脉冲交替放电（Pulsed Plasma），在关断瞬间（Off-time）注入负离子/电子中和孔内积聚正电荷 |

## 3. MEMS 与 TSV 专用的 Bosch（博世）深硅刻蚀工艺

不同于主要用 CCP 刻氧化硅的 HARC，制造 **TSV 硅通孔**、**加速度计/陀螺仪 MEMS 悬臂梁** 需要在纯硅片上挖几十微米到数百微米深的垂直深井，业界最经典的是德国博世发明的 **DRIE（Deep Reactive Ion Etching）时分复用交替工艺**：

1. **钝化步（Passivation, 通 $\text{C}_4\text{F}_8$ 气体，2~5 秒）**：在硅槽底部和侧壁统一铺上一层类似特氟龙的高分子保护膜；
2. **刻蚀步（Etch, 通 $\text{SF}_6$ 气体 + Bias 轰击，3~8 秒）**：垂直入射的离子打碎**槽底**保护膜，含氟自由基迅速各向同性化学掏空硅，同时**侧壁**保护膜完好挡住横向侵蚀；
3. **循环往复数十~数百个 Cycle** → 最终在硅片内刻出垂直度接近 90° 的深坑，侧壁在电镜下呈现出标志性的周期微波浪纹，称为 **扇贝纹（Scallop）**（可通过缩短单步周期或后氧化剥离平滑）。
