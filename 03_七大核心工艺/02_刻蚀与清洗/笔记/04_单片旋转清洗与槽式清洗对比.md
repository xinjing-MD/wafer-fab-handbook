# 单片旋转清洗（Single Wafer Clean）vs 槽式清洗（Wet Bench）

- **所属模块**：`03_七大核心工艺 / 02_刻蚀与清洗`

---

## 1. 晶圆厂清洗设备两代主流形态对比

晶圆清洗步数占全流程 30% 以上，设备分为两大流派：**批量浸泡槽式机台（Wet Bench）** 与 **高速单片旋转清洗机（Single Wafer Spin Cleaner）**。

| 对比维度 | 槽式清洗（Wet Bench / Batch） | 单片旋转清洗（Single Wafer Clean） |
| :--- | :--- | :--- |
| **一次处理量** | 整批（25 片或 50 片同时浸入同一大药槽） | 每次各腔室仅处理 1 片（高速自转喷淋，机台常配 8~16 个腔室并发保持 WPH） |
| **交叉污染风险** | **高！** 前一批带入的颗粒、铜金属离子或剥落残渣容易污染同一槽里的其他晶圆 | **极低！** 新鲜药液一次性（Single-pass）喷淋后即排走或独立回收，绝不交叉污染 |
| **物理剥离控制** | 槽底震子兆声波易产生声场驻波死角与微结构破坏 | 可精准控制转速、喷嘴扫描轨迹与 **SAPS 空间交变兆声波**，均匀性极佳 |
| **大尺寸翘曲适应** | 300mm 晶圆大片垂直浸泡间距窄、烘干极易水印或粘连 | **片内干燥控制极强**：配合高速离心 + 加热 $\text{N}_2$/IPA 表面张力梯度干燥 |
| **化学药液消耗** | 单片分摊药液消耗相对低（槽液寿命内循环过滤） | 药液耗量偏大（除非配热磷酸/SPM 闭环回收系统） |
| **产线主流分工** | 适合前段非关键批处理、热磷酸剥氮化硅、炉管前大批清洗 | **28nm 及以下前段关键层、FinFET/GAA、铜互连与 Post-CMP 绝对主力** |

---

## 2. 先进微结构清洗干燥的噩梦：图形倒塌（Pattern Collapse）

当 FinFET 鳍片或高圆筒 DRAM 电容间距缩小到 10~20nm、高宽比超过 15:1 时，清洗后的纯水烘干阶段液体弯月面会产生巨大的**毛细管拉应力（Capillary Force）**：
$$F_{cap} \propto \frac{\gamma \cos\theta}{d}$$
（其中 $\gamma$ 为液体表面张力，$d$ 为微结构间距，纯水 $\gamma$ 高达 $72.8\,\text{mN/m}$！）

在纯水蒸发瞬间，相邻两堵纳米高墙会被拉扯弯曲甚至永久粘连断裂。晶圆厂两大破局技术：
1. **IPA（异丙醇）置换干燥 / 马兰戈尼干燥（Marangoni Drying）**：IPA 表面张力仅约 $21.7\,\text{mN/m}$（不到水的 1/3），且利用表面张力梯度自发将水膜拉干；
2. **超临界二氧化碳干燥（$\text{scCO}_2$ Supercritical Drying）**：将腔室加压升温使液态 $\text{CO}_2$ 跨过临界点进入超临界态（同时具备气体极低粘度和液体溶解力），然后直接降压气化——**全过程完全跳过气-液相变边界，表面张力 $\gamma \equiv 0$**，实现纳米微结构零倒塌完美干燥！
