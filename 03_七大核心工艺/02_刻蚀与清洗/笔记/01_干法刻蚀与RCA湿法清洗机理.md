# 干法刻蚀（CCP/ICP/ALE）与湿法 RCA 清洗核心机理

- **所属模块**：`03_七大核心工艺 / 02_刻蚀与清洗`

## 1. 干法刻蚀 vs 湿法刻蚀

| 维度 | 干法等离子体刻蚀（Dry Etch） | 湿法化学刻蚀（Wet Etch） |
| :--- | :--- | :--- |
| **介质** | 气态等离子体（物理轰击 + 化学反应协同） | 液态酸/碱化学药液 |
| **方向性** | **各向异性（Anisotropic）为主**，可垂直向下挖深槽 | **各向同性（Isotropic）为主**，易产生横向钻蚀（Undercut） |
| **选择比** | 较高（需精确调配气体比例与偏置电压） | **极高**（如 DHF 对 $\text{SiO}_2$/Si、热磷酸对 $\text{Si}_3\text{N}_4$/$\text{SiO}_2$） |
| **典型用途** | 精细图形转移（Gate、Fin、Contact、HARC 孔洞） | 全片剥膜（Strip）、去牺牲层、缺陷清洗 |

---

## 2. 干法刻蚀核心指标（Etch KPIs）
- **刻蚀速率（Etch Rate）**：单位时间刻蚀厚度（Å/min 或 nm/min）。
- **选择比（Selectivity）**：目标材料刻蚀速率 / 掩模（Mask）或底部停止层（Stop Layer）刻蚀速率。
- **均匀性（Uniformity）**：Center-to-Edge 差异。
- **各向异性度 & 剖面形貌（Profile）**：垂直度、是否出现 Bowing（鼓肚）、Notching（底部凹槽）、Micro-trenching（微沟槽）或 Loading Effect（负载效应：密集区与稀疏区刻蚀深度不一致）。

## 3. CCP vs ICP 刻蚀腔体与 ALE
- **CCP（电容耦合等离子体）**：上下两块平行电极板，离子能量高但等离子体密度相对中等。典型用于**介质刻蚀（Dielectric Etch，如氧化硅/氮化硅接触孔、HARC）**，主战场厂商如 Lam Research / TEL。
- **ICP（电感耦合等离子体）**：顶部/侧面加螺旋射频线圈（Source RF）独立产生高密度等离子体，底部单独加 Bias RF 控制离子轰击能量——实现**密度与能量解耦**。典型用于**硅刻蚀、金属与栅极刻蚀（Conductor Etch）**。
- **ALE（原子层刻蚀）**：仿照 ALD 的“自限制循环”思路——`表面改性层吸附 → 温和轰击只剥离单原子层改性物`，实现埃（Å）级损伤极低的刻蚀控制，是 GAA 纳米片释放与 2nm 以下关键工艺。

## 4. 湿法清洗（Wet Cleaning）：RCA 标准体系
晶圆厂每一步高温或薄膜前后几乎都需要清洗，防止颗粒或金属把器件毁掉：

| 清洗步骤 | 经典配方 | 主要去除对象 | 核心机理 / 注意事项 |
| :--- | :--- | :--- | :--- |
| **SPM（食人鱼洗液）** | $\text{H}_2\text{SO}_4 : \text{H}_2\text{O}_2$ (约 100~130°C) | 光刻胶残余、重度有机物 | 强氧化脱水炭化 |
| **SC-1（APM）** | $\text{NH}_4\text{OH} : \text{H}_2\text{O}_2 : \text{H}_2\text{O}$ | **颗粒物（Particles）**与部分有机物 | 微氧化+微刻蚀掀起颗粒，并使表面与颗粒同带负Zeta电位而静电排斥；配合 **兆声波（Megasonic）** 剥离 |
| **SC-2（HPM）** | $\text{HCl} : \text{H}_2\text{O}_2 : \text{H}_2\text{O}$ | **碱金属/过渡金属离子污染** | 络合溶解金属离子 |
| **DHF（稀氢氟酸）** | $\text{HF} : \text{H}_2\text{O}$ (如 1:100) | 自然氧化层（Native Oxide） | 露出纯净疏水硅表面；须防烘干出现 **Watermark 水印**（常用 IPA 马兰戈尼干燥或超临界 $\text{CO}_2$ 干燥防结构坍塌） |
