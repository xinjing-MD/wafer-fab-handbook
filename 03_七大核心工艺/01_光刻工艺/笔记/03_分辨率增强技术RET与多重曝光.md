# 分辨率增强技术（RET）与多重曝光（SADP / SAQP）

- **所属模块**：`03_七大核心工艺 / 01_光刻工艺`

---

## 1. 当瑞利判据碰到物理天花板：为什么必须用 RET？

在 193nm 浸没式光刻（$NA = 1.35$）下，即使把工艺因子 $k_1$ 压到单次曝光物理极限（约 `0.25`），最小半节距（Half-Pitch）极限也只有：
$$\text{HP}_{min} = 0.25 \times \frac{193\,\text{nm}}{1.35} \approx 35.7\,\text{nm}$$
要继续做出 28nm、14nm、7nm 甚至更小的鳍片（Fin）和金属线，必须靠**分辨率增强技术（RET）**把 $k_1$ 逼近 `0.25`，再靠**多重图形化（Multi-Patterning）**把等效 $k_1$ 进一步压破物理底线。

## 2. 三大核心 RET 光学魔法

### （1）OAI（Off-Axis Illumination，离轴照明）
- **痛点**：传统垂直入射圆盘照明的 0 级与 ±1 级衍射光在极小节距下夹角太大，±1 级光直接飞出投影物镜孔径外，晶圆上完全成不了像。
- **解法**：把照明光改成环形（Annular）、偶极（Dipole）或四极（Quasar）斜射入掩模版。**斜着进来的 0 级光和一侧的 +1 级衍射光正好对称穿过物镜两侧边缘**，成功发生双光束干涉成像，分辨率与焦深（DOF）同步翻倍！

### （2）PSM（Phase-Shift Mask，相移掩模）
- 利用光波干涉相消原理：在相邻两条透光缝隙中，把其中一条的石英玻璃挖深特定厚度，使透过的光产生 **180°（$\pi$）相位差**。
- 当两束反相光在暗区边界交叠时振幅直接相互抵消为零，图像对比度（NILS）陡峭度大幅提升。常见包括 **Alt-PSM（交替相移）** 与 **Att-PSM（衰减相移，如 6% MoSi 掩模）**。

### （3）OPC（Optical Proximity Correction，光学邻近修正）与 SMO
- **邻近效应**：光波衍射会让掩模上的标准直角在硅片上变成圆角，线端变短（Line-end Shortening），孤立线与密集线线宽不一致（Iso-Dense Bias）。
- **OPC 对策**：用计算光刻软件预先把掩模版图形改得“奇形怪状”——在线端加上**锤头（Hammerhead）**、在拐角加上**衬线（Serif）**、在空旷处插入不曝光的**亚分辨辅助图形（SRAF）**，经过物镜低通滤波衍射失真后，投影到晶圆上的图形恰好变回完美直角矩形！
- **SMO（Source-Mask Optimization）**：把光源形状像素化 + 掩模图形像素化联合反演求解（常见 Inverse Lithography Technology, ILT 曲线掩模），榨干光学系统最后 1% 的工艺窗口。

## 3. 突破单次曝光极限：LELE vs SADP / SAQP 多重图形化

| 技术代号 | 核心流程 | 优点与极限痛点 |
| :--- | :--- | :--- |
| **LELE**（Litho-Etch-Litho-Etch） | 一次曝光刻蚀做偶数线 → 再涂胶二次曝光刻蚀做奇数线（间隔错位减半 Pitch） | **套刻误差（Overlay）敏感**：两次光刻对不准就会导致奇数线与偶数线间距一宽一窄（Pitch Walking） |
| **SADP**（自对准双重图形化） | 1. 做出较宽的芯轴（Mandrel）<br>2. ALD 极均匀包覆一层薄侧墙（Spacer，厚度决定最终间距！）<br>3. 顶层回刻露出芯轴并掏空芯轴，**只留下两侧对称的侧墙当作硬掩模** | **无套刻误差！** 间距完全由 ALD 原子级膜厚决定，密度直接翻倍；还需配套 Cut Mask 切断不需要连接的环路 |
| **SAQP**（自对准四重图形化） | 把 SADP 流程连续嵌套做两遍（Mandrel → 第 1 轮 Spacer → 当作第 2 轮芯轴再长第 2 轮 Spacer） | **193i 做到 14nm/10nm/7nm 鳍片与密集金属线的核心武器**；缺点是工序步数暴增、成本与 Cycle Time 飙升，最终在 7nm/5nm 被 EUV 单次曝光接替 |
