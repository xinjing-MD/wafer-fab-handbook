## 一、硅片材料、器件物理与制程整合（Wafer, Device & Integration）

| 缩写 | 英文全称 | 中文解释 | 常见出现场景 |
| :--- | :--- | :--- | :--- |
| **BEOL** | Back-End-of-Line | 后道金属互连工艺 | M1~Top Metal 多层 Cu/Low-k 互连 |
| **BPR** | Buried Power Rail | 埋入式电源轨 | 3nm/2nm 过渡至背面供电前的轨道下沉技术 |
| **BSPDN** | Backside Power Delivery Network | 背面供电网络（如 PowerVia） | 2nm 及以下先进节点解决正面 IR 压降瓶颈 |
| **CFET** | Complementary FET | 互补场效应晶体管（N/P 垂直堆叠） | 1nm 及以下 Sub-nm 世代器件架构 |
| **CMOS** | Complementary Metal-Oxide-Semiconductor | 互补金属氧化物半导体 | 主流数字/模拟逻辑集成电路基本单元 |
| **CZ** | Czochralski Method | 直拉法单晶生长 | 12 寸半导体级单晶硅锭生长主流工艺 |
| **DIBL** | Drain-Induced Barrier Lowering | 漏致势垒降低 | 短沟道器件亚阈值漏电加剧的核心短沟效应 |
| **EOT** | Equivalent Oxide Thickness | 等效氧化层厚度 | 衡量 HKMG High-k 栅介质电容控制能力（$\sim 0.7\text{--}1.2\text{ nm}$） |
| **FEOL** | Front-End-of-Line | 前道晶体管制造工艺 | STI、阱注入、栅极、侧墙与源漏外延（高温预算上限） |
| **FinFET** | Fin Field-Effect Transistor | 鳍式场效应晶体管 | 22nm~3nm 世代三面环栅主流立体器件 |
| **FZ** | Float-Zone Method | 区熔法单晶生长 | 高压功率器件（IGBT 等）低氧高阻硅片 |
| **GAA** | Gate-All-Around | 全环绕栅极（Nanosheet 纳米片） | 3nm/2nm 继 FinFET 后的四面包裹通道架构 |
| **GIDL** | Gate-Induced Drain Leakage | 栅致漏极漏电 | 关态高漏压下栅-漏交叠区带间隧穿漏电 |
| **HKMG** | High-k Metal Gate | 高介电常数金属栅 | 以 $\text{HfO}_2$ + 功函数金属替代 Poly/$\text{SiO}_2$ |
| **ILD / IMD** | Inter-Layer / Inter-Metal Dielectric | 层间介质 / 金属间介质 | 隔离晶体管与金属线之间的绝缘氧化物/Low-k 膜 |
| **LDD** | Lightly Doped Drain | 轻掺杂漏极 | 缓解沟道夹断区峰值电场与热载流子注入（HCI） |
| **MEOL / MOL** | Middle-of-Line | 中段接触孔工艺 | 连接晶体管 S/D、Gate 与 M1 层的 W/Co/Ru 接触 |
| **RMG** | Replacement Metal Gate (Gate-Last) | 替代金属栅（后栅工艺） | 避免源漏 $1000^\circ\text{C}$ 退火破坏功函数金属与 $\text{HfO}_2$ |
| **S/D** | Source / Drain | 源极 / 漏极 | MOSFET 载流子发射与收集电极（先进节点用 e-SiGe/Si:P） |
| **SFQR** | Site Flatness Quality Requirement | 局域平整度要求 | 评估 $26\times 8\text{ mm}$ 曝光场内平坦度，决定光刻不失焦 |
| **SOI / FDSOI** | Silicon-On-Insulator / Fully Depleted SOI | 绝缘体上硅 / 全耗尽 SOI | 射频开关、汽车电子、低功耗抗辐射芯片衬底 |
| **SS** | Subthreshold Swing | 亚阈值摆幅（$\text{mV/dec}$） | 室温物理极限为 $60\text{ mV/dec}$，衡量栅极开关陡峭度 |
| **STI** | Shallow Trench Isolation | 浅沟槽隔离 | 填充氧化硅隔绝相邻有源区，防串扰与闩锁（Latch-up） |
| **TSV** | Through-Silicon Via | 硅通孔 | 穿透硅衬底垂直互连，HBM 与 2.5D/3D 封装核心 |
| **Vth** | Threshold Voltage | 阈值电压 | 晶体管沟道强反型导通的临界栅压 |
| **WFM** | Work Function Metal | 功函数金属（如 TiN/TiAlC） | 分别调校 NMOS 与 PMOS 的 $V_{th}$ 到设计窗口 |

| **POU** | Point-of-Use | 使用点末端（过滤器/加热器/减害器） | 紧邻机台入口的最后一道精度过滤或尾气处理单元 |
| **SCBA** | Self-Contained Breathing Apparatus | 正压式空气呼吸器 | ERT 紧急应变队员处理剧毒特气泄漏的标准穿戴 |
| **Scrubber** | Exhaust Gas Abatement Scrubber | 尾气处理/洗涤塔 | Burn-Wet/Dry-Bed 分解 $\text{SiH}_4$、$\text{NF}_3$、$\text{WF}_6$ 等有毒废气 |
| **Sub-Fab** | Sub-Fabrication Level | 晶圆厂下层辅助设备层 | 放置干泵、Chiller、RF 电源柜与尾气 Scrubber（净高 4.5~6m） |
| **TGMS** | Toxic Gas Monitoring System | 毒气监测系统 | 24h 监测 $\text{AsH}_3/\text{PH}_3/\text{Cl}_2/\text{NH}_3$ 并触发联动排风与警报 |

| **ULPA** | Ultra-Low Particulate Air Filter | 超高效微粒空气过滤器 | 对 $\ge 0.12\,\mu\text{m}$ 颗粒截留效率 $\ge 99.9995\%$ |
| **VMB / VMP** | Valve Manifold Box / Panel | 阀门歧管箱 / 气瓶分配盘 | 特气房到机台之间的分流开关与压力安全控制箱 |

## 三、光刻、掩模与分辨率增强技术（Lithography, Reticle & RET）

| 缩写 | 英文全称 | 中文解释 | 常见出现场景 |
| :--- | :--- | :--- | :--- |
| **ADI** | After-Development Inspection | 显影后检查 | 测定涂胶显影后光刻胶线宽 CD、套刻 OVL 与宏观缺陷 |
| **ArF / ArFi** | Argon Fluoride (Dry / Immersion) | $193\text{ nm}$ 氟化氩干式 / 浸没式光刻 | 镜头与晶圆间注入 $n=1.44$ 超纯水使 $\text{NA}=1.35$ |
| **BARC** | Bottom Anti-Reflective Coating | 底部抗反射层 | 吸收穿过光刻胶的曝光光波，抑制驻波效应与散射 |
| **CAR** | Chemically Amplified Resist | 化学放大光刻胶 | 产酸剂 + 后烘（PEB）催化链式反应大幅提高灵敏度 |
| **CD** | Critical Dimension | 关键尺寸 | 晶圆上最小线条宽或接触孔直径（Rayleigh 第一公式主导） |
| **DOF** | Depth of Focus | 焦深 | 光刻成像保持在合格 CD 窗口内所允许的 Z 向离焦范围 |
| **DUV** | Deep Ultraviolet | 深紫外光刻 | 包含 $248\text{ nm}$ (KrF) 与 $193\text{ nm}$ (ArF/ArFi) 世代 |
| **EPE** | Edge Placement Error | 边缘放置误差 | 综合评价 CD 偏差 + OVL 套刻 + LER 的最终图形定位总误差 |
| **EUV** | Extreme Ultraviolet ($13.5\text{ nm}$) | 极紫外光刻 | 7nm 以下单次曝光核心，全真空多反射镜体系 |
| **ILT** | Inverse Lithography Technology | 反向光刻计算技术 | 通过曲线掩模反推优化光强分布，提升工艺窗口 |
| **$k_1$ Factor** | Process Resolution Factor | 工艺因子 | $k_1 = \text{CD}\cdot\text{NA}/\lambda$，单次光学物理极限为 $0.25$ |
| **KrF** | Krypton Fluoride ($248\text{ nm}$) | 氟化氪深紫外光刻 | 用于中厚层、离子注入掩蔽层与非最微缩 BEOL 层 |
| **LWR / LER** | Line Width / Line Edge Roughness | 线宽粗糙度 / 线边缘粗糙度 | EUV 时代受光子散粒噪声影响的关键微缩限制项 |
| **NA** | Numerical Aperture | 数值孔径 | 表征投影物镜集光锥角大小（ArFi `1.35` / EUV `0.33` / High-NA `0.55`） |
| **OPC** | Optical Proximity Correction | 光学邻近修正 | 在掩模上预先增加衬线/锤头补偿衍射导致的圆角与缩颈 |
| **OVL** | Overlay | 套刻对准精度 | 上下两层电路图形之间的水平位置对准偏差（$\le 1.5\text{--}3\text{ nm}$） |
| **PEB** | Post-Exposure Bake | 曝光后烘烤 | 驱动 CAR 光刻胶内光生酸扩散完成去保护反应（对温度极敏感） |
| **Pellicle** | Reticle Pellicle | 光罩防尘薄膜 | 悬置掩模表面几毫米使落尘离焦避免印到每颗 Die 上 |
| **PSM** | Phase-Shift Mask | 相移掩模 | 利用 $180^\circ$ 相位差相消干涉提升图形对比度（降低 $k_1$） |
| **SADP / SAQP** | Self-Aligned Double / Quadruple Patterning | 自对准双重 / 四重图形化 | 借助芯轴与 ALD 侧墙将 ArFi 密距倍增（突破 $k_1=0.25$ 限制） |
| **Scanner** | Step-and-Scan Lithography System | 步进扫描光刻机 | 同步高速扫描掩模台与晶圆台（单台 ASML ArFi/EUV 核心构型） |
| **SMO** | Source-Mask Optimization | 光源-掩模协同优化 | 定制自由曲面照明瞳形与掩模版共同压榨最小工艺窗口 |
| **SOC / SOH** | Spin-on Carbon / Spin-on Hardmask | 旋涂碳硬掩模 | 多层三明治抗蚀膜堆叠底层，提供极高刻蚀阻力与平坦化 |
| **Track** | Coater / Developer Track | 涂胶显影机 | 与光刻机联机实现涂 BARC/PR、软烘、PEB 与 TMAH 显影 |
| **T-Top** | T-Topping Resist Profile | 光刻胶顶部 T 型畸变 | 环境中 trace 级 $\text{NH}_3$ 中和 CAR 表层光生酸导致顶帽阻挡 |

## 四、干法刻蚀与湿法清洗（Etch & Wet Clean）

| 缩写 | 英文全称 | 中文解释 | 常见出现场景 |
| :--- | :--- | :--- | :--- |
| **AEI** | After-Etch Inspection | 刻蚀后检查 | 检测刻蚀后终线宽、侧壁倾角（Profile）、残胶及微沟槽 |
| **ALE** | Atomic Layer Etch | 原子层刻蚀 | 表面改性 + 低能脱附自限制循环，实现埃米级无损伤刻蚀（如 GAA） |
| **AR / HARC** | Aspect Ratio / High Aspect Ratio Contact | 深宽比 / 高深宽比接触孔 | 3D NAND 通道孔深宽比超 $60:1$，极易触发弓形（Bowing）与歪斜 |
| **ARDE / RIE Lag** | Aspect Ratio Dependent Etching | 深宽比相关刻蚀效应 | 越深越窄的沟槽中性自由基输运受阻，刻蚀速率显著慢于宽开口 |
| **Ashing / Strip** | Plasma Ashing / Photoresist Strip | 灰化 / 去胶 | $\text{O}_2/\text{N}_2/\text{H}_2$ 等离子体或 SPM 溶液彻底剥离残余光刻胶 |
| **BOE** | Buffered Oxide Etch | 缓冲氧化物刻蚀液 | $\text{HF} + \text{NH}_4\text{F}$ 混合液，pH 稳定且不易腐蚀残留光刻胶边界 |
| **CCP** | Capacitively Coupled Plasma | 电容耦合等离子体 | 上下平板电极，高离子能量，主攻 $\text{SiO}_2/\text{Si}_3\text{N}_4$ 等介质刻蚀 |
| **DHF** | Diluted Hydrofluoric Acid | 稀氢氟酸 | 湿法去除晶圆表面自然氧化层（$\text{Native Oxide}$） |
| **DRIE** | Deep Reactive Ion Etching (Bosch) | 深反应离子刻蚀 | 交替 $\text{SF}_6$ 刻蚀与 $\text{C}_4\text{F}_8$ 钝化实现高垂直深硅通孔 |
| **EPD** | Endpoint Detection | 刻蚀终点侦测 | 通过 OES 光谱发射强度突变或激光干涉精准判定刻穿界面瞬间 |
| **ICP** | Inductively Coupled Plasma | 感应耦合等离子体 | 线圈感应产生高密度低能量等离子体，主攻 Si/Poly/Metal 刻蚀 |
| **Loading Effect** | Micro / Macro Loading Effect | 负载效应 | 晶圆开口率（Open Area）不同导致活性自由基消耗失衡与速率差异 |
| **PR** | Photoresist | 光刻胶 | 图形转移时的临时牺牲阻挡掩膜 |
| **RCA Clean** | RCA Standard Clean (SC-1 / SC-2) | RCA 标准清洗工艺 | $\text{SC-1}$（氨水+双氧水）去颗粒，$\text{SC-2}$（盐酸+双氧水）去金属离子 |
| **RIE** | Reactive Ion Etching | 反应离子刻蚀 | 物理离子轰击（垂直性）与化学自由基反应（选择比）协同 |
| **Selectivity** | Etch Selectivity | 刻蚀选择比 | 目标层与掩膜层/停止层之间的刻蚀速率比值 |
| **SPM** | Sulfuric Peroxide Mixture | 硫酸双氧水混合液（食人鱼洗液） | $120^\circ\text{C}$ 强氧化剥离重度注入硬化光刻胶与有机物 |

## 五、薄膜沉积、热处理与离子注入（Deposition, Thermal & Implant）

| 缩写 | 英文全称 | 中文解释 | 常见出现场景 |
| :--- | :--- | :--- | :--- |
| **ALD** | Atomic Layer Deposition | 原子层沉积 | 交替脉冲自限制单分子层生长，阶梯覆盖率近 $100\%$ |
| **Anneal** | Thermal Annealing | 热退火 | 修复注入晶格损伤并让掺杂原子移入晶格替位电激活 |
| **CVD** | Chemical Vapor Deposition | 化学气相沉积（含 LPCVD / PECVD） | 气相前驱体在晶圆表面化学反应成膜（介电层/多晶硅/W 塞） |
| **Epi** | Epitaxy (Selective Epitaxial Growth) | 外延生长（选择性外延） | 在单晶硅衬底延续晶格生长 $\text{e-SiGe}$/$\text{Si:P}$ 或 GAA $\text{Si/SiGe}$ 超晶格 |
| **Furnace** | Vertical Batch Furnace | 立式批处理扩散/氧化炉 | 一次装载 $100\sim 150$ 片晶圆进行高温热氧化或 LPCVD $\text{Si}_3\text{N}_4$ |
| **HDPCVD** | High-Density Plasma CVD | 高密度等离子体气相沉积 | 边沉积边溅射微回刻，填高深宽比 STI 沟槽不产生孔洞 |
| **IMP** | Ion Implantation | 离子注入 | 通过电离-质量分析-高压加速精准控制掺杂剂量与深度 |
| **LSA** | Laser Spike Annealing | 激光毫秒级退火 | $< 1\text{ ms}$ 闪热实现超高激活率同时几乎零热扩散 |
| **PEALD** | Plasma-Enhanced ALD | 等离子体增强原子层沉积 | 借助等离子体自由基降低成膜温度，适应 BEOL 低温限制 |
| **PVD** | Physical Vapor Deposition (Sputtering) | 物理气相沉积（磁控溅射） | 轰击 Ta/TaN/Ti/Cu/Al 靶材，沉积金属阻挡层、Cu 种子层与铝垫 |
| **RTP / RTO** | Rapid Thermal Processing / Oxidation | 快速热处理 / 退火炉 | 卤素灯阵列秒级升至 $1050^\circ\text{C}$ 完成超浅结退火与硅化物反应 |
| **Rp / $\Delta$Rp** | Projected Range / Straggle | 投影射程 / 纵向偏差 | LSS 高斯注入分布的峰值深度与分散宽度 |
| **SACVD** | Sub-Atmospheric CVD | 亚常压化学气相沉积 | 常压/亚常压 $\text{O}_3\text{-TEOS}$ 沉积高流动性间隙填充氧化硅 |
| **Showerhead** | Gas Distribution Showerhead | 气体喷淋头 | CVD/Etch 腔顶部均布微孔喷嘴，决定腔内气场与厚度均匀性 |
| **SILC / SIV** | Stress-Induced Voiding | 应力诱发空洞 | BEOL 金属退火后热膨胀失配导致的铜通孔底部隐蔽空洞 |
| **TEOS** | Tetraethyl Orthosilicate | 正硅酸乙酯 | 广泛用于沉积高度保形且低应力的 $\text{SiO}_2$ 介质膜液态前驱体 |

## 六、化学机械平坦化与电镀金属化（CMP & ECP）

| 缩写 | 英文全称 | 中文解释 | 常见出现场景 |
| :--- | :--- | :--- | :--- |
| **CMP** | Chemical Mechanical Planarization | 化学机械平坦化 | 化学腐蚀软化 + 纳米磨料机械研磨实现全局亚纳米平表面 |
| **Dishing** | Copper Line Dishing | 铜线碟形凹陷 | CMP 过抛时宽铜线被压低凹陷，导致金属电阻意外升高 |
| **Dual Damascene** | Dual Damascene Process | 双大马士革工艺 | 先刻介质通孔+沟槽，填阻挡层+Cu ECP 后 CMP 磨去多余铜 |
| **ECP** | Electrochemical Plating | 电化学电镀（超填铜） | 依靠加速剂/抑制剂/整平剂实现沟槽“自底向上”无孔洞填铜 |
| **EM** | Electromigration | 电迁移 | 高电流密度下电子风推动金属原子漂移引起开路或晶须短路 |
| **Erosion** | Oxide / Dielectric Erosion | 介质侵蚀 | 密集细线区连同周围绝缘介质被一并多磨薄造成的厚度损失 |
| **MRR** | Material Removal Rate | 材料去除速率 | Preston 公式 $K \cdot P \cdot V$ 决定不同薄膜在 CMP 中的抛光速率 |
| **Pad Conditioner** | Diamond Pad Conditioner | 金刚石修整盘 | 实时梳理聚氨酯抛光垫表面沟槽防“钝化釉化”（Glazing） |
| **Seed Layer** | PVD Copper Seed Layer | 铜籽晶层 | ECP 通电前必须先用 PVD 在窄沟槽内壁镀一层连续导电铜膜 |
| **Slurry** | Polishing Slurry | 抛光研磨浆 | 含氧化剂、络合剂、缓蚀剂（BTA）与 $\text{SiO}_2/\text{CeO}_2$ 纳米颗粒 |
| **Stop-on-Barrier** | Barrier CMP Stop | 阻挡层停止 / 去除步 | 多盘 CMP 中先高选择比停在 TaN 再用低碟陷浆料清阻挡层 |
| **TDDB** | Time-Dependent Dielectric Breakdown | 经时介质击穿 | 长期工作电场下 Low-k 或栅氧中形成导电通道导致的击穿失效 |

## 七、量测、失效分析、电性测试与可靠性（Metrology, Yield, FA & Reliability）

| 缩写 | 英文全称 | 中文解释 | 常见出现场景 |
| :--- | :--- | :--- | :--- |
| **AFM** | Atomic Force Microscopy | 原子力显微镜 | 测量粗糙度（RMS）、浅台阶高度与 CMP 后亚纳米表面形貌 |

| **CP** | Chip Probing (Wafer Sort) | 晶圆中测 / 针测 | 探针卡扎上每颗裸片焊盘测功能并输出良率与 Wafer Map |

| **DFM / DFY** | Design for Manufacturing / Yield | 可制造性 / 高良率设计 | 从版图阶段引入冗余通孔、规则图形与光刻热点检查 |
| **EBI** | Electron Beam Inspection | 电子束电压衬度缺陷检测 | 探测光学看不到的物理埋藏断路/短路（如高深宽比接触孔未通） |
| **EMMI** | Emission Microscopy | 光子发射显微镜 | 捕获芯片漏电、闩锁 PN 结发光热点，毫秒级锁定失效坐标 |

| **FIB** | Focused Ion Beam | 聚焦离子束 | 精准 $\text{Ga}^+$ 离子束在晶圆指定位置切出纳米超薄片送 TEM 观测 |
| **FT** | Final Test | 成品封装测试 | 切割封装成芯片颗粒后的最终全功能、高低温与老化筛选 |
| **HCI** | Hot Carrier Injection | 热载流子注入 | 高漏场下高能电子/空穴注入栅氧造成的器件退化 |
| **OBIRCH** | Optical Beam Induced Resistance Change | 激光诱导电阻变化定位 | 利用激光扫描发热引起的阻值变化精准定位金属细微短路或空洞 |
| **OCD** | Optical Critical Dimension (Scatterometry) | 光学关键尺寸散射仪 | 非接触反演 Fin/GAA 3D 截面高度、侧壁角与底层线宽 |
| **OM / Brightfield** | Optical Inspection | 光学明暗场缺陷扫描（如 KLA） | 全片快速扫描颗粒、划痕与光刻图形桥接热点 |
| **TEM** | Transmission Electron Microscope | 透射电子显微镜 | 亚埃级放大直接观测栅极氧化层原子晶格、内侧墙厚度与缺陷成分 |
| **SIMS** | Secondary Ion Mass Spectrometry | 二次离子质谱仪 | 破坏性深度剖析极微量掺杂原子（B/P/As）的纵向浓度分布 |
| **WAT** | Wafer Acceptance Test | 晶圆允收电性测试 | 在切割道测试结构测量 $V_{th}$、$I_{dsat}$、$I_{off}$、$R_s$ 决定片子放行 |
| **XPS / EDX** | X-ray Photoelectron / Energy Dispersive X-ray | 表面元素能谱分析 | 鉴定晶圆未知污染物颗粒的元素组成或化学价态 |
| **TXRF** | Total Reflection X-Ray Fluorescence | 全反射 X 射线荧光分析 | 监控清洗后晶圆表面微量金属原子残留（$10^9\text{ atoms/cm}^2$ 级） |
