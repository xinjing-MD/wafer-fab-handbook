### 4.1 AMHS 物流天车（OHT）装卸交接与运动学全流程

在制作 Blender 动画时，天车与机台的交接动作是最具工业美感和节奏感的镜头。其背后有着极其严苛的 **SEMI E84（光通信握手）** 与 **SEMI E15.1/E57（机械定位）** 行业规范。

```
[ 步骤 1: OHT 天轨巡航 ]        [ 步骤 2: 减速对位与 E84 握手 ]        [ 步骤 3: 夹爪开箱与垂降 ]
   ======OHT======>                    [ OHT 停正 ]                        [ OHT 悬停 ]
=========================         =========================           =========================
                                              |                                   |  | (4条扁平带伸出)
                                              | (红外光通信握手)                   |  |
                                              V                                   V  V
                                       +-------------+                     +-----------------+
                                       | Load Port   |                     | 机械夹爪 Gripper|
                                       +-------------+                     +--------+--------+
                                                                                    | (锁死提手)
                                                                           +--------V--------+
                                                                           |   FOUP 晶圆盒   |
                                                                           +-----------------+
                                                                                    |
                                                                                    V
                                                                           [ 缓缓降向 900mm 台面 ]
```

#### 动画分步运动分解与时间节奏表（动画 K 帧基准）：

1. **巡航与减速制动阶段（耗时 ~2.0 秒）：**
   - **平移动作：** OHT 天车以约 $2.5\text{ m/s}$（动画舒适观赏速度）在天轨上沿曲线平滑进站。在到达目标 Load Port 正上方前 1.5 米处开始施加 S 曲线平滑减速（Deceleration profile）。
   - **对准公差：** 天车底部激光测距传感器扫描 Load Port 顶部的光学反光标志，平移停止在垂直误差小于 $\pm 1.0\text{mm}$ 的死区范围内。天车前后各有一对黄色微型 LED 状态灯从常亮切换为高频闪烁。

2. **SEMI E84 光学握手通信阶段（耗时 ~0.5 秒）：**
   - **非接触通信：** OHT 底部的光发射器向 Load Port 侧面的光敏受光管发射红外编码脉冲（动画表现：细微的红外不可见光，可在特效中加一层淡淡的青蓝色光波扫描特效）。
   - **联锁确认：** Load Port 向上位机反馈“设备就绪，平台无干涉物，允许下落”，Load Port 面板上的绿灯亮起。

3. **四点悬吊卷扬机垂直下落阶段（耗时 ~4.0 - 5.0 秒）：**
   - **机械结构：** OHT 底板中央的两扇水平滑动防尘门向两侧滑开（开度约 450mm）。
   - **放绳机构：** 内部由高精度伺服电机同步驱动的双卷筒同时旋转，均匀下放 **4 条宽约 25mm、厚约 1.5mm 的高强度凯夫拉黑色编织索带（或薄型不锈钢平钢带）**。
   - **夹爪与 FOUP：** 四角索带末端吊挂着一个四方形轻量化铝合金抓手托架（Gripper）。抓手中央带有气动卡爪，死死扣住 FOUP 顶部的多边形塑料法兰（Top Handling Flange）。
   - **下降速度曲线：** 抓手带着 9kg 重的 FOUP（空盒约 4.5kg，满载 25 片晶圆后约 8.5kg - 9kg）以约 $0.6\text{ m/s}$ 匀速垂直下降；当距下方装载台面约 50mm 时，速度急剧减缓至 $0.03\text{ m/s}$（微寸动）。

4. **SEMI E57 运动学三销精准着陆（耗时 ~1.5 秒）：**
   - **底部卡位机制：** Load Port 装载台面（标高恒定在距地板 **$900\text{mm} \pm 10\text{mm}$** 处）水平凸出有 **3 个互成 120° 辐射角分布的不锈钢半球形定位销（Kinematic Pins）**。
   - **吻合下沉：** FOUP 底盘嵌有的 3 组倒“V”型硬质阳极氧化铝合金导向凹槽精确套在 3 个定位销上。由于 V 型槽的斜面导向作用，晶圆盒在下落最后 5mm 时会产生极其轻微的机械自对准微移，彻底消除 6 个自由度的晃动。
   - **锁紧与脱钩：** 抓手内部气缸泄气，两侧夹爪向外张开 20mm，完全释放 FOUP 顶部提手。卷扬机倒转，空夹爪以 $1.0\text{ m/s}$ 高速缩回天车腹腔内，天车底板对开门关闭。天车随后加速驶离，奔赴下一个任务点。

### 4.2 Load Port 开门机构与 EFEM 大气机械手作业细节

当 FOUP 稳固停在 900mm 标高的装载台上后，晶圆不能暴露在常压洁净走廊中，而是通过 SEMI E62 自动开门机构将晶圆盒前盖直接拉入 EFEM 内部。

```
              [ SEMI E62 自动开门机构动作剖面分解 ]

   +----------------+  +--------------+          +----------------+  +--------------+
   |  FOUP 晶圆盒   |  | Load Port 门 |          |  FOUP 晶圆盒   |  | Load Port 门 |
   |                |  |              |          |                |  |              |
   |    [ 硅晶圆 ]  |  |              |          |    [ 硅晶圆 ]  |  |   [ 门板结合 ]
   |    [ 硅晶圆 ]  |  |   [吸盘与钥匙|          |    [ 硅晶圆 ]  |  |   [已旋转90°]|
   |    [ 硅晶圆 ]  |  |    进入锁孔] |          |    [ 硅晶圆 ]  |  |              |
   |   [前盖板Door]-+->|--[接口板Port]|          |                |  |<--[向后平移50mm]
   +----------------+  +--------------+          +----------------+  +--------------+
      (阶段 1: 锁孔对准与真空吸附)                   (阶段 2: 旋转开锁并向后脱出)
                                                                            |
                                                                            V (阶段 3: 向下隐蔽滑移)
                                                 +----------------+
                                                 |  FOUP 盒内完全 |
                                                 |  面向 EFEM 敞开|
                                                 |                |
                                                 +----------------+
                                                        |
                                                        V [整块门板下沉 300mm 潜入设备内部底盘]
```

#### 开门与取片机械机构运行分解：
1. **FOUP 水平推近与对准（Docking）：**
   - 装载台面底部的滚珠丝杠滑台驱动整个装载托架水平向前平移约 **$40\text{mm} - 50\text{mm}$**，将 FOUP 的前门外沿紧紧挤压在 EFEM 竖直开口密封硅胶垫圈上。

2. **锁闭解除与门板抓取（Unlocking & Retraction - SEMI E62 规范）：**
   - Load Port 机构门板表面伸出 **4 个微型真空吸盘**，瞬间吸住 FOUP 前门板光滑区域。
   - 门板上对称分布的两根带键槽的旋转插销（Latch Keys）水平插入 FOUP 门上的两个“一”字型开锁盲孔内。
   - 伺服机构驱动插销旋转 **$90^\circ$**，驱动 FOUP 门板内部联动的双偏心凸轮机构收缩，从盒壳边框卡槽内收回上下左右共 4 根定位锁舌。
   - Load Port 机构板向 EFEM 内部平移后撤 **$50\text{mm}$**，将脱开的整块 FOUP 门板平稳拔出。
   - 升降气缸带动整扇吸附着前门的机构板垂直向下潜行沉入设备下腹部的容纳空腔中（行程约 **$300\text{mm}$**）。至此，25 片水平排列的硅晶圆完全展现在 EFEM 洁净微环境面前。

3. **晶圆槽位快速激光扫描测绘（Wafer Mapping）：**
   - 位于装载口上方的细长弧形传感器支架带动一对红外激光对射探头自上而下在 1.5 秒内极速扫过 25 个晶圆槽。
   - **检测逻辑：** 确认每个槽位是否有片、是否有两片叠槽（Double Slotting）、是否有晶圆斜插卡壳（Cross Slotting）。确认无误后，主控系统发出抓取指令。

4. **EFEM 大气机械手运动姿态与拾取动作：**
   - **机械手臂构型：** 采用双关节 SCARA 机械臂结构，肩部（Base）、肘部（Arm 1）、腕部（Arm 2）由高精度谐波减速机直驱，末端配有轻量化铝合金或碳纤维材质的超薄双叶片末端执行器（End-Effector / Fork）。
   - **拾取晶圆动作：**
     - 机械手以折叠姿势上升到目标晶圆槽位下方标高。
     - 薄型叶片（厚度仅 2mm - 3mm）水平直线伸入晶圆底下的狭窄空隙（晶圆间距仅 10mm）。
     - 叶片垂直向上微升 **$3.0\text{mm}$**，将晶圆从 FOUP 两侧的塑料支撑齿架上托起。
     - 叶片末端的微型真空吸盘通电吸附晶圆背面边缘，或气动边缘夹爪从圆周三点向内微合轻扣（Edge-grip）。
     - 机械手臂水平平滑直线缩回，晶圆完全离开 FOUP。

5. **光学缺口寻心与对准（Pre-Aligner 动作）：**
   - 机械手水平旋转 $90^\circ - 180^\circ$，将晶圆放置在侧旁的 Pre-Aligner 真空旋转吸盘台面上。
   - 寻心台启动高速旋转（转速约 180 - 300 RPM，旋转 1 至 2 圈）。
   - 台侧的微型 CCD 线阵激光传感器实时扫描高速旋转中的晶圆边缘，计算晶圆物理中心与转轴的偏心距，并瞬间捕捉晶圆边缘的“V”型定位刻口（Notch，深度约 1.0mm - 1.25mm）。
   - 晶圆根据工艺要求旋转到特定角度停止，EFEM 机械手重新精确下压取片，保证晶圆进入工艺腔时晶格取向绝对一致。

### 4.3 进出真空室与反应腔处理内部机械链条

晶圆从大气压洁净室进入极高真空（$10^{-6}\text{ Torr}$）反应腔的物理传递链条：

```
+----------------------------------------------------------------------------------------------------+
|                             真 空 过 渡 与 腔 室 加 工 运 动 链 条                                 |
+----------------------------------------------------------------------------------------------------+

 [EFEM 搬送]               [Loadlock 降压]             [VTM 真空倒料]             [反应腔加工]
   晶圆入闸                  粗抽+分子泵抽真空           磁悬浮真空手接力           静电吸附与等离子体
      |                             |                           |                         |
+-----V------+              +-------V------+            +-------V------+          +-------V------+
| 大气机械手 |              | 狭缝阀门密封 |            | 双叶片真空臂 |          | 陶瓷静电吸盘 |
| 送入预备仓 |              | 1000mbar降至 |            | 伸入中间中转 |          | 顶升销降下托底|
| 狭缝门关闭 |              | 0.05mbar以下 |            | 翻转进入各PM |          | 等离子体辉光 |
+------------+              +--------------+            +--------------+          +--------------+
```

#### 关键机械运动参数与视觉表现：
1. **狭缝隔离阀门动作（Slit Valve Motion）：**
   - 位于 Loadlock 与腔室之间，阀口呈扁平细长矩形（约 $340\text{mm} \times 35\text{mm}$）。
   - **开合方式：** 气缸驱动阀板先水平平移退开 15mm 避开密封 O 形橡胶圈，再垂直向上或向下收缩滑移。动画中应表现出清脆的气动换向泄气声（“哧——”的一声轻响）。

2. **真空传输机械手（VTM Dual-Blade Robot）：**
   - 处于绝对高真空与无油摩擦环境下，通常采用磁悬浮无接触传动轴或双蛙腿平行四边形连杆机构（Frog-leg mechanism）。
   - 末端叶片由耐高温高纯陶瓷（纯氧化铝 $\text{Al}_2\text{O}_3$ 或碳化硅 $\text{SiC}$）精细加工而成，没有真空吸盘（真空环境下真空吸盘无法工作），纯粹依赖叶片微凹曲面和重力摩擦力托举晶圆。
   - 机械臂执行“**极速伸入 $\rightarrow$ 微距下沉 $\rightarrow$ 平滑收回**”的交接动作。

3. **反应腔内静电吸盘与顶升机构动作（ESC & Lift Pins）：**
   - 工艺腔内部正中央为巨大的圆盘形加热/水冷基座。
   - **顶升销升起：** 3 根白色高纯石英/氧化铝陶瓷撞针从基座表面均匀分布的微孔中垂直向上顶升伸出 **$15\text{mm} - 20\text{mm}$**。
   - **放片：** 真空机械手将晶圆水平送至撞针正上方约 2mm 处，随后微沉将晶圆平稳交接搁置在 3 根针尖上，机械手原路退回，狭缝阀紧闭锁死。
   - **收针与吸附：** 撞针缓缓向下降入基座内部孔洞，晶圆完全贴附在平整的陶瓷静电吸盘表面。吸盘电极加载 $\pm 1000\text{V} - 1500\text{V}$ 的直流高压，利用约翰逊-拉贝克效应（Johnsen-Rahbek Effect）产生高达几十千牛顿的强大静电吸附力将硅片牢牢锁死在冷盘上。
   - **背面充气：** 基座微孔向晶圆背面压入高纯氦气传导散热。
   - **等离子体起辉（Plasma Ignition）：** 顶部喷淋盘通入工艺特气，高频射频电源（13.56 MHz / 60 MHz）瞬间脉冲放电，强电场将气体瞬间电离成璀璨明亮的发光等离子体（Plasma Sheath 悬浮在晶圆上方 10mm - 25mm 处）。

### 4.4 洁净室内气流组织与人员人机工程表现

在 Blender 场景中，除了冷冰冰的钢铁设备，必须加入符合工业规范的**洁净室人机要素与空气流动动态**，才能赋予画面强烈的专业真实感与空间呼吸感：

1. **下沉式单向垂直层流可视化（Laminar Airflow Visuals）：**
   - 洁净室空气从天花板 ULPA 滤网以约 **$0.35\text{ m/s} - 0.45\text{ m/s}$** 的均匀恒定微风竖直向下压送。
   - 空气不产生任何横向湍流或大漩涡，笔直灌入架高地板的密布穿孔孔洞中。
   - 在粒子动画（Particle System）表现中，可使用极微弱的漫反射悬浮光斑模拟纯净气流在光束照耀下的笔直下沉运动。

2. **洁净室工程师服饰与人机交互姿态（Bunny Suit Personnel）：**
   - **穿戴规范（严禁露出一根头发与裸露皮肤）：**
     - 全身连体式超细聚酯防静电无尘服（Bunny Suit），嵌有可见的 $5\text{mm} \times 5\text{mm}$ 防静电导电碳纤维方格暗纹。
     - 头部佩戴连体无尘帽，面戴防雾护目镜（Goggles）与医用级 N95 级别无尘口罩。
     - 手戴双层无粉丁腈（Nitrile）手套，脚蹬白色高帮防静电软底洁净靴（靴套扎死在无尘裤管外部）。
   - **交互动作：**
     - 工程师在 Clean Bay 走廊极少大步奔跑，动作保持缓慢平稳以减少搅动空气涡流。
     - 双手持有专用防静电平板电脑（ESD Tablet）或轻便推车，在机台悬臂工业触控屏前驻足调阅参数曲线、输入工艺配方（Recipe）。
     - 侧面维护区（Chase 灰区）工程师手持力矩扳手、氦质谱检漏仪（Helium Leak Detector），对拆开的真空法兰盘进行喷氦检漏。
