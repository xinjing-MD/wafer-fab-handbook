## 核心黄金工程尺寸基准（300mm Fab 三维参考）

- **晶圆直径 / 厚度**：`300.0 mm ± 0.2 mm` / `775 μm`
- **FOUP 槽位间距与容量**：Pitch `10.0 mm`，标准 `25` 片
- **SEMI E15.1 Load Port 基准标高**：`900 mm`（距架高地板）
- **架高地板单元 / 天花龙骨**：`600 mm × 600 mm` / `1200 mm × 600 mm`（FFU）
- **洁净室净空 / Sub-Fab 净空**：Cleanroom `4.2 ~ 4.8 m` / Sub-Fab `4.5 ~ 6.0 m`
- **OHT 天轨标高**：距架高地板约 `3.2 ~ 3.8 m`（预览模型采用 `Z = 3.50 m`）
- **光刻区安全光光谱**：`589 nm` 单色琥珀黄光

## 使用方式指南

1. **浏览器直接体验 3D 洁净室（`08_交互式3D洁净室CleanBay结构预览.html`）**
   - 说明：GitHub 网页端默认将 `.html` 文件展示为源代码。请将仓库克隆到本地，用 Chrome / Edge 等现代浏览器直接打开 `08_交互式3D洁净室CleanBay结构预览.html`（或通过本地静态服务器打开，需联网加载 Three.js CDN）。
   - HUD 交互功能：支持鼠标左键旋转、滚轮缩放、右键平移，并配有 **切换 589nm 光刻黄光区**、**暂停/恢复 OHT 天车巡航** 与 **重置视角** 按钮。

2. **Blender 一键生成 1:1 标准工程白模（`07_Blender_bpy_300mm晶圆厂标准件生成脚本.py`）**
   ```bash
   # 在 Blender 4.x / 5.x 命令行无头执行，或在 Scripting 工作区运行
   blender --background --python 09_实战脚本与3D/04_三维建模与视觉参考/07_Blender_bpy_300mm晶圆厂标准件生成脚本.py
   ```
   > 若使用系统普通 Python 直接运行该文件，脚本会自动检测无 `bpy` 环境并打印上述 Blender CLI 调用提示。
